# reading-analysis

把英语阅读题交给 AI 分析的方法卡体系：高考 / 四六级 / 考研通用。

## 一、解决什么问题

**在没有老师指导的情况下**，靠自己刷题研究英语阅读（高考/四六级），普遍会卡在三件事上：选项分析不透彻——错了一题只知道选错了，不知道错在哪条原理上；找不到门路——网上技巧满天飞，零散不成体系；没有可操作的方法——道理都懂，落到一道具体的题上还是不知道第一步干什么。

本项目解决的就是这个：把阅读分析拆成 126 张可操作的方法卡。每个选项都有归因（错在哪类陷阱）、有原理（为什么这样判）、有步骤（下一步怎么做）。错了知道为什么错，对了知道为什么对——相当于给自己配了一套不需要老师在场的分析流程。

## 二、主要功能

分析英语阅读，生成一份**带完整解析的「阅读解析版」**：篇章结构、每段段旨、逐题解析（正确项的依据 + 干扰项逐项归因）、长难句剥离、命题点预埋。

覆盖：高考阅读与七选五、四六级选词填空/长篇匹配/仔细阅读、考研阅读，以及中文概括归纳题。

## 三、安装方法

三种方式任选，详见 `USER-GUIDE.md`：

1. **网页对话**：复制 `SKILL.md` 全文，粘进任意 AI 对话框（豆包/DeepSeek/Kimi/ChatGPT），然后发题。每次开新对话需重粘
2. **装成 Skill**（WorkBuddy / Claude Code / Cursor）：整个文件夹放进工具的 skills 目录（如 `~/.workbuddy/skills/reading-analysis/`）
3. **RAG / API**：把 `references/cards/` 挂成知识库，`SKILL.md` 作为 system prompt

## 四、使用方法

| 你说 | AI 走的模式 |
|---|---|
| 「分析这道题」+ 原文和题目 | 单题分析（挂卡号 + 缺口栏） |
| 「拆这篇文章」 | 全文拆解（篇章模式/段旨/长难句/命题点，八步流程） |
| 「跑这篇，有参考答案」 | 对抗式：AI 先闭卷作答，再对撞你的答案，差异回填卡片 |
| 「批量跑」+ 5-10 篇 | 批量速览（每篇五行摘要，详析落 case 文件） |
| 「阅读复盘」 | 统计错因分布，生成个人规则 |

喂错题时给三样最有效：①原文 ②哪题错 + 正确答案 ③**你当时为什么选错**。

## 五、输入输出示例

**输入**：

> 文章：（一篇讲 AI 隐性学习的说明文，5 段，从略）
> 第 32 题：What is Paragraph 2 mainly about? A. 研究过程 B. ... D. 实验细节
> 我选了 D，正确答案是 A。我当时觉得段落里全是实验操作细节，就选了 D。

**输出**（节选）：

```
【题型】段落主旨题
【定位】P2 整段：First 微调教师 AI → Then 训练学生 AI（不提 owls）
      → Surprisingly 学生也答 owl → Second test 危险回答同样被传染
【正确项 A】这条时间链整体在展示「研究怎么一步步做」= 研究过程
【干扰项 D】段落确实全是实验细节，但那是描述不是功能——
      概括停在半途。检验：你的概括还能不能再上提一层？
【用到卡】B048 段落主旨 / B016 句子功能 / A003 信息层级
```

每个干扰项都有归因，每个结论都能追溯到原文某一句。完整说明见 `USER-GUIDE.md`。

## 仓库结构

```
SKILL.md                 工作规则与工作流（AI 读这个）
USER-GUIDE.md            使用说明书（人读这个）
QUESTION-TYPE-MAP.md     题型 → 必查卡对照表
references/cards/        126 张方法卡（A/B/R 三系，各带 INDEX）
references/*.md          原理内核 / 语篇关系 / 概括层 / 考试参数
references/theories/     理论拆解（空，使用者自己积累）
references/cases/        真题案例（空，使用者自己积累）
references/my-patterns.md 个人错题模式（空，复盘自动填充）
```

## 说明

- 方法与规则为本项目原创提炼与实战校准；仓库内不含任何第三方书籍原文或真题内容
- `theories/` 与 `cases/` 刻意留空：用你自己的材料填充，个人错题模式才会长在你自己的数据上
- 欢迎按 `SKILL.md` 的铁律规则提交改进
