# 反模式索引（ANTI-PATTERNS）

> **这是什么**：卡库的**反向入口**。正向卡回答「这是什么、怎么用」；本表回答「**什么做法一定是错的**」。
>
> **怎么用（给 agent）**：用户提交题目时——
> 1. 用户**自述**了某个错误（「我总在这类题上…」「我的问题是…」）→ 扫本表匹配关键词
> 2. 用户的**错选项**构造能归入某条 → 弹出对应卡
> 3. 用户写的**错因**直接匹配 → 弹出
>
> **弹出上限 1-2 条**，命中就弹、不命中不弹。全弹＝噪音，等于没弹。
>
> **素材来源**：全部来自现有 A/B 系卡（逐条挂卡号），本表只做反向重组。新增卡时如出现新反模式，追加进本表。

## 一、选项判读类

### AP-01 拿结果/机制当主张
- **匹配关键词**：拿结果当主张、机制当主张、把手段当目的、下游效果冒充、效果冒充原因、看着对、因为原文说、原文里有、看到原文说、说的没错但不是答案、明明原文有、明明有原文、有原文的词、选项里明明有
- **症状**：选项含原文词，读着很对，但它是因果链的**下游效果**或**中间手段**，不是作者要证明的那句
- **为什么错**：结果与机制都可能真实成立，但它们不回答「作者主张什么」
- **怎么防**：三位置判定——选项落在**主张位**才是答案；落在结果位/机制位＝错位
- **挂卡**：B083

### AP-02 靠日常语感容忍度判等价
- **匹配关键词**：我觉得算、看着挺对、觉得挺对、太严了吧、也算、大概、差不多、程度上可以接受、生活里能接受、49%
  > 「**日常语感**」原在此条，第十一轮移到 AP-03（L3-3）：本条的判据是**容忍度**（也算/差不多/太严），语感类说法归 AP-03；两条共用「语感」词会同时弹、其中一条不对题（已加互斥对兜底）。
- **症状**：主体对、方向对、日常语感完全接受，但原文限定强度不到这个程度
- **为什么错**：考的是**命题等价**，不是日常容忍度；限定词是硬边界
- **怎么防**：回原文抠限定词（only / may / tend to / at / from），不用生活常识补票
- **挂卡**：B083

### AP-03 凭语感赌选项
- **匹配关键词**：读着顺、读起来通、靠语感、凭语感、语感猜、猜的、凭感觉、感觉对、说不清依据、说不出为什么、日常语感
- **症状**：读着顺就选，说不出依据；重做一遍还是错
- **为什么错**：干扰项就是照「读着顺」设计的——顺恰恰是诱饵
- **怎么防**：每题必须有**可指认的原文证据句**，指不出来不许落笔
- **挂卡**：B083

### AP-04 范围限定被扩大/缩小
- **匹配关键词**：范围被放大、范围被缩小、限定词没看清、题干限定、扩大范围、缩小范围、题干条件漏看
- **症状**：题干限定的范围（时间/地点/条件）在选项里被放大或缩小
- **怎么防**：先把题干限定条件圈出来，再逐项比对，不比对整体意思
- **为什么错**：命题等价要求「范围」这一维完全对等——范围一变，命题真值就可能反
- **挂卡**：B083（类5）

### AP-05 方向反转
- **匹配关键词**：方向搞反、方向反了、搞反了、弄颠倒了、升的看成降、快慢搞反、增减搞反
- **症状**：动词一换方向反转（separate→transform）；考研密度约 8 处/篇（四级两三倍）
- **怎么防**：抓核心动词，确认方向词极性后再判
- **为什么错**：方向词承载因果极性；极性一换，命题就从「促进」变成「抑制」
- **挂卡**：B083（类3）

### AP-06 所属对象挪移
- **匹配关键词**：张冠李戴、安错对象、安到别人头上、搞混了主体、对象搞错、换了个对象
- **症状**：性质从一个对象挪到另一个对象头上
- **怎么防**：问「这个性质原文里属于谁」，逐项核对主体
- **为什么错**：性质依附于主体，主体换了命题就换了；原文词对得上 ≠ 对象对得上
- **挂卡**：B083（类4）

### AP-07 判断归属错位
- **匹配关键词**：判断归属搞错、谁的观点搞混、把当事人当成作者、观点归属错、安到作者头上
- **症状**：把当事人的判断安到作者头上（或反之）
- **怎么防**：先分清说话人，再判这是谁的观点
- **为什么错**：文中不同人的判断分属不同立场；归属一错，等于替别人表了态
- **挂卡**：B083（类6）/ B038

### AP-08 模态档位升格
- **匹配关键词**：把可能写成已经、展望当成既成、升格、模态档位错、把 may 当成已经
- **症状**：选项把 may/suggest 的展望链条升格为既成事实，或把同级写成 more than before
- **怎么防**：抓模态词，确认是「可能」还是「已经」
- **为什么错**：模态词（may/suggest）标的是「可能性」；升格为既成＝改写作者立场
- **挂卡**：B083（类9）/ A034

### AP-09 局部↔整体越层
- **匹配关键词**：越层、局部升成整体、拿个案当普遍、把个案说成规律、一处推广到整体
  > 「**以偏概全**」原在此条，第十二轮移到 AP-14（G37 扫出共用词）：本条的判据是**层级**（局部证据升格为整体结论），「以偏概全」在中文里更常指**概括覆盖度**（太窄/只覆盖一端），归 AP-14 更对题。两条语义**不互斥**（一个讲层级、一个讲覆盖度），故用**归属切分**而非互斥对。
- **症状**：局部证据真实成立但层级不对（某法案的 unwieldy 被升格为"这类改革难落地"）
- **怎么防**：区分「换对象」（AP-06）与「换层级」（本条）
- **为什么错**：局部结论只在局部成立；越层升格＝把个案当普遍
- **挂卡**：B083（类10）/ A032

### AP-10 热点当推荐
- **匹配关键词**：热点当推荐、讨论多当作者推荐、把热闹讨论当成作者主张
- **症状**：把文中热闹讨论的（热点）当成作者推荐的（修辞位）
- **怎么防**：区分「文中被讨论」与「作者要立」，回修辞位判
- **为什么错**：文中「被讨论」与作者「要立」是两件事；热门话题常是被审视的对象
- **挂卡**：B083（类8）

### AP-11 话题切分错误
- **匹配关键词**：缝成一件事、跨段缝、两件事缝成一件、把两段拼一起
- **症状**：同人跨段的两件事被缝成一件事
- **怎么防**：按段落边界切分话题，不跨段合并
- **为什么错**：段是话题的边界；跨段合并会把两件独立的事缝成一件
- **挂卡**：B083（类7）

## 二、概括与主旨类

### AP-12 层级错配（该升不升 / 该降不降）
- **匹配关键词**：太具体、拔不起、拔不高、琐碎、空话、概括得不够、说得太细、太虚、概括得飘、例子当主旨、拿细节当论点、细节当论点、把细节当、拿例子当主旨、写得太空、写成空话、要么太细、要么太空、太细要么太空、概括得太细、概括得太空、概括太细、概括太空
- **症状**：两头都错——**该升不升**：细节堆砌当论点（「他昨天七点半吃了个鸡蛋」当主旨）；**该降不降**：空话架空（「我们要努力学习、提高素质」）
- **怎么防**：判层级先问「这句上提一层是什么」——只看字面必误判
- **为什么错**：概括的价值在「上提一层」——停在原层等于没概括，越层等于脱离材料
- **挂卡**：A003

### AP-13 定位技巧当结构层级
- **匹配关键词**：把首尾呼应当层级、设问当层级、倒金字塔当层级、层级画多了、分层分太多、层级图画乱
- **症状**：把首尾呼应/设问自答/倒金字塔当成一层，两层语段画成四层
- **为什么错**：层级只按**句群统属关系**划分；定位技巧是技巧不是结构
- **怎么防**：一层＝一组同层关系（一个复句/句群单元）；技巧标注在树**旁边**
- **挂卡**：A003

### AP-14 概括太窄 / 太宽
- **匹配关键词**：以偏概全、无中生有、只说了、超出原文、概括偏了、概括得太宽、概括得太窄、漏了、写得太大、概括得太大、概括太泛、抓不住、抓不住主旨、抓不住重点、看不出层级
- **症状**：太窄＝只覆盖一部分；太宽＝超出文章讨论范围
- **怎么防**：好概括三标准——覆盖性 / 不溢出 / 无细节
- **为什么错**：主旨要同时满足覆盖性与不溢出；窄了漏信息，宽了出材料
- **挂卡**：summarization §二 / A004

### AP-15 正向误读：把批判读成赞美
- **匹配关键词**：正能量、赞扬、励志、只抓品质、题意读偏、读成正面的了、以为在夸
- **症状**：把作者的批判读成赞美（「父亲勤劳坚韧」掩盖了对"把尊严寄托于外在形式"的批判）
- **怎么防**：概括情节时记**变化**（前后对比），不记「谁做了什么」
- **为什么错**：作者写「变化」常是为了批判；只抓正面品质会把批判读成赞美
- **挂卡**：B003

### AP-16 否定态度混成「中立」
- **匹配关键词**：当成中立、说成客观、不偏不倚、态度题选中立、把否定当中立
- **症状**：作者对 X 否定、对 Y 肯定，概括成一个不偏不倚的「中立态度」
- **怎么防**：先分正反两侧各自定性，不许平均化
- **为什么错**：态度题考的是立场不是情绪强度；有褒贬就不能平均成「中立」
- **挂卡**：B009

### AP-17 维度清单不全 → 特点题漏项
- **匹配关键词**：漏了一个、少了一个、特点题漏、维度清单不全、特点没扫全
- **症状**：同一病灶重复（众筹题漏「高效」、社会创业家漏「关注自然环境」）
- **怎么防**：按固定维度清单逐项扫（效率/公平/参与/透明/专业/灵活/低成本/环境/诚信/责任）＋集合主体扫描法
- **为什么错**：特点题的答案由「材料里有几维」决定；清单不全必然漏项
- **挂卡**：B084

### AP-18 概括过度
- **匹配关键词**：升华了、上升到人生、太宏大、空泛哲理、过度升华
- **症状**：把具体诗意/主题上升为空泛哲理（诗歌/文学主旨题常见）
- **怎么防**：检查概括是否还在原文范围内，越级概括＝错
- **为什么错**：概括不能超出材料给的抽象层；越级升华＝把自己的话当成作者的话
- **挂卡**：summarization 8.6

## 三、关系判定类

### AP-19 见连接词就判关系
- **匹配关键词**：看到 but 就、看到 however 就、见词就判、连接词当决定者、假标记
- **症状**：见词就判关系，不回原文验语义
- **为什么错**：**连接词只是路标，不是关系的决定者**（A008）
- **怎么防**：回语义验证；警惕假标记——while（当…时/然而）、since（自从/因为）、as（当/因为/尽管）
- **挂卡**：A008 / B015

### AP-20 一刀切：不分文体取因取果
- **匹配关键词**：因果搞反、因果一刀切、取果取因一刀切、把因当果
- **症状**：无脑取果（说明文常考「因」，议论文常考「果」）
- **怎么防**：先判因果三型（单纯陈述→留果 / 探本质→留因 / 渲染型→留因）
- **为什么错**：因果取舍由作者「写来强调哪一半」决定，不由「因在前果在后」决定
- **挂卡**：B020 / B021

### AP-21 转折＝强调后面
- **匹配关键词**：转折后、强调后面、后面重要、选后面、就选后面、but 之后、只要转折就、转折必选后、以转折后为主、取转折后
- **症状**：把「重心在后」当定义用
- **为什么错**：转折的定义是**语义方向出现拐角**；「强调后面」只是常见效果；转折前后**同层级**
- **怎么防**：先分层级定重心（不由位置定），回主旨验证
- **挂卡**：B019 / A003

### AP-22 默认并列无重心
- **匹配关键词**：并列都重要、并列一样重要、把并列当成一样、并列当一样、不分主次、没有侧重、平均对待、默认并列无重心
- **症状**：见并列就当平均，不做轻重判断
- **怎么防**：并列也要回主旨看有没有侧重——不要默认无重心
- **为什么错**：并列是形式，权重是内容；形式并列不排除语义上有侧重
- **挂卡**：B001

### AP-23 把复现当证据
- **匹配关键词**：看到原词就选、原词重现、靠复现、复现当证据、一模一样的词、有原词所以选
- **症状**：拿选项词回原文找「复现」就定答案
- **为什么错**：**复现是线索，不是证据**（A006 六点六）
- **怎么防**：复现用来**筛选**，定案仍须功能/层级验证
- **挂卡**：B011

### AP-24 见代词就认定回指
- **匹配关键词**：见代词就、代词就是、以为是回指、代词指代搞错、有代词就认定、指的是不是同一个、是不是同一个、指的是同一个、是不是指同一个、分不清指谁
- **症状**：以为「有代词＝一击命中」
- **为什么错**：有指称形式 ≠ 有指称关系；代词只是把范围砍掉一半
- **怎么防**：找到先行词后仍须验证指称关系
- **挂卡**：B013

### AP-25 假设内容简单舍弃
- **匹配关键词**：让步句舍掉、把假设舍了、虽然就舍、舍掉让步、分不清让步、让步和转折分不清
- **症状**：看让步句就舍，忽略它可能是论证的一部分
- **怎么防**：**让步不能简单舍**——假设内容常是论证的必要部分
- **为什么错**：让步/假设常是论证的必要前提（「若无 X 则不能 Y」）；舍了论证就断
- **挂卡**：B023

## 四、词汇与指称类

### AP-26 比喻义硬解字面
- **匹配关键词**：比喻按字面、字面直译、sweet spot 当地方、按字面理解比喻、Goldilocks 当地点
- **症状**：把比喻义坐实成物理地点/具体位置（sweet spot / Goldilocks 类）
- **怎么防**：**语境义优先于字面义**（B037）；生词比喻标注后跳词根/上下文兜底，别硬猜
- **为什么错**：比喻的所指由语境确定；按字面读等于换了论题
- **挂卡**：B052 / B037

### AP-27 阶梯含意忽略取消标记
- **匹配关键词**：忽略取消标记、not all 当成、阶梯含意搞错、把含意当必然
- **症状**：默认「not all」含意成立，忽略作者加的修正语
- **怎么防**：先用 at least / in fact / even 扫一遍有没有取消标记，再下结论
- **为什么错**：作者的修正语（at least / in fact）会取消原含意；不先扫就下结论必错
- **挂卡**：B075

### AP-28 间接言语行为忽略语境
- **匹配关键词**：忽略语境、按句型表硬套、语境理解错、不看场景
- **症状**：按句型表硬套，忽略场景（泳池边 "Can you swim?" 可能是邀请/请求）
- **怎么防**：**先看场景再套句型表**
- **为什么错**：同一句式在不同场景下施为不同；句型表是线索，不是判决
- **挂卡**：B077

### AP-29 引用观点当作者观点
- **匹配关键词**：引用当作者观点、把某某说的当成作者、引用分不清、说话人搞混
- **症状**：把文中引用的观点当成作者观点
- **怎么防**：**区分说话人**——引用观点 ≠ 作者观点
- **为什么错**：引用是「借他人之口」；说话人一混，立场就反了
- **挂卡**：B038 / B061

## 五、文体与方法边界类

### AP-30 单一方法硬套所有文体
- **匹配关键词**：套模板、所有文章都一样、一套方法用到底
- **症状**：把「现象→机制」型说明文的规则套到研究类说明文（应看首段结论 / B042），或反之
- **怎么防**：先判文体类型，再选方法；评论/观点类文章「结论前置」失效
- **为什么错**：不同文体的问题结构不同（现象→机制 vs 研究→结论）；方法必须随文体换
- **挂卡**：B034 / B042

### AP-31 形式一致性当硬约束
- **匹配关键词**：小标题形式当硬约束、形式一致当约束、形式一致性当硬指标
- **症状**：把小标题形式一致当硬约束（2015 新课标1 三个小标题并不同型）
- **怎么防**：**形式一致性是弱线索**——先看内容覆盖，形式是辅助
- **为什么错**：形式是弱线索——作者可以不遵守自己的形式；内容覆盖才是硬证据
- **挂卡**：B007

### AP-32 同义选项排除法用于多选
- **匹配关键词**：同义排除法用错、多选里用排除法、把单选规则用到多选
- **症状**：把「单选题里同义项必错」的规则用到多选/七选五（本就是多选性质）
- **怎么防**：**此法只在单选题成立**，先确认题型
- **为什么错**：「同义项必错」的前提是「只有一个正确答案」；多选里多答案共存
- **挂卡**：B035

### AP-33 长难句从句首硬读
- **匹配关键词**：读到一半就、读一半忘了、读到后面忘了前面、从句首、一句一句啃、越读越乱、读长句读不下去
- **症状**：从句首逐词理解，读到一半忘了前面在说什么
- **怎么防**：三拍顺序——**先抓全局关系 → 再抓连接标志 → 最后局部化简成标准句式**
- **为什么错**：长难句的信息重心在结构关系上；逐词读会先耗尽工作记忆、再丢主干
- **挂卡**：B028

### AP-34 用形式过滤冒充判定
- **匹配关键词**：靠标点筛、形式过滤当判定、筛完就定案、过滤完当答案
- **症状**：形式过滤（标点/信号词/指代）出结果就直接定案
- **为什么错**：**形式是过滤器，不是判定器**
- **怎么防**：形式过滤砍掉 2-4 个选项后，剩下的靠功能/层级定
- **挂卡**：B004 / B024

### AP-35 劝导性定义
- **匹配关键词**：靠定义假定、定义当论证、顾名思义、用定义假定结论
- **症状**：论证靠定义假定结论（「堕胎=谋杀婴儿」）
- **怎么防**：论证应证实结论，不是靠定义假定结论
- **为什么错**：定义若已把结论包进去，论证就成了同义反复——它没有证明任何东西
- **挂卡**：B059

## 六、元层：术语自查

### AP-36 术语通胀（用标签判案）
- **匹配关键词**：核心素养、赋能、建构、生态、体系化、高阶思维、闭环、抓手、底层逻辑
- **症状**：用华丽术语包装旧动作；或反过来——因为术语华丽就判它是包装
- **怎么防**：三问测试，用**行为**判案不用**标签**——
  1. 换回大白话，动作会变吗？（会变→真命名）
  2. 能举出「不用它就说不清」的例子吗？（有→真命名）
  3. **能被证伪吗**？（能→真命名；不能→装饰）
- **注**：第 3 问是杀手锏。不可证伪的术语＝装饰
- **为什么错**：术语的价值在能改变行为；不可证伪的术语（找不出反例）只是装饰
- **挂卡**：无（元规则，见 CHANGELOG 2026-09-24）

## 匹配原则（写给使用者与 agent）

**关键词要口语化**——写成用户真会说的样子，不是术语。例：写「看着挺对」不写「日常语感容忍度」。

**关键词来源**：①用户实际说过的原话（实战中补）②该反模式的典型口语表述。

**禁用过泛词**：如「就是」「结果」「觉得」这类单字/通用词会大量误命中，已剔除。

**匹配是语义的，不是纯字符串的**：agent 读关键词是拿它当**提示**理解用户意图；脚本的字符串匹配是给自动化用的兜底，命中率低一些正常。**宁漏不误**——误报比漏报更伤。

**判定口径（2026-09-24 实测补）**：一个词**会不会出现在「描述文章内容」的正常句子里**？会 → 不合格，必须删或改成带错误意图的短语。
> 反例：「因果」「并列」「比喻」「定义」「人生」——都在正常描述里出现（"这篇讲的是因果关系的文章"），实测 5/5 误报。
> 正例：「因果搞反」「看到 but 就选后面」「我总把例子当主旨」——带错误意图，不会出现在内容描述里。

**意图闸门**：`match_anti_patterns()` 先判输入含不含**自述信号**，无信号直接返回空（防把「我想知道第三段的定义是什么」当成认错）。五类信号在 `scripts/anti_patterns.py` 的 `GATE_RE`：
① 第一人称＋差错/习惯词（窗口 30 字）② 独立差错动词/出错结构（含「一看到…就」）③ 第一人称习惯/自我判定（含「我觉得」，因 AP-02 关键词需要它）④ **无第一人称的自述起手式**（概括起来/这类题/每次遇到…）⑤ 作答证据痕迹（对答案/复盘/被骗…）

**闸门与关键词的分工（2026-09-24 实测厘清，纠正上轮判断）**：
- 决定误报的是**关键词宽度**；闸门是粗筛。
- **但闸门不是冗余**：关闸实测，27 条「正常提问」有 25 条会被宽关键词打中——闸门在生产里确实在挡它们。
- **闸门过窄会内耗**：关键词本可命中的合法自述被自己挡掉（第六轮 K2-a/b/c 全是这类）。
- 故策略：**闸门宁可放宽**（安全交给关键词），**关键词严守「带错误意图」**（不许出现纯概念名裸形）。

**施事判定（2026-09-24 第七轮 L2 补、第八轮修正，与闸门同级）**：关键词命中 ≠ 该弹——还要看**词的施事是谁**。
- 同一串字，主语不同、含义相反：「**这段**概括得太宽」= 用户**评价文章**（不该弹）／「**我**概括得太宽」= 用户**自述**（该弹）。
- **判据（第九轮定版：四层，优先级从高到低）**——都在关键词**所在子句**内判断：
  1. 强自指（频率副词「老是/总是」或「我+行为习惯」）→ **保留**
  2. 「我 + 行为动词」（做/答/写/概括/选/填…）→ 我是**任务施事** → **保留**
  3. 「我…的感受/看法/观点是」→ **评价框架** → **否决**
  4. 子句内有对象词 且「我 + 评价动词（觉得/感觉/认为/以为）」→ 我是**评价者** → **否决**
  5. 兜底：对象词更近 → **否决**；「我」更近（话题句）→ **保留**
  > ⚠️ 第 2 层**刻意不含「读/看」**：「我读完整个第三自然段的感受是概括得太宽了」里「读」虽是动作，
  > 但整句语义框架是**评价文章**，故归第 3 层处理。
- **为什么不再单靠「距离」（第九轮 N3，实测数据）**：报告给了两个反例，距离判据在它们身上恰好指向错答案——
  · 「**我**做这类题总以偏概全」：我在最左、对象词更靠近关键词 → 判成评价 → **误杀自述**
  · 「这段的论述**我**觉得有点以偏概全」：我比对象词更近 → 判成自述 → **误报**
  两句距离关系相反、正确答案却是同一方向（看「我」是**行为施事**还是**评价者**）。
- **为什么没直接照报告建议换成「我+评价动词→否决」**：实测把它单用，总误差 **3**（比现行的 2 还差）——
  它会打坏「我觉得 49% 也算很多吧」这类**没有对象词**的自述。故保留距离做兜底，四层叠加后总误差 **0**（104 条样本）。
- 两个例外（保护真自述，见 `strong_self()`）：① **频率副词**独立成立（老是/总是/经常 → 习惯只能属于人）② 剥离认知框架「我觉得/我看」后仍能配到「我+行为」。
- **两轮实测轨迹（这条规则改过两版，值得记）**：
  | 版本 | 判据 | 评价句误报 | 话题句漏报 |
  |---|---|---|---|
  | 第七轮 | 关键词左侧 **10 字**内有对象词 → 否决 | 0/8 ✅ | **5/5 ❌（误杀）** |
  | 第八轮 | 子句内「我 vs 对象词」谁更近 | **0/8** ✅ | **0/5** ✅ |
  | 第九轮定版 | 四层（强自指 / 我+行为动词 / 评价框架 / 我+评价动词 → 距离兜底） | **0/18** ✅ | **0/17** ✅ |
- 第七轮那个版本的错在于：**「这段 我概括得太宽了」是中文极常见的「话题在前、主语在后」句式**，主体是「我」，「这段」只是话题（topic）不是施事（agent）——一刀否决把这类真自述全杀了。**这是典型的 fix-one-break-one：修好 8 条误报，同时打坏一类漏报。**
- 第九轮的元教训：**判据的「可解释性」不等于「正确性」**。第八轮的「谁更近」听起来很本质、也确实修好了当时的 8 条误报，但它对「对象词是否在主语位置」不敏感——第九轮两条例外都出在这里。**改判据后必须跑审核方原句**（现入库为 `ROUND9_EVAL` / `ROUND9_SELF`）。
- 第八轮另一处修正：**对象词表要够宽**。原表只列固定词组（「这段」「这个选项」），说法一长就漏——「这整个段落」「这部分内容」「第三自然段」全不在表里。**注意：这曾被误判为「距离太远」，实测把窗口从 10 放宽到 40 只改善 1/4**——真因是**词表覆盖**，不是距离。现改为「指示词 + 最多 4 字修饰 + 对象名词」。

**关键词的两种读者要分清**：
- **agent（主路径）**：读关键词当**语义提示**——概念名（如「越层」「正能量」）对 agent 有用，必须保留。
- **脚本（兜底）**：做字符串匹配——概念名裸形会误命中「正常提问」，已逐条收紧（如 AP-21 删「看到 however」裸形、AP-12「概括不够」→「概括得不够」）。
- 因此**不能要求关键词单独就零误报**（那是把 agent 的提示词当脚本判定词用）；生产口径 = 闸门 + 关键词共同决定。

**回归套件纪律（第六轮 K1 立规，硬要求）**：
- 用例集在 `scripts/ap_cases.py`，**追加式**：每轮复验/实战发现的漏报或误报，**追加进去且永不删除**。
- 分来源标注（审核方 / 实战 / 自造）——**自造样本全绿不代表审核方的能过**；上轮「漏报 0/10」之所以虚，就是样本是按关键词调过的那几条。
- 改匹配逻辑后必跑 `python scripts/verify_anti_patterns.py`（四道门禁，含本套件）。

## 附：匹配优先级

多条命中时，按此顺序弹（最多 1-2 条）：

1. **用户自述的**（他自己说的痛点，最高优先）
2. **错选项构造命中的**（客观证据）
3. **错因描述命中的**
4. 同一题内多条命中 → 只弹与本题证据链最直接相关的

## 维护规则

- 新增卡时若出现新反模式 → 追加进本表，并在 CHANGELOG 记一笔
- 反模式与正向卡的对应关系必须双向可查（本表挂卡号，卡内不强制挂本表）
- 本表**不重复卡内内容**，只做「症状 → 怎么防 → 挂卡」三行式索引；完整原理回原卡
- **共用词归属表**（第十一轮立表 / 第十二轮补覆盖检查）：两条反模式若**共用同一个关键词**，同一段自述会同时命中两条，其中一条**不对题**（用户看到一张错卡）。每个共用词交集**必须有归属决定，不许留白**，三选一：
  1. **切分**（首选，治本）：把词归给更对题的那条 → 切完交集为空
  2. **互斥**：登记进 `scripts/anti_patterns.py` 的 `EXCLUSIVE_PAIRS`
  3. **并存**：两条都对题、同时弹是正确的 → 登记进 `COEXIST_OK` 并**写明理由**
  - **门槛在机制上**：`verify_anti_patterns.py` **门禁 7** 自动扫全部关键词交集，任何交集不在上面两张表里 → 报红。
  - **口径（第十二轮 P3 定，取代「谁命中多留谁」）**：互斥对按**有没有独立证据**判——
    两条各自命中只属于自己的关键词 → 用户确实说了两件事 → **两条都留**（2 条也在克制上限内）；
    只有一条有独立证据 → 丢另一条（它只是靠共用词蹭进来的）；全靠共用词命中 → 取更实的。
    > 实例：「我老是靠语感选，**而且**我觉得 49% 也算多」→ 旧口径只留 AP-02，白丢 AP-03；现口径两条都留。
  - 现有互斥对：「AP-02 × AP-03」（容忍度判等价 vs 凭语感赌选项，共用「语感」类词）。
  - **由来（值得记）**：L3 冷启动实测弹出两张卡、其中一张不对题 → 立了 `EXCLUSIVE_PAIRS` 机制，
    但**表是手搓的、只登记了被抓到的那一对**；第十二轮审核方扫全库，又抓出 **AP-09 × AP-14 共用「以偏概全」**。
    **「修好一个实例」≠「机制已完备」——立了通用机制之后必须补一次覆盖检查**，否则就是
    「手工清单不完整」的同一个形状（同一课，在关键词表上又踩了一次）。
  - 改词表后**必跑** `python scripts/verify_anti_patterns.py`（门禁 7 会替你查有没有新长出来的共用词）。
- **字段一律一行式**（2026-09-24 定）：每个字段写成一整行，**禁止用缩进子行写成多行**——审计工具与渲染器都按「一行一字段」解析（多行会读成空值；渲染器另有续行合并兜底，但不作为常规写法）
- **关键词不许写「纯概念名裸形」**（2026-09-24 定）：概念名（越层/正能量/转折后）对 agent 是提示、可保留，但当它同时会被脚本字符串匹配时，**必须配套一个带错误意图的口语变体**（如「越层了」「只抓品质当主旨」）。新词入库后跑 `verify_anti_patterns.py` 的「关键词宽度试纸」验证。
- **字段规约（2026-09-24 定）**：`匹配关键词` / `症状` / `为什么错` / `怎么防` / `挂卡` **五项必填**。新增条目时不得缺项——缺项会导致用户可见层渲染出空行（见第十四轮复验 F1）。渲染器另有「空值跳过」兜底，但字段齐整是硬要求
