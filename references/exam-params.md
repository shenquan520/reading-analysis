# 考试差异参数

> 原理是同一套，这里只记**差异**。原理部分一律去 `core-principles.md` 看，不要在这里重复写。

---

## 高考英语阅读

| 项 | 参数 |
|---|---|
| 篇幅 | 单篇 300–400 词 |
| 题材 | 记叙文 / 说明文 / 议论文 / 应用文（广告、通知） |
| 题型组合 | 阅读理解（细节·推断·主旨·词义猜测）+ 七选五 + 完形填空 |
| 词汇门槛 | 3500 左右，超纲词通常给中文注释 |
| 干扰项风格 | 相对直白，多为**无中生有**和**以偏概全** |
| 特殊点 | 应用文题考信息检索，秒定位即可，别通读；七选五比四六级权重高 |

**高考专属提醒**
- 应用文（A 篇）是送分题，用题干关键词直接扫，30 秒内解决
- 词义猜测题在高考中出现频率高于四六级
- 记叙文重点抓**情感线**和**转折后的结局**

---

## CET-4 阅读

| 项 | 参数 |
|---|---|
| 篇幅 | 仔细阅读 300–350 词 × 2 篇；长篇匹配约 1000 词 |
| 题型组合 | 选词填空 + 长篇匹配（10 题）+ 仔细阅读（10 题） |
| 词汇门槛 | 约 4500，无注释，超纲靠推断 |
| 同义替换 | 中等强度，替换多为词性转换或近义词 |
| 特殊点 | 长篇匹配是**扫读题**，不是精读题 |

**CET-4 专属提醒**
- **长篇匹配**：先读 10 个题干圈关键词 → 回原文扫段落首尾 → 匹配即走，别通读全文。段落可重复选。
- **选词填空**：先判词性再选，靠语法缩小范围，最后才是语义。这题性价比低，留到最后做。
- 与本项目词汇系统同源（`E:\四六级` 的 HS/CET4 词库），分析时可查词难度。

---

## CET-6 阅读

| 项 | 参数 |
|---|---|
| 篇幅 | 仔细阅读 400–450 词 |
| 词汇门槛 | 约 6000，抽象名词与学术词汇密度高 |
| 同义替换 | **隐蔽**，常是整句改写而非单词替换 |
| 长难句 | 密度显著高于四级，从句嵌套多 |
| 选项风格 | 更抽象、更概括，直白复述的选项几乎都是干扰项 |

**CET-6 专属提醒**
- 读不懂时**先剥句子主干**，别硬读（`core-principles.md` 第六节）
- 正确项往往是原文的**高度概括**，看起来"不够具体"反而可能是对的
- 推断题比例高，一步原则执行要更严

---

## 通用难度标尺

| 维度 | 高考 | CET-4 | CET-6 |
|---|---|---|---|
| 词汇障碍 | 低（有注释） | 中 | 高 |
| 句子复杂度 | 中 | 中 | 高 |
| 同义替换隐蔽度 | 低 | 中 | 高 |
| 干扰项迷惑度 | 中 | 中高 | 高 |
| 时间压力 | 高 | 高 | 很高 |

**跨考通用结论**：无论哪个考试，**定位失败**和**脑补过度**两大错误归因的占比都远高于纯词汇问题。词汇是门槛，逻辑才是主战场。
