## 一、论证本质（公理层）

1. **论证 = 理由/证据支持结论的过程**；不是争论，不是表态。结论 = 被撑的陈述；前提 = 给理由的陈述。（该专著导论/规则 1 → A023）
2. **论证两大用途**：探究（答案未知时筛选观点）+ 辩护（已有结论后说服他人）。说服别人 = 拿出说服你自己的理由。
3. **演绎 vs 非演绎**（合法性边界）：演绎结论不超出前提（必真）；非演绎（例证/权威/类比/因果）超出前提，只保概率。→ 推理题：能推出的选项不超出前提，说得满 = 越界（B052）。

## 二、论证方式四大家 + 中国文论补充

| 方式 | 核心规则 | 卡片 |
|---|---|---|
| **举例** | 孤例不立；样本代表性；背景率；数字四陷阱；反例完善规律（规则 7-11） | B050 |
| **类比** | 「孤例不立」唯一例外；只需**相关方面**相似，无关差异不削弱（规则 12） | B043 |
| **诉诸权威** | 来源五检：列出/可靠/公正/多方/网络谨慎；领域权威≠跨界权威（规则 13-17） | （B042 上游） |
| **因果** | 关联四解释：巧合/方向反转/第三变量/多因复杂；补全缺失环节选最可能（规则 18-21） | B051 |

**议论文提炼读物塞进来的**：
- **例证端**：议论文标准结构 = 中心论点 + 例子 + 分论点 + 结论重申；**反面例子 = 反证中心论点**（课文实例：反面例子不是跑题，是从反面支撑正面论点）→ 例子作用题「描述≠功能」的反面版。
- **论点端**：论点句是骨架（B002）；**承上启下概括句**常在段首/段尾，是结构题突破口（课文实例）。
- **论证深加工**：好议论文靠分析、比较、分类、综合、概括得出普遍法则——论证的终点是上位概念（「出入」→「追求」），主旨题勿停在字面。

## 三、论证结构（篇章层）

1. **路线图段**：议论文首段末的总概括句预告全篇结构（规则 36）；主体每前提一段（重申→展开→证明）；「as noted above / to return to」= 引回路线图。→ D 篇先抓路线图段。
2. **让步-反驳段**（规则 37 → B053）：详述对方理由 → 两层驳（釜底抽薪 + 反向比较）→ 谦逊结论（规则 39：worth trying / despite uncertainties = 谨慎支持）。
3. **汉语复句研究塞进来的——让步复句体系（让转句式，最大金矿）**：
   - **统一框架**：让步句 = 先让步后转折（虽然 p，但 q / 即使 p，也 q / 宁可 p，也 q / 无论 p，都 q）；英语对应 = Although / Even if / Even though / Whether or not + but / yet / still。
   - **根本特征**：让步句同时具有**让步性**（姑且承认 p）与**转折性**（pq 逆向）——分类必须按 pq 关系，不能按「事实/假设」二分（虽然/即使都能接事实，如「即使如此」）。
   - **实让 vs 虚让**（传统语法学「容认 vs 推宕」）：**实让**从客观事实出发的理性让步（「他虽说缺点多，却实干」——p 是真的）；**虚让**对虚拟情况的让步（「即使明天塌下来，我也要……」——p 是假的）。→ B053 补强：让步句里的 p 不一定是作者承认的事实；判断 p 真假 = 判断作者是「承认既成事实」还是「借假设托出立场」。
4. **衔接理论塞进来的——连接的内部/外部关系**：连接分**外部**（事件之间的因果/转折，语篇外部世界）与**内部**（说话者论证行为中的因果/转折，「所以我认为/不过说实话」）。**让步连接（yet / however / nevertheless 引导的让步性衔接）属内部关系**——它是说话者在组织论证，不是描述世界。→ 判断连接词时先问：这连接的是**事件**还是**论证步骤**？
5. **语篇衔接专著塞进来的**：宏观结构（问题-解决模式，B034）= 方案类论证的宏观骨架；规则 33 的「能解决 + 优于替代方案」双条件是其判定升级。

## 四、谬误库（干扰项原型总库，规则 49 补 + 附录一）

- 谬误 = 违背正确论证规则的误导性论证；21 项全表见 `theories/lunzheng.md` 第 5 批。高频 8 项见 B054。
- 三大原型：**假二难**（藏第三条路）、**偷换概念**（同词两义滑移）、**稻草人**（歪曲对方再反驳）。
- 两种非法演绎：肯定后件（q→p）、否定前件（非p→非q）——本质都是忽略其他可能性。
- **规则 49 补**：攻击动机 = 人身攻击；公允承认对方理据 + 存疑 = 理性作者姿态（「柏拉图有其理据，但是否适用于今日另当别论」）。
- 排除法直觉：**越绝对的选项越像谬误**；正确项几乎从不包含谬误结构。

## 五、定义方法（论证地基，附录二）

- 词义不明 → 使之明确（词典起手但可能太宽/歧义）；争议词义 → 三范畴 + 种属种差（鸟 = 动物 + 有羽毛）。
- **劝导性定义** = 用定义夹带立场；「作者如何定义核心词」= 立场泄露点（首段 X means/is defined as = 地基句）。
- **定义不能代替论证**：「X is Y」推不出「X 该如何对待」；定义明晰 ≠ 回答问题。

## 六、作者姿态词库（规则 39/45/49/50 合流）

- 谦逊结论：worth trying / promising though uncertain / on balance → 谨慎支持。
- 激情不构成论证：情绪强度与论证质量成反向信号。
- 好作者只求开放心态（consider / remain open），不宣称一锤定音（规则 50「海轮转向」）。
