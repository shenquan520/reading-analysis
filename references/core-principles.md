# 原理内核：阅读分析的通用底层逻辑

> 高考与四六级共用这一套。差异只在篇幅、题材、题型组合、词汇门槛 —— 见 `exam-params.md`。

---

## 一、命题学：选项是怎么造出来的

### 正确项三特征
1. **同义替换（paraphrase）** — 原文换个说法，不是照抄。照抄原文的选项反而要警惕。
2. **概括度匹配** — 主旨题正确项的概括范围正好覆盖全文，不宽不窄。
3. **语气克制** — `may / some / partly / likely / tend to` 命中率显著高于 `must / all / never / always / only`。

### 干扰项六大构造法（核心）

| 类型 | 命题人的手法 | 识别信号 |
|---|---|---|
| **无中生有** | 原文没提，但看起来合理 | 选项里出现原文完全没有的名词或动作 |
| **偷换概念** | 换掉限定词 / 对象 / 时态 / 程度 | 逐词与原文对照，找出被替换的那一个 |
| **以偏概全** | 局部细节冒充整体结论 | 内容原文真有，但只属于某一段某一句 |
| **张冠李戴** | 主体错位，A 做的事安到 B 头上 | 检查动作的**主语和宾语**是谁 |
| **因果倒置 / 强加因果** | 原文是并列或相关，选项说成因果 | 看到 `because / lead to / due to / result in` 就回原文验方向 |
| **程度范围失当** | 加绝对化词，或扩大/缩小范围；**比较级无对比** | `all / never / only / must / every / none` 高危；`more / -er / most / -est` 需回核原文是否有二者对比 |

**排除顺序建议**：先杀无中生有 → 再杀张冠李戴 → 再验因果 → 最后抠程度和限定词。

> **补充：比较级必须回核对比对象**（实战案例）。看到选项含 `more dynamic / better / larger` 等比较级，必须能在原文找到被比较的两个对象；找不到 → 属于程度失当/无中生有。

## 二、定位：回原文找证据

1. **题干先拆**：判题型 + 圈关键词（专有名词、数字、引号词、独特搭配 —— 避免选全文高频词）
2. **题文同序原则**：第 N 题的答案大体落在第 N 段区域（主旨题除外）
3. **定位句 ≠ 答案句**：答案常在定位句的**前一句或后一句**，推断题尤其如此
4. **一次定位失败就换关键词**，别死磕同一个词
5. 找不到定位 → 大概率是关键词选错了，或者这题考的是跨段整合

---

## 三、推断：只推一步

- **推断题 = 原文有据 + 逻辑只走一步**
- **脑补检测**：能不能在原文指出支撑句？指不出来就是脑补，直接排除
- 正确推断常呈**弱化/否定式**表述，而不是斩钉截铁的结论
- 推断题正确项几乎不会是原文句子的原样复述

---

## 四、主旨：串线法

1. **串线**：把各段首句（尤其末段）串起来，得到主线
2. **高频词法**：反复出现的实词 = 主题词，正确项通常包含它
3. **排除三类**：
   - 太宽 — 超出文章讨论范围
   - 太窄 — 只是某一段的细节
   - 偏离 — 抓错了重点（文章讲 A 的成因，选项讲 A 的影响）
4. 主旨题**最后做**，等其他题做完，文章结构已经摸清了

---

## 五、词义猜测：上下文线索

| 线索类型 | 信号词 | 方向 |
|---|---|---|
| 并列 | `and / or / namely / 即` | 同义 |
| 转折 | `but / however / yet / while` | 反义 |
| 解释 | `that is / in other words / 破折号 / 定语从句` | 直接给定义 |
| 举例 | `such as / for example / like` | 从例子反推 |
| 因果 | `because / so / therefore` | 顺着因果推 |

**代入法兜底**：把四个选项逐一代回原句，读不通的直接杀。

---

## 六、长难句：主干剥离

按顺序剥：
1. 去**插入语**（双逗号 / 双破折号中间的内容）
2. 去**从句**（`that / which / who / wh-` 引导）
3. 去**修饰**（介词短语、分词短语、同位语）
4. 剩下 **主语 + 谓语 + 宾语** — 先懂主干，再把修饰一层层挂回去

读不懂的句子先找谓语动词，一个句子只有一个主干谓语，找到它结构就清楚了。

---

## 七、七选五 / 段落衔接

- **代词铁律**：空后若出现 `they / it / this / such`，空前**必须**有它的指代对象
- **连词逻辑**：`however` 前必有可转折的内容；`therefore` 前必有原因
- **复现原则**：正确选项与前后文有词汇复现（原词 / 同义 / 同族词）
- **位置功能**：段首 = 主题句；段中 = 展开或举例；段尾 = 小结或过渡
- **先做确定项**，用排除法缩小范围，别按顺序硬做

---

## 八、观点态度题

- 找**形容词 / 副词 / 评价性动词**，它们是态度的载体
- 注意**转折后的真实态度**（`but` 之后才是作者真正想说的）
- 注意**引号与反讽** — 引号里的词常是作者不认同的
- **优先排除**：`indifferent（冷漠）`、`biased（有偏见）`、`confusing（迷惑）` — 极少作为正确答案
- 中立客观（`objective / neutral`）在说明文中命中率高；议论文里作者通常有明确立场

---

## 九、通用做题顺序

1. 先读题干判题型，**不看选项**
2. 通读文章 — 不求全懂，抓三样：**主题 + 各段功能 + 作者态度**
3. 逐题：定位 → 比对 → 排除
4. 主旨题留到最后做
5. 全部做完后，检查有没有两道题答案互相矛盾（有则必有一错）

## 十、错题归因三分类

每道错题必须归到以下之一，这个分类决定后续怎么补：

| 归因 | 表现 | 补法 |
|---|---|---|
| **定位失败** | 根本没找到证据句 | 练关键词选取 + 题文同序 |
| **词汇卡壳** | 定位找到了，但句子读不懂 | 记进词汇缺口，回词汇系统补 |
| **脑补过度** | 都读懂了，但选了"推理"出去的选项 | 练一步原则 + 脑补检测 |

**不归类的错题等于没改。** 记进 `cases/` 时必须标归因。

## 十一、概括方法讲义提炼的阅读分析要点

> 以下要点来自编者概括方法讲义（），补充到通用做题框架中。

### 11.1 阅读是"解写作"：还原作者的概括过程

- 作者写文章时经历了：分析 → 分类 → 比较 → 抽象 → 综合 → 概括。
- 读者做题时要反向还原：看到材料安排、例子选择、论点提出，要意识到这是概括思维的产物。
- 结构题/主旨题常考的"作者为什么举这个例子""某段作用"，答案往往指向概括思维的某个环节（铺垫、归类、对比、升华）。

### 11.2 小说主旨题：抓情节转折 + 心理变化

- 不能只抓人物表面品质（勤劳、善良、坚韧）。
- 要关注：
  1. 情节转折（如造好台阶后父亲反而失落）。
  2. 人物心理变化（如拥有月亮前后白兔心态变化）。
  3. 作者批判/反思什么（深层主题）。
- 避免"正能量误读"：不要把文本硬套成励志故事，而忽视作者的批判/悲悯立场。

### 11.3 诗歌主旨题：意象 → 归类 → 综合 → 整体

- 步骤：
  1. 充分感知想象（进入诗的情境）。
  2. 意象本质归类（如"风景"=可欣赏的事物，"看"=欣赏感受）。
  3. 部分综合为整体主旨。
- 警惕两类错误：
  - **过度解读**：抓住一个词无限引申。
  - **过度概括**：把具体诗意上升为空泛哲理（如"互相依存相互联系"）。

### 11.4 议论文阅读：论点句是骨架

- 中心论点 + 分论点 + 概括性语句构成文章骨架。
- 概括性语句常出现在段首/段尾，起承上启下作用。
- 反面例子作用：反证中心论点。
- 识别"类比论证"（船/生命、茧/蝶、沙砾/蚌）有助于回答"作者如何支持观点"。

### 11.5 散文/游记主旨：由具体到一般的升华

- 作者常从具体景物、人物、事件出发，逐步抽象到普遍人生道理。
- 阅读时要识别"升华点"：作者从"写这个"跳到"写人生/社会/人性"的位置。
- 比较手法常用来突出事物本质特征。

### 11.6 感知与理性双翼

- 完整阅读分两阶段：
  1. **感性感知**：沉浸式阅读，进入文本情境，获得整体印象。
  2. **理性分析**：分析、概括、推理、判断。
- 两个阶段不能互相替代：
  - 跳过感知直接做题 → 断章取义。
  - 只停留感知不分析 → 主旨模糊。
- 深度感知是准确概括的前提。

### 11.7 语言学习即概括

- 语言学习（语法、搭配、语篇模式）本质是从特殊语料中提炼一般规律。
- 余映潮：语文教师的第一科研能力是提炼能力。英语学习同理。
- 索绪尔：语言学的重要任务是"整理出能够概括一切历史特殊现象的一般规律"。

## 十二、衔接理论教材贡献的衔接元原理（阅读理解的底层视角）

> 以下条目来自 系统功能语言学家 & Hasan衔接理论教材（中译本），任务1 逐页读完后提炼。它们不直接对应某类题型，而是**所有阅读题的底层世界观**——尤其解释"文章为什么读起来连贯/不连贯"。

### 12.1 衔接的定义（全书地基）

- **衔接 = 使某成分的解释依赖于另一成分的语义关系**。跨句子，不是句子内部语法。
- 判断标准：**"这句话里的 X 我要不要回头找别的东西才能懂？"** 要 → 有衔接；不要 → 无衔接。
- 对阅读的意义：七选五、段落排序、指代题——全部在考"能不能看出某成分依赖另一成分"。

### 12.2 语篇 = 衔接 + 语域一致性（缺一不可）

- 语篇是**语义单位**，不是语法单位；长度无限制（一个词"NO SMOKING"到整本书都算）。
- 语篇成立需要两个条件同时满足：**内部有衔接**（五种手段）+ **外部与语境一致**（语域三要素：话语范围/方式/基调）。
- 对阅读的意义：判断"这算不算一段完整的话"，不要只盯衔接词，还要看**话题是否统一**（语域一致性）。

### 12.3 衔接是必要非充分条件

- 有衔接不一定成语篇（机械堆砌连接词也让人觉得"散"）；但**没有衔接一定不成语篇**。
- 对阅读的意义：看到一段"似乎连贯"的文字，先问它靠什么衔接；看到"似乎不连贯"，先判断是缺衔接还是作者有意为之（松散组篇）。

### 12.4 语篇性 = 程度问题（紧密 vs 松散组篇）

- 不是"有/无衔接"二分，而是**密集度问题**。《爱丽丝漫游奇境记》在紧密和松散之间交替。
- 对阅读的意义：**遇到"脱节"段落可能是有意的松散设计**（文学/诗歌尤其如此），不要急着判为"作者写崩了"或"选项错"。

### 12.5 衔接使解码成为可能（全书最核心的实用启示）

- 读者能填补缺失信息，正因为所读内容与语境系统相关。
- **阅读理解 = 靠衔接补缺**。读不懂时，不是去查更多单词，而是去找"这句的 X 靠什么衔接"。

### 12.6 新语篇的判定标准

- **大多数情况下，新语篇开始于一句与上文无衔接之时**。
- 对阅读的意义：划分段落边界、判断"作者是不是换话题了"，看衔接是否断裂。

### 12.7 衔接形式之间非泾渭分明

- 同一词可同时属于多个类别（如 so 可作指称/替代/连接/真值判断）。
- 对阅读的意义：**遇到多义衔接词（so/one/that/the same），判断其功能的决定因素是语境中的具体使用方式**，不是词本身。

### 12.8 特指性 = 衔接的前提条件

- 疑问词（who/what/which）因只要求特指性而不提供特指性本身 → **不能起衔接作用**；能起衔接作用的指示词必须特指。
- 对阅读的意义：看到 who/which 开头的问句，它本身不是回指线索——真正的线索在别处。
