## 零、一句话心法

**阅读题的本质是考关系，不是考单词。**
单词不认识可以猜，关系判错了整段理解就偏了。

### ⭐ 零之零、主次判定：先分层级，不看前后（编者 2026-09-01 裁决）

**核心规则**：
> **遇到逻辑层次丰富的语段，先把上下层级分出来，上层级更主要——而不是看"前"还是"后"。**

**背景**：市面上流传"转折后重要""多个逻辑词最后面最重要"，都是**经验规律**——它们经常成立，是因为作者常用句式暴露意图；但**背后的逻辑不是位置，是层级**。

**操作三步**：
1. **分层**：把语段的信息层级画出来（总/分、主/次、因/果、前提/结论）
2. **定主**：上层级通常更主要（对下层的概括）
3. **验证**：仍受 A017 约束（总句不一定重要）→ **最终回主旨验证**

**反例意识**：
- "转折后重要"在"转折作衔接"时失效（B019）
- "总句重要"在"总句是引子"时失效（A017）
- **位置（前后）永远只是提示，层级才是结构，主旨才是最终裁决**

## 一、三大关系族（三分系统 + 英语映射）

### A. 广义因果族

| 关系 | 汉语标记 | 英语标记 | 阅读考点 |
|---|---|---|---|
| 说明性因果 | 因为p，所以q | because / since / as / so / therefore / thus / hence | **因果方向**是推断题头号陷阱 |
| 推论性因果 | 既然p，就q | since / given that / now that | 前提是事实，推的是结论 |
| 假设 | 如果p，就q | if / suppose / provided that / assuming | 假设≠事实，别当结论 |
| 必要条件 | 只有p，才q | only if / unless / provided | **only if ≠ if**，高频坑 |
| 充分条件 | 只要p，就q | as long as / if | |
| 目的 | p，以便q | so that / in order to / so as to | |
| 结果 | p，结果q | so...that / result in / lead to / give rise to / contribute to | **结果性动词也是因果标记**，别只认连词 |

**因果方向检测**：看到因果标记，先问"谁是因谁是果"。
命题人最爱干的事就是把因果**倒置**（A causes B → 选项写 B causes A）。

---

### B. 广义并列族

| 关系 | 汉语标记 | 英语标记 | 阅读考点 |
|---|---|---|---|
| 并列 | 既p，又q | both...and / not only...but also / as well as / and | 并列项常被选项只取其一 → 以偏概全 |
| 递进 | 不但p，而且q | moreover / furthermore / in addition / what's more / indeed / above all | **重心在后半句** |
| 选择 | 或者p，或者q | either...or / whether...or | |
| 择优 | 与其p，不如q | rather than / prefer...to / would rather...than | **取的是后者** |
| 连贯 | p，于是q | then / afterwards / subsequently / 时间顺序 | 时间线推进，非逻辑推进 |
| 对照 | 不是p，而是q | not...but / rather / instead | 否定前者肯定后者 |

**并列项的完整性检查**：原文列了 A、B、C 三点，选项只说 A → 以偏概全，杀。
原文列了 A、B、C，选项说 A、B、C、D → 无中生有，杀。

---

### C. 广义转折族

| 关系 | 汉语标记 | 英语标记 | 阅读考点 |
|---|---|---|---|
| 转折 | p，但是q | but / however / yet / while / whereas | |
| 让步 | 虽然p，但是q | although / even though / despite / in spite of / while | |
| 假转 | p，否则q | otherwise / or else | |
| 出乎预期 | p，没想到q | unexpectedly / surprisingly / turn out / contrary to | |

#### 让步 vs 转折：阅读的头号分水岭

- **让步（although A, B）**：先承认 A 有一定道理，但 B 才是重点 → A 是次要信息
- **转折（A, but B）**：A 与 B 对立 → B 是重点

**共同铁律：重心永远在后面。**

| 句式 | 作者真正立场 |
|---|---|
| Although A, B | B |
| A, but B | B |
| It is true that A, but B | B |
| While A, B（while 表让步时） | B |

**作者态度题的答案，几乎 100% 在转折/让步之后。**
看到 but / however / yet / although，立刻画线 —— 后面就是答案区。

## 二、句与句：句间关系的三个层次

### 1. 显性衔接（形合）
有连词 / 连接副词 / 关系标记。好认，上面三大族的表就是。

### 2. 隐性衔接（意合）—— 真正的难点
**没有连词，靠语义推断。** 高考和四六级的区分度题大量出在这里。

识别信号：
- 句号断开，但两句主语/话题相同 → 大概率并列或递进
- 后句出现代词回指（this / it / such / they）→ 前句是后句的论述对象
- 前句说现象，后句说原因 → 隐性因果
- 前句正面，后句负面（或相反）→ 隐性转折
- 时态切换（一般过去 → 现在完成）→ 常标志话题推进

### 3. 词汇衔接
- **复现**：原词 / 同义词 / 上下义词 / 同族词（decide → decision → decisive）
- **搭配**：collocation，两个词习惯性共现（make a decision, heavy rain）

**词汇衔接是七选五的命门**：正确选项一定与前后文有词汇复现。

## 三、段内：句子的功能分工

| 功能 | 位置 | 信号 |
|---|---|---|
| **主题句** | 段首居多，偶尔段中/段尾 | 概括性表述，后面跟具体展开 |
| **举例句** | 主题句后 | for example / such as / for instance / take...as an example |
| **数据/引用句** | 主题句后 | according to / 数字 / 研究名 / 引号 |
| **因果展开句** | 主题句后 | because / since / that's why |
| **转折句** | 段中 | but / however / yet —— **后面是作者真立场** |
| **类比句** | 段中 | similarly / likewise / in the same way |
| **对比句** | 段中 | in contrast / by contrast / on the other hand |
| **小结句** | 段尾 | therefore / thus / in short —— 或承上启下 |

**定位题的捷径**：先看句子功能，再看内容。
举例句和数据句**几乎从不是答案**（它们是论据不是论点），论点和态度在主题句和转折句里。

## 四、段与段：段落关系

| 关系 | 信号 | 阅读考法 |
|---|---|---|
| 并列/平行 | 段落结构相似 / Similarly / Likewise / First...Second | 主旨题要**合并**，别只取一段 |
| 递进 | Moreover / Furthermore / What's more | 重心在**后段** |
| 转折 | However / Nevertheless / Yet / But | **重心在后段** —— 主旨和态度常在这 |
| 因果 | Therefore / As a result / Consequently | 前段因，后段果 |
| 总分 / 分总 | 首段总起、末段总结 | 主旨题直接取首尾 |
| 问题—解决 | 提问题 → 分析 → 给方案 | 说明文常见 |
| 现象—解释 | 摆现象 → 给解释 | 科普文常见 |
| 观点—反驳 | 摆他人观点 → 作者反驳 | 议论文常见，**作者立场在反驳段** |

**段落关系的快速判法**：读每段首句，串起来看。
段首句串线不仅能得主旨，还能直接看出段间关系。

## 五、段落与全文：篇章结构模式

先判模式，再取主旨。**模式一判对，主旨题基本送分。**

| 模式 | 结构 | 常见文体 |
|---|---|---|
| **总—分—总** | 总起 → 分述 → 总结 | 最常见，说明文/议论文 |
| **问题—分析—解决** | 提问题 → 析原因 → 给对策 | 社会类、议论文 |
| **现象—原因—影响** | 摆现象 → 析成因 → 谈后果 | 科普、环境类 |
| **观点—论证—结论** | 亮观点 → 摆论据 → 重申 | 议论文 |
| **时间/过程顺序** | 按时间或流程推进 | 记叙文、说明文 |
| **通篇对比** | A 与 B 全篇对照 | 比较类说明文 |

**主旨题排除法（配合模式用）**：
- 太宽：超出模式覆盖范围
- 太窄：只覆盖模式的某一段
- 偏离：抓错了模式（文章讲成因，选项讲影响）

## 六、用这一层重做七选五

七选五考的全是衔接，是这一层的直接应用。

| 空的位置 | 判断依据 |
|---|---|
| **段首空** | 要能概括全段 → 找主题句特征；同时看上段末，做承上启下 |
| **段中空** | 看空前空后一句的关系标记：空后有 however → 空前必须是对立内容；空后有 they → 空里必须出现被指代的复数名词 |
| **段尾空** | 小结本段，或过渡到下一段 → 看下段首句讲什么 |

**三步走**：
1. 划出每个空前后一句的**关系标记词**和**代词**
2. 用关系类型判定该空"应该是什么功能"（转折？举例？递进？总结？）
3. 用**词汇复现**验证：正确选项一定与前后文有词汇呼应

## 七、汉→英：这套知识的三个使用提醒

1. **类型学是通用的，标记词是特定的。**
   书给你的是"该找什么关系"（完整清单），英语给你的是"怎么找到它"（标记词）。
   先有清单，才不会漏掉**没有连词但确实存在**的关系。

2. **英语也有意合，这是区分度所在。**
   别以为英语句句有连词。大量逻辑关系靠语义推断 —— 这正是高考/CET 拉开差距的地方。
   判定口诀：**话题延续 = 并列/递进；话题转向 = 转折；话题溯源 = 因果。**

3. **警惕假标记，见词别急着判关系。**

   | 词 | 常见义 | 伪装义 | 怎么验 |
   |---|---|---|---|
   | while | 当……时 | 然而（让步/对比） | 看前后是否语义对立 |
   | since | 自从 | 因为 | 看后句是不是结果 |
   | as | 当/随着 | 因为 / 尽管（倒装） | 看位置和语义 |
   | for | 为了（介词） | 因为（连词） | 看后面是短语还是句子 |

   **回原文验语义，别见词就判关系。**

## 九、概括方法讲义复句/文段层面的保主舍次规则

> 以下规则来自编者概括方法讲义第四章，用于概括复句、文段时决定"留哪部分、舍哪部分"。与上文三分系统对照使用：先判关系，再按本章规则取舍。

### 9.1 转折关系

- 重心在**转折后**（but / however / yet / 但是 / 然而）。
- 概括时保留转折后内容，转折前降为铺垫。
- 但注意：**形象 → 抽象**的转折（如"不是…而是…"）重心在抽象解释部分。

### 9.2 因果关系

- **现象间单纯"引起被引起"** → 重心在**果**，舍因留果。
- **由浅入深 / 由现象到本质 / 由形象到抽象** → 重心在**因**，舍果留因。
- **推论因果**（既然 p，就 q）→ p 是前提事实，q 是推论结论，重心在 q。
- 段落间因果：保留结果段，舍弃原因段，不可简单累加。

### 9.3 递进关系

- 一般递进：重心在**后一层**（不但 p，而且 q）。
- 衬托递进：被衬托的**主体**是重心，衬托内容可舍。
- 首段递进 ≠ 总分总：不要误把首段递进当成全文总起。

### 9.4 总分关系

- **先总说后分说**：总说句是重心，分说可舍或压缩。
- **先分述后总说**：总说句是重心，分述可舍或压缩。
- 总说句三种处理方式：
  1. **摘录**：原句已够概括，直接取。
  2. **补充**：原句不完整，补充必要信息。
  3. **保主舍次**：原句含主次，保留主干。

### 9.5 条件、假设、目的、选择关系

| 关系 | 取舍规则 | 英语标记 |
|---|---|---|
| 条件 | 条件句是前提，重心在条件推出的结果/观点 | if / unless / only if / as long as |
| 假设 | 假设句是虚拟前提，重心在假设下的结论 | if / suppose / assuming |
| 目的 | 目的状语可舍，保留为实现目的而做的动作/观点 | so that / in order to / so as to |
| 选择 | 择优关系取后者；一般选择需合并两者 | rather than / prefer...to / would rather |

### 9.6 连续概括与范畴

- **连续概括**：对同一对象逐层上升抽象层级（如"苹果→水果→食物→物资"）。
- **范畴**：概括时必须在恰当范畴内，不能越级（如把"苹果"直接说成"物资"就过度）。
- 阅读应用：主旨题正确项的概括层级要与文章范围匹配，不能太宽也不能太窄。

### 9.7 段间关系的概括取舍

- 并列段：合并，找共同上位词。
- 转折段：取后段为重心。
- 因果段：按 9.2 判主次。
- 递进段：取最后一段或最后一层。
- 总分段：取总述段。
- 举例段：例子可舍，取被论证观点。

## 十、衔接理论教材衔接五类型完整体系（系统功能语言学家 & Hasan，骨架级）

> 本章把衔接理论本体合并进语篇关系层。**这是语篇关系层的理论基础**，前三节的三分系统（因果/并列/转折）与本章的衔接体系互相补充：三分系统回答"是什么逻辑关系"，衔接体系回答"靠什么手段实现"。

### 10.1 衔接五类型总览

| 类型 | 本质 | 层次 | 例子 |
|---|---|---|---|
| 指称 Reference | 靠参照他物来解释 | 语义层 | he / this / the / more |
| 替代 Substitution | 语法占位替换语项 | 词汇语法层 | one / do / so / the same |
| 省略 Ellipsis | 零替代，省去可恢复成分 | 词汇语法层 | Yes, I have. / He might. |
| 连接 Conjunction | 通过特定意义间接预设 | 语义层 | but / so / then / however |
| 词汇衔接 Lexical | 靠词汇选择产生衔接 | 词汇层 | 复现 / 搭配 / 概括名词 |

**一句话心法**：指称/替代/省略直接提供"已有的词"（语法关系）；连接通过语义间接预设（语义关系）；词汇衔接靠词汇选择（词汇关系）。

### 10.2 指称

- **四分法**：外指（情景）/ 内指（语篇）→ 回指（向上）/ 下指（向下）。**只有内指才有衔接意义**。
- **三类型**：人称（he/she/it/they）/ 指示（this/that/the/here/there/now/then）/ 比较（same/similar/different/more/better）。
- **the 的中性本质**：不自动携带特指内容，靠语境（语篇或情景）恢复——**the 永远不下指衔接**，典型功能是回指确认。
- **this/that 的距离双轨**：语篇距离（this=说话者说过；that=对话者说过）+ 情感距离（this=近；that=远）。
- **代词消歧铁律**：**语义优先 > 语法（主位-述位）**；前一句主位是最可能的指称目标。
- **it 的延伸指称**：可指代整个事件/过程/现象（不只具体人/物）——阅读理解高频考点。
- **有指称形式 ≠ 有指称关系**：them 可能与先行词不是相同指称；it/this 可能指宾语而非指称。

### 10.3 替代

- **本质**：措词之间的关系（语法层次），与指称（意义关系/语义层次）相对。
- **三类型**：名词性（one/ones/same）/ 动词性（do/do so）/ 小句性（so/not）。
- **one 四身份**：替代词 / 人称代词 / 基数词 / 限定词——判断标准：有无修饰限定 + 是否回指可数名词主词。
- **one 不能替代专有名词**；复合名词中不能用 one/ones 替代。
- **替代词是限定修饰语的载体**：ones 前的修饰语（red ones）往往暗示对比点/新信息。
- **do 六身份**：动词替代词 / do so / 词汇动词 / 概括动词 / 代动词 / 动词小品词。
- **so/not 只替代引述不替代事实**：事实用 that 从句或 it 指称。

### 10.4 省略

- **本质**：零替代；必须有结构预设（前文有相同结构），没有结构预设的"未明说"不是省略。
- **三类型**：名词性 / 动词性 / 小句性。
- **识别铁律**：省略的成分必须能从前文**结构**恢复——不是靠猜。
- **两类省略方向**：词汇省略"从右到左"（省词汇动词）；小品词省略"从左到右"（省助动词/主语）。
- **省略中的极性必须显化**：Yes/No/n't 必须出现，其余可省；极性变化时倾向完整形式。
- **省略不能预设内包小句**（级转位的定语从句），只能预设主从小句。
- **系统变体不是省略**：Simon's playing（the piano）看似省略实则不预设任何语项。
- **小句 = 语气成分（主语+限定）+ 命题成分（动词其余+补语+附加语）**——省略按双模块还原。

### 10.5 连接

- **本质**：通过特定意义间接预设其他成分存在——语义关系，非纯语法关系。
- **⭐ 外部 vs 内部（核心二分法）**：外部=事件之间的关系（客观）；内部=讲话者组织话语的行为/意图之间的关系。**判断"描述事件 vs 推进论证"的元技能**。
- **四大类 × 多层子类**（完整查表工具）：
  - 增补（additive）：and/nor/or/furthermore/in addition/that is/for example/likewise —— 最复杂，10+ 子类
  - 转折（adversative）：but/yet/though/however/on the other hand/in fact/instead/at least/in any case —— 10+ 子类
  - 因果（causal）：so/then/therefore/consequently/because/for/if/otherwise —— 7 类
  - 时间（temporal）：then/next/finally/at once/meanwhile/up to now/to sum up —— 8 类
- **⭐ 转折定义 = "与预期相反"**（不是"相反"本身）；预期来源：内容/交际过程/说话人心理。
- **but = and + however 的合体**：既带并列回溯力又表转折。
- **and 双重身份**：并列结构（men and women）= 结构关系非衔接；句首 and 连接句子 = 增补衔接。
- **接续词六词**：now/of course/well/anyway/surely/after all —— 弱化形式才起衔接作用。
- **语调也是衔接**：降调1=增补；降调4=对比/存疑。

### 10.6 词汇衔接

- **⭐ 概括名词（八大类）**：human/creature/thing/stuff/business/move/place/idea + the = 回指复合体；同时传递回指+态度双重信息。
- **⭐ 复现（reiteration）渐变群**：严格重复 → 同义词 → 近义词 → 上义词 → 概括词 —— 同一语义关系的不同"距离"。
- **⭐ 搭配（collocation）**：两大来源——(1)系统语义关系（反义/互补/有序序列）(2)相似语境共现（laugh...joke / candle...flame）。**搭配是独立于指称的衔接**。
- **词汇衔接独立于指称一致性**：两词不需共同所指就能衔接（boys...boy 也算）——与指称的根本区别。
- **词汇衔接的"微妙性"**：不像 he/the 清晰可判，需参照语境才能确立；每个词都可能成为衔接的一部分但它不自我标记。
- **影响衔接力三因素**：(1)语义系统相关度 (2)项目间距离 (3)总出现频率——封闭类词（the/do/good）高频→衔接力低。

### 10.7 衔接分析代码系统

- **五字母系统**：R（指称）/ S（替代）/ E（省略）/ C（连接）/ L（词汇衔接）。
- **方向距离标记**：直接=0；中介=M[n]（有中介句进入预设链）；远距=N[n]（有中介句不进入预设链）；下指=K。
- **专有名词重复 = 词汇衔接（L1），不是指称（R）**。
- 七篇语篇样品（I-VII）覆盖童话/对话录音/十四行诗/自传/戏剧/访谈/儿童对话——**高考/四六级所有文体类型**。
- 诗歌衔接 = 抽象锚点多层映射（bad thing → solitude/alone/it/pain）；戏剧对白衔接核心 = 省略恢复+外指解歧；转述引语中 I↔he 人称转换不破坏衔接。
