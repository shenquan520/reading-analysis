# B093 二元概念：名词读不出关系，动词才读得出

> **一句话**：两个**名词**摆在一起只能并列；把它们各配一个**动词**，关系才显形。
>
> **口诀**：**两个名词配动词，共同的那个是上位。**

> ⚠️ **来源等级：二级（据逐字稿整理，未核到板书）** —— 判据本身很硬，但**措辞待复核**。

## 一、这是干什么用的

**题干或段落里常出现两个抽象名词并排**：`中国梦 / 自我价值`、`理论 / 实践`、`环境 / 经济`、`社会贡献 / 家庭`。

**只看名词，你看不出它们是什么关系**——像并列，又像对立，还像包含。

**做法：把它们各自改成「动词＋名词」，关系就出来了。**

## 二、怎么做（三步）

### 第一步：给每个词配一个动词

| 名词 | 配上动词后 |
|---|---|
| 中国梦 | **为国家**奋斗 |
| 自我价值 | **为自己**奋斗 |
| 理论 | **在理论中**学习 |
| 实践 | **在实践中**学习 |

### 第二步：找**共同的动词**

- 中国梦 / 自我价值 → 共同动词是「**奋斗**」
- 理论 / 实践 → 共同动词是「**学习**」

**→ 那个共同的动词，就是它们的上位概念。**

### 第三步：用上位概念回答

**题目问"二者的关系"时，答的其实是那个共同动作。**

## 三、★ 判据（用这一条就够）

> **能不能给两个词各配一个动词？**
> - **配得出** → 找共同动词 = 上位概念
> - **配不出** → **这不是二元题**，别硬套

## 四、五个示范（可直接当例证）

| 二元概念 | 各配动词 | 共同动词（上位） |
|---|---|---|
| **理论 / 实践** | 在理论中学习 / 在实践中学习 | **学习知识** |
| **身体健康 / 精神健康** | 保持身体健康 / 保持精神健康 | **保持健康** |
| **环境 / 经济** | — | **可持续发展** |
| **文化 / 经济** | — | **社会发展** |
| **社会贡献 / 家庭** | 奉献社会 / 关爱家庭 | **奉献 / 关爱** |

## 五、为什么这招管用

**名词是"静态的标签"，动词是"动态的关系"。**
**两个标签并排，你只能看出"它们被放在一起"；两个动作并排，你能看出"它们是不是同一个动作的两个方向"。**

**这也解释了为什么抽象题难**：
题目用名词问，作者用动作想。**你把名词还原成动作，就跟作者站到同一个层面了。**

## 六、边界与红线

### ⚠️ 红线 1：配不出动词就不是二元题

**别硬配。**
如果两个词根本配不上同一个动作（比如"苹果"和"正义"），
**那不是二元关系，是硬凑的对子** —— 与 **B090 门槛①「统一本身要条件」**同理：
**没有同一性，就不是一对矛盾。**

### ⚠️ 红线 2：共同动词要"同层"，不能一个吞掉另一个

| 好 | 坏 |
|---|---|
| 中国梦 / 自我价值 → 都配"奋斗"（同层）| 硬说"自我价值包含在中国梦里"（**包含关系不能并列**，见 B094 待建）|
