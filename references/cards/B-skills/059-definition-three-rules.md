# 定义三规则（论证方法手册附录二 · 词义题元方法）

> **一句话**：词义/句意题的底层方法——**词义不明先明确（定义要具体且前后一致）、争议词义从明显例子着手（种属+种差）、定义不能代替论证**。

## 一、规则 1：词义不明时，使之明确

- **词典起手**（好处：中立），但词典定义可能**太宽**（头疼=头部疼痛）或有**歧义**
- 要求：**定义具体且前后一致**
- ⚠️ **警惕劝导性定义**：「堕胎=谋杀婴儿」——论证应证实结论，**不是靠定义假定结论**
- **可操作定义**：把词定义为一套测试/程序（立法「会议」= 足够数量议员聚集讨论法案）——**为特定目的服务的窄定义是合法的**

## 二、规则 2：争议词义，从明显例子着手

**三范畴**：
| 范畴 | 例子 |
|---|---|
| 明显适用 | 麻雀是鸟 ✅ |
| 明显不适用 | 桌子是鸟 ❌ |
| **争议地带** | 鸵鸟/企鹅是鸟？ |

**定义三要求**：
1. 涵盖所有**明显正例**
2. 排除所有**明显反例**
3. **边界划在可解释处**

**方法 = 种属 + 种差**：
> 鸟 = 动物（种属）+ 有羽毛（种差）
> ⚠️ 飞**不行**——鸵鸟不会飞（正例被排除）、黄蜂会飞（反例被包含）

## 三、规则 3：定义不能代替论证

> 「大麻是毒品」（定义层面成立）**推不出**「大麻该不该禁」（需权衡影响的独立论证）

**定义明晰 ≠ 回答问题。**

## 四、⭐⭐ 对英语阅读的价值（做题怎么用）

| 场景 | 应用 |
|---|---|
| **词义题/句意题** | 先判「该词在**本文**的定义边界」，选项偷换定义边界 = **偷换概念**（equivo-cation） |
| **作者立场** | 「作者如何定义 X」是立场泄露点（劝导性定义）——**首段出现 "X means / is defined as" = 论证的地基句，主旨常挂在其上** |
| **推断题** | 「X is Y」类断言 ≠ 「X 该如何对待」——**定义陈述不能直接推出对策选项** |
| **A024 语义五维咬合** | 定义边界 = 外延；种差 = 内涵——定义三规则就是 A024 在词义层的操作化 |
