# 省略（Ellipsis）：零替代

> **一句话**：省略 = 用零项目代替某一项目（"零替代"），与替代本质同一、机制不同——识别省略是找回被"吃掉"信息的关键。

## 一、核心定义（Halliday 第四章）

- **替代**：一个项目代替另一个项目（one / do / so…）
- **省略**：**用零项目代替某一项目**——什么都不放，但结构上留了一个"空位"

**二者本质同一**：都是"语篇内项目间的预设关系"，通常回指；外指省略罕见。
**只是机制不同**：替代有标记词，省略没有（零标记）。

## 二、⭐⭐ 省略的本质特征

1. **省略的语项 = 一个由其他地方语项填充的特殊结构空位**——不是"没写"，是"空着等填充"
2. **底层选项在结构中被省略**——语法上被删，语义上可还原
3. **与替代相同**：都有**预设**（读者知道空位里该是什么）
4. **与替代不同**：没有标记词

**例**：Does Jean sing? — No, but Mary **does**.（does 替代 sing）
→ 若英美口语再省一步："No, but Mary." —— 就是省略（零替代）

## 三、⭐ 对英语阅读的价值

| 场景 | 应用 |
|---|---|
| **回填信息** | 遇到省略结构，先问"空位里被吃掉的是什么"——**向前文找**（通常回指） |
| **指代题** | 省略和替代都是指代题的考查对象——"Mary does" 的 does = 回指 sing |
| **长难句** | 并列结构中的省略（"John likes tea and Mary ___ coffee"）——省略的谓语要从第一分句找回 |
| **七选五** | 选项若含省略结构，它的"填充物"必须能在上下文找到——找不到 = 信息合作未完成（R1 解释原理） |

## 四、英美差异（实用小点）

- 动词词组**只有一个词**（一般过去/现在时）→ 英美都用替代词 does：No, but Mary **does**
- 动词词组**多个词** → 美国人倾向省略形式，英国人可用 do/doing/done

## 五、与其他卡的关系

- **替代总表**（substitution-form-table）：替代有词表，省略没有——两者配套看
- **B013 同一替换**：省略回填时要验证"外延是否同一"（填进去的东西和原项目是否指向同一对象）
- **R1 解释**：省略 = 另一种"信息合作"——作者省略，读者补全，合作完成
