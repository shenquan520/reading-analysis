# 情感极性一致与 also / too / either 的句法约束

> **一句话**：`also / too` 要求前后**同向**（都肯定或都否定），`either` 只用于**否定句**——它们是"情感极性"的语法开关，一句话就能砍掉一半选项。

> **口诀**：**also 跟着走，either 跟着不。**

---

## 一、用法（这是什么）

**情感极性** = 一句话的态度方向（肯定 / 否定、正面 / 负面）。英语里有一批词**自带极性要求**，它们把前后两句的极性**锁死**：

| 词 | 极性要求 | 位置 |
|---|---|---|
| **`also`** | 前后**同极**（前肯后肯，或前否后否） | 句中（be 后 / 实义动词前） |
| **`too` / `as well`** | 前句**肯定** → 本句也肯定 | 句末（`, too`） |
| **`either`** | 前句**否定** → 本句也否定 | 句末（`, either`） |
| **`still` / `even`** | 递进，不改变极性 | — |
| **`nor` / `neither`** | 前句否定 → 倒装接续 | 句首（倒装） |
| **`Instead`** | 前句是被排除项 → 极性**反转** | 见 B006 |

> **判定价值**：这类词是**免费的约束**——不用理解文章，看一眼就知道空处的极性必须与哪一句一致。

---

## 二、考点（命题人怎么动手脚）

1. **极性反了不报错**：填进去读起来"也通顺"，但 `too` 前面是否定句 → 错。
2. **位置陷阱**：`too` 在句中（`Too much…`）不是"也"；`either` 在句首（`Either A or B`）是"二者择一"，不是"也（不）"。**先判词义再判极性。**
3. **跨句极性**：`also` 的参照句可能在**上一段**，不在紧邻的上一句。
4. **隐性否定**：前句有 `hardly / rarely / few / little / without` → 视为否定，后面用 `either` 不用 `too`。

---

## 三、逻辑（怎么判定 · 能照做）

1. **在选项或空后句里扫到 `also / too / either / neither / nor`。**
2. **先确认词义**：是"也/也不"，还是"太/或者"？（看位置：句末逗号隔开 = "也"）
3. **定位它的参照句**（前一句，或跨段的前文同极性句）。
4. **判参照句的极性**（注意隐性否定词）。
5. **约束空处**：`also/too` → 空处与参照句同极；`either` → 空处必须否定。
6. 与 B004（标点）、B006（反向约束）并用。

---

## 四、英语阅读专属提醒

- `also` 在**句首**常作句子副词（`Also, …`），仍要求与前句同向，但语气更接近"补充理由"而非"并列动作"。
- `Me too.` / `Me neither.` 是固定配对，别写成 `Me either.`（口语里存在但考试视为不规范）。
- `not only… but also…` 的 `also` 可省；它强调**后半**，接近递进（见 DESIGN-DECISIONS 八 · 待办 4）。

| 原文空位 | 错误选项（为什么错） | 正确选项 |

## 五点五、⭐ 实战验证记录

### ① `either` 的强度被我定低了 —— 它实际是**一击命中级**

**实例**（2020 北京原文第 (5) 空）：
> 「It **doesn't** have anything to do with ignorant optimism when an individual refuses to notice a problem. **[空]**」
> 7 个选项里**只有 A 含否定词**：
> **A**「It **doesn't** cause any severe emotional discomfort, **either**.」✅

判定链只有两步：
1. 空前句含 `doesn't` → 本句须也是否定（`either` 的极性要求）
2. 扫 7 个选项，只有 A 是否定 → **选 A，零语义推理**

> → **`either` 从 ⭐⭐⭐ 保持为 ⭐⭐⭐，但要加一句：当它被识别出来时，搜索空间通常直接收敛到 1 个。**

### ② `also` 与 `However` 的联合夹击（配合 B006）

见 **B006「联合用法」**：2016 新课标1 第 40 空被 `However` + `also hard` 两头夹住，交集只剩一个选项。

### ③ 本批验证小结

| 词 | 出现位置 | 效果 |
|---|---|---|
| `either` | 2020 北京 (5) | 7 → **1**（一击命中） |
| `also` | 2018 北京 (3) | 定位到 pre-anger 话题 |
| `as well` | 2018 北京 (4) | 确认同极，配合复现锁定 A |
| `also hard` | 2016 新课标1 (40) | 与 However 联合，7 → 1 |

### ④ 拓展场景：开篇现象/问题描述题，先用情感正负过一遍

**实例**（2023 新高考 II 卷 D 篇 ）：
> 开篇 P1 描述负面现象：「access to nature ... becoming harder to find」「unusual to find places ... relatively wild」。
> 选项 A「Pocket parks are now popular」、D「People enjoy living close to nature」均为**正面态度**，与 P1 情感极性相反 → 直接秒排。

**判定步骤（拓展）**：
1. 读 P1，标段落情感极性（本题 = 负面现象）。
2. 扫四个选项，凡是态度方向与 P1 相反的 → 优先杀。
3. 剩余项回原文做精确定位验证。

> → **极性一致不只管 `also/too/either` 这类语法词，也管「段落态度方向 vs 选项态度方向」的宏观一致**（与 B034 四步主旨链、core-principles §八 态度题同源）。本场景补入 case-007。

### ⑤ 进阶场景：推断题「态度分组秒杀」

**实例**（2022 全国乙卷 D 篇 ）：
> 四个选项：A. short-sighted（负） / B. success story（正） / C. benefits manufacturers（正） / D. upsets customers（负）
> 末段态度词：positive influence / healthier / healthy and active / playing its part → 全文**正面**
> 第一步：按正负分组 → A/D 负面，B/C 正面；用全文正面态度**砍掉 A/D**
> 第二步： 已确定 sugar tax 目的是保护儿童健康，不是让制造商受益 → **排除 C**
> 第三步：锁定 B

**判定步骤（能照做）**：
1. 读完文章首尾段，标出全文情感极性（正/负/中性）。
2. 遇到推断题/主旨题，先把四个选项按态度方向分组。
3. 与全文态度方向**相反**的组 → 批量排除。
4. 剩余项再用细节/主题一致性精筛。

> → **把推断题从「全文重读」变成「态度分组 + 细节核验」**，尤其适用于有明显褒贬态度的说明文/议论文。

## 七、⭐ 态度题快速定位

**场景**：阅读理解态度题（作者对 X 的态度 / 作者的态度）。

**判定动作（能照做）**：
1. **看首尾段的情感词**：开头描述现象（负/中性）+ 结尾总结态度 → 态度立场在交集处。
 - 例：P1「feeling like zoo animals, face pressures」+ P5「tired of being famous already」→ 同情（Sympathetic）
2. **区分"同情对象"vs"反对对象"**：态度是针对**对象**（名人）还是针对**现象/事物**（名声）？
 - 同情名人（D Sympathetic）≠ 反对名声本身（C Disapproving）——两者易混，务必分清态度落点
3. **排除与作者立场无关的态度词**：sincere（真诚）/ skeptical（怀疑）常在题支但无关立场，优先排除。

**实例**：
- P1「zoo animals / pressures」+ P5「tired of being famous」→ 作者对名人处境**同情** → D Sympathetic
- 干扰项 C Disapproving 是"反对名声"而非"同情名人" → 排除

**讲义原文**（p346）：「作者对名人是什么态度，要去看文章的首尾段... 开头的'动物园里的动物''面对巨大的压力'，结尾的'他们已经厌倦了成名'... 答案是 D（同情）」

### ⑥ ⭐ 态度极性由「宾语从句内容」决定，不由主句动词决定

**场景**：细节·人物感受题，主句动词是**中性词**（struck / impressed / affected / moved），方向不明。

**实例**（2020 北京卷 C 篇 ）：
> 「But Smith was **struck** mainly by the fact that she **didn't truly grasp** any of the skills the author described.」
> 问：How did Smith feel after reading the French manuscript?
> 选项按正负分组：A. Confused（负）/ B. Impressed（正）/ C. Discouraged（负）/ D. Shocked（负）
> **错误路径**（我闭卷栽的坑）：把 struck 当 impressed（正）→ 选 B。
> **正确路径**：struck 的方向由宾语从句「didn't truly grasp（负向事实）」决定 → 负态度 → 排除 B → 在负向组里找与「能力不足/不会」对应的 = D. Shocked for her own lack of hand skills。

**判定步骤（能照做）**：
1. 主句动词是中性词时，**不许直接赋极性**。
2. 看宾语从句 / 被冲击事实的正负 → 那才是态度的方向。
3. 选项先按正负分组，再进对应组精确匹配。

**⚠️ 双重警示**：本题 B 选项的 detailed instructions 出现在原文 OCR 缺损处（P1 引语），拿**选项词回原文找"复现"** 时若原文文本不完整，复现不可靠——复现是线索不是证据（红线 8）。

**适用题型**：阅读理解·态度题 / 细节·人物感受题；不适用七选五还原。

## ⭐ 负态度细节定位 + 正负并存中间态
1. **负态度细节定位法**：细节题问"问题/危害/影响"→ 在目标段扫**负态度细节**（challenges / died / sacrificed），非负态度信息（位置对但极性不对）先排。
2. **正负信号并存 = Cautious 类中间态**：作者既支持必要性（We need X badly）又警示代价（trade-offs will have to be made）→ 态度题选「小心谨慎/审慎」类；单一极性的 Approving / Disapproving 均装不下双信号。
- **适用题型**：阅读理解·细节题/态度题；不适用七选五还原。

## ⭐ 根因升级

 极性误判（struck），隔壁归因"极性看宾语从句"——**编者归因更根本：词本无意，意由境生**。

**极性误判的根因不是词感，是词义观**：AI 先用了词典常见义（struck=打动→正面），没让语境改写词义。
正确顺序：**先承认"struck 在此文什么意思由语境说了算"→ 语境（didn't truly grasp，负向）重定义 → 极性自动为负。**

极性判断是"词义由语境生"的一个特例——见 **B037 总原则**。

## ⭐ 唯一负态度选项定位
- **规则**：七个选项中**唯一的负态度选项**（hit roadblocks / feel discouraged）→ 对应文中负态度段落（如总结段"道路曲折"）；感情色彩一致性是七选五强过滤器。
- **适用题型**：七选五还原（主）/ 阅读理解态度题。
