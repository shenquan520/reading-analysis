# B085 完形填空·语境优先两遍法（Cloze Context-First）

> **一句话**：先握语境再填词，两遍是本质——首读不填（全文或分段握语境），二遍才动笔；每个空是「语境约束的求解」，不是「我觉得顺」。

## 一、母原理

**A021 藕断丝连·残件还原（词级）**：挖掉的词仍与语境保持联系（搭配/指代/情感方向/逻辑接口），语境残留着对它的约束。**填词 = 求出满足全部接口约束的那个解**，不是凭语感挑个顺眼的。

## 二、核心操作：两遍法（编者 2026-09-04 定调）

**流派之争的裁决**：有老师主张「首读零填空通读全文」、有老师主张「读完本段再填本段」——**分歧只在首读粒度，共识才是本质：语境必须先行**。

- **全文流**（文章简单/情节清晰）：首遍跳空通读 → 全局语境（主题/情节线/作者态度）到手 → 第二遍从头填
- **分段流**（文章难/长难句多）：首遍只读本段（含空前后句）握本段语境 → 填本段 → 下一段
- **共同铁律**：没握语境的空不填。跳过的空首遍标记，绝不硬选

## 三、红线：禁止意淫（编者原话）

**填出的词必须服从原文语境，不能让词扭曲语境**——

- 不是「我觉得这个词顺」，是「原文的接口约束只允许这个词」
- 你脑子里蹦出的第一个「顺」的词，可能是**你的语境**不是**作者的语境**——每填一个，回问一句：这个接口（搭配/逻辑/情感）是原文给的，还是我脑补的？
- 意淫填词 = 破坏语境 → 后续空被你带歪 → 连环错（与七选五两连炸同机制：错一个污染相邻题）
