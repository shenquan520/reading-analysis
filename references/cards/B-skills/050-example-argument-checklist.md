# 举例论证评估五问（规则 7-11）

> **一句话**：作者举例撑论点时，用五问检验例子够不够格——够多吗？有代表性吗？成功率多少？数字有基准吗？有反例吗？

## 一、用法（这是什么）
例证论证的标准结构：**例子 = 前提，概括性结论 = 结论**（讲义叫「底行」）。做题时先把段落还原成这个形式：列出每个例子 + 找出结论句，再逐问检验支撑是否成立。

五问：
1. **孤例不立**——只有一个例子？只能「说明」不能「概括」。
2. **代表性**——例子是最容易想到的（易得偏差），还是自己选进来的（自选样本）？都不算数。
3. **背景率**——只报「命中」不报「基数」？星座应验一次 ≠ 星座可信。
4. **数字陷阱**——有基准线吗？有比较基线吗？精确到 412067 个？外推到荒谬？
5. **反例**——有没有跟结论矛盾的例子？作者加限定词了吗（all → many）？

## 二、考点（考试怎么考）
1. 例证题（B017）问例子作用：考的是「例子 → 结论」支撑关系，不是例子内容本身。
2. 推理题「过强结论」选项：all / must / every / only = 作者没考虑反例（五问之 5），必错。
3. 数字细节题：选项照搬原文数字但偷换基准（50% 毕业率 → 「毕业率高于整体」），考五问之 4。
4. 七选五：例子句 + 概括句相邻出现，概括句常是要补的空。

## 三、逻辑（怎么判定）
1. 找结论句（作者最想让你接受的那句）。
2. 列出所有例子/数据，逐个问：准确吗（前提可靠）？
3. 数例子：1 个 = 说明；少数 = 穷举；大量 = 看样本是否随机、有没有自选偏差。
4. 见数字：找基准线和比较对象；找不到 = 证据不足。
5. 自己想一个反例：能想到 → 结论该加限定词 → 那些把话说满的选项排除。

## 四、英语阅读专属提醒
- 英语议论文惯用「研究/调查/数字」撑论点（research shows...），数字陷阱出现率远高于汉语文章——凡见百分比先找分母。
- 转折词（however / but）之后常紧跟反例或限定，是结论修正的信号。
- 熟词政策：example / case / instance 所在句 90% 是前提不是结论。

## 五、典型干扰项
1. 原文：作者举自己邻居支持办学债券的例子。错误选项：The bond will definitely pass（孤例当通则）。正确选项：The author's neighborhood may not represent all voters（代表性）。
2. 原文：50% 的学生运动员能毕业。错误选项：Athletes graduate at higher rates than before（缺比较基线）。正确选项：The figure alone does not prove improvement。
3. 原文：新闻报道鲨鱼袭击事件。错误选项：Shark attacks are a major threat（背景率缺失）。正确选项：Media coverage makes rare events seem common。

## 七、⭐ 例证型议论文快速定位

- **场景**：议论文中大段讲述一个例子（如父母干预、某个调查），但标题/题干暗示讨论的是更抽象的主题（技术 vs 态度）。
- **规则**：显式例子标志 **"An example at hand / for instance / take X as an example"** → 该段是**例子段，不承载主旨**；主旨在**首段（总论点）与末段（重申）**。
- **判定动作**：
 1. 看到 "An example at hand" 等标志 → 立即标注该段为"例子段"。
 2. 例子段内容只用于细节题（问"调查/例子说了什么"），**不用于主旨/标题题**。
 3. 主旨 = 首段主张 + 末段重申，例子只是其旁证。
- **实例**：P2 开头 "An example at hand" 显式标记父母干预是例子； 答案在 P2 调查内容（父母过度保护），但文章主题 = 技术（非态度）。「虽然文章里面大段地讲述家长...但是文章第二段开头明确地告诉你，这就是个例子」。
- **联动 B017**：例证题问"例子作用"→ 永远指向它服务的主题，不在例子本身兜圈子。

## 八、⭐ 答案必然形态法

- **场景**：例证型议论文的作者观点题/主旨题。
- **规则**：正确项**必须涉及主题（非例子内容）**——例子篇幅再长也不是主旨（本篇 P2-P5 大段讲父母干预，主题却是"技术 vs 态度"）。「第一题的调查可以只涉及父母对子女的态度，这道题的答案则必然涉及技术发展的因素。」
- **判定动作**：1) 锁定主题（首段立论+末段呼应）；2) 检查每个选项是否涉及主题——只涉例子内容的先排；3) 若可见选项全被文章立场否定 → 重新审题（可能漏看选项或选项有缺失）。
- **联动**：B058 12.4 转折段主客观分界（态度在前、技术在后）。
- **适用题型**：阅读理解·主旨题 / 作者观点题；不适用七选五还原。
