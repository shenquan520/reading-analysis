# 转折关系

> **一句话**：转折 = **语义方向不按直线推进，出现拐角**。⚠️"重心在后 / 强调后面"是常见**效果**，**不是定义**。

## 一、用法（这是什么）

### ⭐ 定义（编者 2026-08-31 纠正）

> **转折的定义是「语义方向出现拐角」——不按直线推进。**

三条必须记住：

| # | 要点 |
|---|---|
| 1 | **"重心在后 / 强调后面"是常见修辞效果，不是定义** |
| 2 | 转折**还可以纯粹用于衔接**（连接上下文，不强调任何一边） |
| 3 | 转折两端在**语义层（概括上提后）**是同一层——但**表达层可以不同层**（见下节） |

### ⭐⭐ 表达层级 ≠ 语义层级（编者 2026-09-02 纠正）

**原表述"转折不改变层级"不严谨**。反例：

> 「**虽然**我的叔叔没文化，**但**他能写一手好毛笔字。」

| 端 | 表达层（字面） | 概括上提后 |
|---|---|---|
| 前 | 没文化（抽象判断） | 没文化 |
| 后 | 会写毛笔字（具体事件） | **有文化** |

**转折的真正对立 = 「没文化 ↔ 有文化」——在语义层成立，在表达层看不出来。**

**原理（编者）**：**人表达时会选取恰当的层级来表达——同一件事可以说得更抽象，也可以说得更具体。** 所以判断关系时：
1. 先看**表达层**（字面写了什么）
2. 再**概括上提**，看两端在语义层是不是真对立（A003 层级判定：对象越抽象层级越高）
3. **上提后才判关系**——别被"一端抽象一端具体"骗过去

**做题含义**：转折题选项常把后句**直接用字面**（"会写毛笔字"）当答案，正确答案往往是**上提后的**（"其实有文化/有修养"）。

### ⭐ 补：新旧观点段的干扰项规律

新旧观点段里，But 之后不只是答案区——还意味着**旧观点方成为高频干扰项**（选项直接复述旧观点本身，就是最常见的错项）。

### 英语标志词

- **直转**：but / yet / however
- **让步转折**：although / though / even though
- **假转**：otherwise / or else
- **其他**：nevertheless / whereas / in fact / instead / on the contrary

## 二、为什么重要

- **考点密集区**：作者立场常在转折后
- **但必须警惕**：「转折后是答案区」是**经验规律，不是原理**

> ⭐ **任何"看到 X 就选后面"都是经验规律，不是原理。**
> 它常对，是因为作者选转折句式往往暴露了意图——**但可能被主旨推翻**。

---

## 三、邢福义三分

| 细分 | 标志 | 例句 |
|---|---|---|
| **直转** | …可是… | 这套书很贵，**可是**我也买回来了 |
| **让步转折** | 虽然…也… | **虽然**这套书很贵，我也买回来了 |
| **假转** | …否则… | 这套书很贵，**否则**我就买回来了 |

**假转特别提醒**：`否则` 是**假设性**转折（"如果不是这样，就会…"），不是事实转折。**别当直转处理。**

---

## 四、考点（考试怎么考）

1. **观点态度题**：转折后常是作者真正立场（**但需回主旨验证**）
2. **七选五**：空后出现 however → 空前必须是**对立**内容
3. **词义猜测**：转折 = **反义**线索
4. **层层转折**（讲义编者）：重心在**最后一层**
5. **假转**：otherwise 出现 → 前后是"条件-反结果"关系

---

## 五、逻辑（怎么判定）

1. **找标志词**（but / however / although / otherwise…）
2. ⭐ **回语义验证**：前后**语义上**是不是真的拐了弯？（**连接词只是路标，路标不等于路况**）
3. **判断细分**：直转 / 让步转折 / 假转
4. **若是层层转折** → 重心在**最后一层**
5. **权重判断**：回到**主旨**，不由"这是转折"决定

### ⭐ 关键：连接词的动态功能（A010）

| 功能 | 转折时的表现 |
|---|---|
| **显示** | 关系本来就有，连接词把它显化（**这是常态**） |
| **选示** | 同一对句子可理解为多种关系，作者选了"转折"这一种 |
| **转化** | 作者**主动改写**关系视角（如把时间关系写成转折） |
| **强化** | 标志复现（although...yet）——**不是冗余，是强调** |

---

## 六、典型干扰项

| 干扰项 | 怎么错 |
|---|---|
| 转折前的内容 | 常是干扰，**但不是绝对**——有重心的转折可能重心在前 |
| "转折后就是答案"直接选 | 没回主旨验证，**拿经验规律当原理** |
| 把假转当直转 | otherwise 是假设性转折 |
| 把让步转折当直转 | 让步"先承认再转"，语气不同 |

## ⭐ but 转折反推被转折对象
- **规则**：七选五空后出现 ", but ..." → 填入句内容=**被转折掉的半句**。反推动作：看空前句/小标题（如 Don't rely on technology alone）确定被转折对象（技术），选含该对象的选项拼合（It is easy to... through social media, but...）。
- **适用题型**：七选五还原（主）/ 阅读理解句间关系。

## ⭐ however+majority 反推少数
- **规则**：填入句含 "However, the majority of people..." → 空前文必为**少数人**相关（some individuals are born with...）；some/majority 对偶转折可反向锁定。
- **适用题型**：七选五还原 / 句间关系。

## ⭐ Nevertheless 转折反推
- **规则**：空后 "Nevertheless, not much will change..." → 转折后=没变化（负），转折前=**有变化/有努力**（正）——填句 E "Efforts to improve teaching... have recently emerged."
- **配套**：but 转折反推被转折对象。
- **适用题型**：七选五还原 / 句间关系。

## ⭐ but 的语用学根基：转折 = 颠倒一般推断（2026-09-01 增强，会话 Y）

**出处**：何自然《语用学概论》§3.3.2 规约含意（书 126-127，PDF 145-147）——本卡"语义方向出现拐角"定义的学术支撑：

- **but 是规约含意**（conventional implicature）：非真值条件、不需语境、凭直觉、**不可取消**。它的固定含意是"**出乎意料，与人们的一般推断相反**"。
- **经典例**：*She is poor but honest.* —— 说话的先决是人们的一般推断为"**人穷就不诚实**"；but 颠倒的正是这个默认推断。
- **推论（做题直接用）**：读到 but/however，先自问"**读者按常理会默认什么？**"——被颠掉的默认项就是转折前的语义预期。这与编者"拐角"定义同构：拐角之所以是拐角，是因为默认路径（一般推断）在那里断了。
- **边界**：and（*She is poor and honest*）无此含意——并列不颠倒预期。⇒ 转折标记词的语用效果是**专有的**，不是所有连接词都带"翻预期"功能。

**相关卡**：B075 等级含意（同一章的量级否定规则）、A016 言语行为（第六章来源）。

## ⭐⭐ but+other = 递进非转折
- **规则**：but 与后面的 **other/more** 配合时表**递进**而非转折——"But there is a whole range of **other** health issues... beneficial"（还有很多**其他**益处）前文须正态度"有很多"；同构例：「我们已经遇到了很多困难，但还有更多的挑战」。
- **操作**：见 but 先看后半句有无 other/more/another——有 → 递进判定，前文态度与后半句同向；无 → 常规转折。
- **配套**：转折的定义=语义方向拐角（DESIGN-DECISIONS 纠正二）；本条是"连词功能由语境用法决定"（core §12.7）的实例。
- **适用题型**：七选五还原 / 阅读理解句间关系与态度题。
