# B064 七选五宏观解题总纲（Qixuanwu Macro Framework）

> **一句话**：七选五考两层面——**内容层**（段意一致 + 相邻句延续）与**形式层**（空位功能，六字诀：**概括、承上启下**）。

## 一、内容层面：一致性 + 延续性（讲义内容层面部分）

1. **一致性** = 填入句必须与**段意**一致。段意把握靠：段首总括句 + 段落内部**重复名词**。
2. **延续性** = 相邻两句内容/概念/逻辑有重合（"层叠"感）。靠**相邻句关键词**发现，四类：
 | 关键词 | 要点 | 效果 |
 |---|---|---|
 | 名词/代词 | 名词前后句复现或同义；代词指代须明确（常考 he/they，**you/your 最易忽略**） | 基础 |
 | 连词 | 并列/因果/转折三大关系；并列除 and 外**also 易被忽略** | 明确逻辑 |
 | 形容词/副词 | 填入句与相邻句**感情色彩一致**（正/负态度词） | 出现即难度直降，选项缩到三 |
 | 动词 | **连续动作** + **时态一致**（过去/现在差异必须匹配相邻句） | 出现即难度直降，缩到三选一 |

## 二、形式层面：空位定功能

| 空位 | 可能功能 |
|---|---|
| **段中** | 一定考内容细节 → 盯相邻句内容 |
| **段首** | 全文总括句 / 该段总括句 / 两段间承上启下过渡句 |
| **段尾** | 补相邻句细节 / 总结该段 / 过渡引出下文 |

**六字诀：概括、承上启下**——判断特殊位置空格必查。
