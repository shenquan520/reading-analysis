# 因果关系

> **一句话**：一事为因、一事为果；是说明文和议论文的**骨架**。⚠️ 别一刀切：说明文常考「因」，议论文常考「果」。

## 一、用法（这是什么）

因果 = 前后分句之间存在**原因与结果**的关系。

### 邢福义三分（因果类三细分）

| 细分 | 标志 | 例句 |
|---|---|---|
| **据实说明因果** | 因为…所以… | 因为老师有事，下午我们自学 |
| **据理推断因果** | 既然…就… | 既然老师有事，下午我们自学 |
| **假言推断因果** | 如果…就… | 如果老师有事，下午我们自学 |

### 英语标志词

- **因**：because / since / as / now that / for / due to / owing to
- **果**：so / therefore / thus / consequently / as a result / hence
- **条件型**：if / as long as / provided that
- **目的型**：so that / in order that

### ⭐ 英语 because / since / as / now that 的语用差别

| 词 | 强调什么 | 从句性质 |
|---|---|---|
| **because** | **直接原因** | 常是**新信息** |
| **since** | **已知 / 显而易见**的原因 | 常是**已知背景** |
| **as** | **附带**说明 | 次要信息 |
| **now that** | 既然（已成事实的前提） | 已知前提 |

> **理解作者"为什么选这个词"，能判断语气和重点**（见 A010「选示」）。

---

## 二、为什么重要

- **说明文**：常考「因」（为什么会发生）
- **议论文**：常考「果」（论点及其推论）
- **七选五**：因果常表现为「**问题 ↔ 对策**」配对

### ⭐ 同层级对应原则（七选五专用，A005/A006）— 与因果层级无关

七选五里，因果常是"问题-对策"配对，**两半须过双检：功能对位（谁解决谁方向要对）+ 粒度匹配（宏大对宏大、具体对具体）**——两半不必同层级（A005 配对双检，2026-09-03 神券纠错后改版）

> ⚠️ **澄清**：本节的「同层级」**指的是七选五里「问题-对策」的配对层级**，**不是因果关系的层级**。因果层级由作者选择，不纠结（见 REVIEW/06）。：

| 问题 | 对策 | 判定 |
|---|---|---|
| 宏大问题 | 宏大对策 | ✅ |
| 具体问题 | 具体对策 | ✅ |
| 宏大问题 | 具体对策 | ❌ |
| 具体问题 | 宏大对策 | ❌ |

## 三、⭐ 转因为果

**原书原话**：
> 「有的句子、语段表达呈现出的是**原因**，但表达的**目的是结果**——以原因来引导读者思考结果，因此解读这样的句子、语段要**将原因转换成结果**。」

**例**：《三峡》"重岩叠嶂，隐天蔽日" → 转换为原因"山高、谷窄"

**表层写因、深层是果**——作者写"因"是为了让你推出"果"。

**做题应用**：
- 看到"只呈现原因"的描写句 → 问：它**想让你推出什么结果**？
- 推断题里，作者写现象（因）→ 目的常是让你**理解深层机制**（果）
- ⭐ 这跟"选择层级表达信息"（R2 因果）是一类：**作者用低层级的"因"来表达高层级的"果"**

---

## 四、⭐ 层级归属（✅ 已裁决 2026-09-01）

**神券裁决**：「因果层级不纠结，标准与裁决」——**同层还是跨层都可能**，由作者选择：
> 需要选择适合的层级去表达信息（把高层级的信息用低层级表达得更具体、更生动）。

**做题含义**：不预设因果必须同层或跨层，**具体文本具体分析**——判断重点回主旨。

---

## 五、考点（考试怎么考）

1. **因果题**：定位 because / so / since 等
2. **推断题**：从结果推原因，或从原因推结果
3. **七选五**：therefore → 空前必有原因；because → 空后必有结果
4. **概括**：议论文**丢论据留论点**（论据是"因"，论点是"果"）

---

## 五、逻辑（怎么判定）

1. **找标志词**（because / since / so / therefore / if…）
2. ⭐ **回语义验证**：前后是否真有因果？（**连接词只是路标**）
3. **判断细分**：据实 / 据理 / 假言
4. **看文体**：说明文找"因"，议论文找"果"
5. **权重判断**：回到**主旨**，不由"这是因果"决定

### ⭐ 因果倒置（高频干扰项）

| 干扰项 | 怎么错 |
|---|---|
| **因果倒置** | 把"因"说成"果"，或反之 |
| **强加因果** | 原文无因果，选项硬造 |
| **以偏概全** | 只说了一个原因，忽略其他 |
| **层级错** | 把具体原因说成根本原因 |

## ⭐ As a result 定因果方向（七选五）
- **规则**：空后为 ", As a result, ..." → 填入句=**因**，As a result 句=**果**（如"不留修改空间→没养成划改习惯"）。填入句必须含可产生该结果的原因内容。
- **配套**：core §1 因果方向核验；K004（明确因果链时硬判）。
- **适用题型**：七选五还原（主）/ 阅读理解因果细节题。

## ⭐ 因果概括三型：判据是「作者借谁写谁」（2026-09-06 神券探讨落卡）

「重在果，舍因留果」不是铁律——判据不在因果本身，在**作者借哪半写哪半**：

| 型 | 机制 | 概括处理 |
|---|---|---|
| **①单纯陈述型** | 为告知而陈述因果（现象间单纯引起被引起，无渲染意图） | 舍因留果 |
| **②探本质型** | 由浅入深 / 由现象到本质 / 由形象到抽象 | 舍果留因 |
| **③渲染型（以果显因）** | 写果不为告知果，为侧面烘托因——果只是因的表现形式 | 留因；渲染性的果可弃 |

**例③（编者提供讲义案例 · 高中文言）**：李白《梦游天姥吟留别》「天姥连天向天横，势拔五岳掩赤城。对此欲倒东南倾」——「欲倒东南倾」是果（群山欲倾），但写它只为渲染「天姥山高」这个因。概括重心在因：天姥山高峻凌绝。

⭐ 与转折两功能论（B021）同构：**先判功能（借谁写谁），再判删留**。
