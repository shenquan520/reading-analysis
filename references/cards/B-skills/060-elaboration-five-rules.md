# 详论五规则（论证方法讲义第七章 · 论证的构建过程）

> **一句话**：好论证是"做"出来的不是"写"出来的——**研究话题 → 整理为提纲 → 论证每个前提 → 考虑反对意见 → 考虑替代方案**；阅读时识别这些痕迹，判断作者论证的完整度。

## 一、五规则总表

| 规则 | 是什么 | 对阅读的价值 |
|---|---|---|
| **29 研究话题** | 出发点是话题不是立场；别急着站立场 | ⭐ 双观点/修正型文章：**作者最终立场常是研究后的修正**，不是开头引语的观点 |
| **30 整理为论证** | 白纸写"前提—结论"提纲；第一版往往太单薄 | 判断文章论证是"论断式"还是"论证式" |
| **31 论证每个前提** | 每个前提同时是**需要论证的结论** | ⭐ 读长文时：**区分"论证过的结论"和"未论证的断言"** |
| **32 考虑反对意见** | 主动问"什么最能驳斥我" | ⭐ 让步-反驳段的写作学根源（已入 B053） |
| **33 考虑替代方案** | 证明能解决不够，须证明**优于其他方案** | ⭐⭐ 方案题的判定升级（见下） |

## 二、⭐⭐ 规则 33：方案题的判定升级（最有价值的一条）

**原文**：证明建议能解决问题还不够，必须证明它**优于其他方案**。

**做题应用**：
> 解决方案类文章（problem-solution，B034）——作者方案成立 = ①能解决 + ②**优于替代方案**。
> **只说「能解决」的选项是不完整的正确；比较类选项才有含金量。**

**例**：文章提出 A 方案并说明它能解决问题，但没提 B/C 方案——"A 能解决问题"的选项**不完整**，"A 优于其他方案"的选项**过度**（文章没比较）。正确项通常落在"作者认为 A 能解决问题"的稳妥表述。

## 三、规则 29：修正型文章的立场判断

- 好文章是「被证据说服」的过程（"开始时不知道自己在哪里结束"）
- **阅读**：文章开头的观点 ≠ 作者最终立场——**看作者被什么证据改变了**
- 双观点文章：作者立场常在**研究后的修正处**，不在任何一方的原话里

## 四、规则 31：论证过的结论 vs 未论证的断言

- 好论证是"流动的"——证据可能反过来改前提
- 不是每个前提都要展开（**显而易见的可略**）
- **阅读**：作者详写的部分 = 他认为需要论证的（可能是他的软肋/关键）；一句带过的 = 他认为显然的（常识/共识）
