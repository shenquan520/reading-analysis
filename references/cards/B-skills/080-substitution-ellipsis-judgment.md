# B080 替代/省略衔接判定流程（这到底是替代还是省略？）

> **一句话**：长难句里一个 do/空位/光杆词，按四步判定身份——**有没有预设 → 能还原什么 → 用什么词 → 回指还是下指**。

## 一、四步判定流程

1. **有没有结构预设？** 前文有没有可还原的成分？没有 → 既不是替代也不是省略（可能是省略不当/理解断点）
2. **能还原什么？** 名词 → 名词性替代（one/so）；动词词组 → 动词性替代（do/do so）；整句 → 小句替代（so/not）
3. **替代还是省略？**
 - 槽位**被词填住**（one/do/so）→ 替代
 - 槽位**空着**但结构可还原 → 省略（零替代）
 - ⚠️ "Mary did" 式歧义：did 是替代词还是省略后残留的助动词？→ **看共现语境**：前文有可还原动词词组，did 当替代词读
4. **回指还是下指？** 替代词几乎都是**回指**；下指极少且只在同一句内，**不促成语篇衔接**——衔接题里下指候选直接降级

## 二、do 替代 vs 省略的选择

- **单动词**场景 → 用 **do** 替代
- **多动词**场景 → 美国人倾向**省略**，英国人可用 do / doing / done
- 阅读含义：遇到美式文本多动词句的"空档"，按省略读；遇到英式 do/doing/done，按替代读

## 三、小句替代的共同环境

- 小句替代常出现在**从属/假设**环境：if so / I think so / He said so
- 对比成分在小句之外（由 says/believe 等引述动词提供）
- **事实 vs 引述**：so 只能替代**引述**（reported content），事实小句不能用省略衔接、只能用指称
