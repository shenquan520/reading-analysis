# B056 数据支持段落定位法（Data-Supporting Paragraph Positioning）

> **适用题型**：阅读理解细节题/段落定位题（题干问 "Where can you find the data that best supports...?" / "Which paragraph provides evidence for...?"）
> **一句话**：题干问"哪段数据支持 X"→ 不要逐段精读，直接**扫各段的数据密度**，找含具体数字/百分比/对比的段落，再匹配它是否对应 X。
> **口诀**：**问数据支撑 → 先扫数字 → 再核对应。**

---

## 一、用法（这是什么）

高考阅读中偶尔出现**段落定位型细节题**，不考内容本身，而考"证据落在哪一段"。题干常见形式：

| 题干类型 | 例子 |
|---|---|
| 数据支持 | Where can you find the data that best supports "..."? |
| 证据定位 | Which paragraph provides the best evidence for ...? |
| 例子归属 | The example of ... is given in Paragraph ___. |

这类题的关键不是"读懂每段"，而是**快速识别哪一段含有支撑命题的具体证据**。

---

## 二、考点（命题人怎么动手脚）

1. **把背景段当证据段**：P2 讲总体趋势，看似相关，但无具体数据。
2. **把反向数据段当证据段**：P4 讲某群体"基本不变"，不支持"减少"命题。
3. **把原因/建议段当证据段**：P5 讲限制电子阅读，与"阅读乐趣减少"无直接数据关系。

---

## 三、逻辑（怎么判定 · 能照做）

1. **读题干，明确要支持的命题 X**（通常是文章主题或某个论断）
2. **扫各段首句 + 数字信号**：
 - 含 **percent / % / number / proportion / from...to... / increased / declined** 等 → 高概率是证据段
 - 纯议论/背景/建议句 → 低概率
3. **定位到数据段后，核对数据是否直接对应 X**：
 - 数据方向与 X 一致 → ✅
 - 数据方向相反（如 X 说"减少"，数据说"稳定"）→ ❌
 - 数据只是相关但不直接支撑 X → ❌
4. **排除法**：没有数据的段落通常不是答案。

---

## 四、英语阅读专属提醒

- **不要精读全文再判断**：这类题考的是"定位能力"，不是"理解深度"。
- **数据密度 > 语义相关**：一段话如果和 X 语义相关但没有数字，通常不是"best supports"的答案。
- **注意数据方向**：同样的数据可能支持相反命题（如"基本不变"不支持"大幅减少"）。
- **图表/报告类文章常见**：基于 survey / report / study 的文章，命题人喜欢考"哪段有数据"。

---

## 五、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文 | 错误选项 | 正确选项 | 干扰类型 |
|---|---|---|---|
| P2 总体趋势，无具体数字 | A. In paragraph 2.（**无数据支撑**） | **B. In paragraph 3.**（hardly ever 8%→22% / 9%→27%） | 把背景段当证据段 |
| P4 低龄儿童阅读水平基本不变 | C. In paragraph 4.（**数据方向相反**） | 同上 B | 反向数据段 |
| P5 电子阅读限制原因 | D. In paragraph 5.（**对象错位**） | 同上 B | 原因段当证据段 |
