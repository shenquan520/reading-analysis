# 语境效果三情况：推新 / 证实 / 推翻

> **一句话**：每个新句子对前文只做三件事之一——**推出新含意（论证）、证实旧假设（例证强调）、推翻旧假设（转折驳论）**——关联理论给的句子功能三分类。

## 一、用法（这是什么）

**语境效果**（Sperber & Wilson，何自然书 294-295）：新信息只有作用于听话人现有的语境假设才算关联信息，作用方式恰有三种：

| 情况 | 机制 | 例 | 语篇中的身份 |
|---|---|---|---|
| ① **产生语境含意** | 新信息 + 现有假设 → 推出新结论 | If it rains, I'll stay home. + **It's raining.** → 我会待在家 | 论证链一环、因果推进 |
| ② **加强/证实** | 新信息证明现有假设成立（或加强） | It's raining. + It's raining.（确证） | 例证、数据支撑、重复强调 |
| ③ **矛盾/推翻** | 新信息与现有假设冲突 → 放弃原假设 | It's raining. + **It's not raining.** | 转折、驳论、让步后翻案 |

⭐ 附加：新信息夹带**与语境无关的内容**（"It's raining **and there's grass on the lawn**"）→ 语境效果被稀释、关联变弱 = **枝节信息**，出现在原文但服务不了任何题目。

**底层公式**：**关联性 = 语境效果 ÷ 推理努力**——效果越大越关联，费力越多越不关联。

## 二、考点（考试怎么考）

1. **句子作用/结构题**："The author mentions X in order to..." → 三选一：推结论（支持论点）/ 证实（举例证明）/ 推翻（转折立新论）
2. **主旨题**：第③种情况（推翻）发生处 = 旧论被弃、新论登场 = **主旨切换点**；全文以最后一次"推翻"后的新论为主轴（与 B046 层层否定同源）
3. **细节题**：枝节信息（grass 类）是命题人的"原文有但不用"陷阱——**原文出现 ≠ 与题目关联**
4. **推断题排他性**：原文支持多种解读时，只有一个**最佳关联**解（Coffee would keep me awake 例：想喝/不想喝两套假设，靠关联选一）；干扰项 = 字面一致但关联更差的解读

## 三、逻辑（怎么判定）

1. 定位目标句，写出它**触碰了前文哪个假设**（没有触碰 = 枝节）
2. 三选一判定：
 - 前文假设 + 此句 → **能推出新结论**？→ 情况①
 - 此句给前文假设**供证据**？→ 情况②
 - 此句与前者假设**相反/修正**？→ 情况③
3. 判定后接线：①→向后读（结论在后面）；②→回读论点（论点在此句前）；③→重读后文（新论在此句后）
4. 主旨验证：情况③出现处重估全文主旨是否切换（铁律：以主旨为准）

## 四、英语阅读专属提醒

- **关联假设是阅读的总前提**（书 280）：作者写的每句话都默认"值得注意、足够关联"——**没有无目的的句子**；读不懂时先假设"它有用，是我没找到关联点"
- 议论文（CET 常考）典型节奏 = ①→②→③循环：立论→例证→反驳再立论；每遇到 however/nevertheless 就是情况③的显性标志（但情况③可无标志词，靠语义判定——B019"路标≠路况"）
- 读者的百科信息决定关联寻找难度（重庆人不怕热 / quarter pounder 例）：背景词卡壳时**先建立语境假设再硬猜词义**

## 五、典型干扰项

| 原文结构 | 干扰项手法 | 正确判定 |
|---|---|---|
| 论点 + however + 新论 | 把 however **前**的旧论当主旨 | 情况③后立新论 → 新论是主轴 |
| 论点 + 例证（情况②） | 把例证细节当独立观点 | 例证服务论点，细节题回论点验证 |
| 枝节信息（grass 类） | 用原文原词设"无中生有"邻项 | 原文出现但与题目无关 → 排除 |
| 一句多解（coffee 例） | 两个都字面通的解读都给 | 只有最佳关联解是对的 |
