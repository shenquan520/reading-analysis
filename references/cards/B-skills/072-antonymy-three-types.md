# B072 反义关系三类型与态度题反义信号

> **一句话**：反义不是一种东西——**相反（有程度）/ 互补（非此即彼）/ 关系对立（相互依存）**三类，在文中是态度题、推理题、对比结构的信号。

## 一、三类反义

| 类型 | 定义 | 例 | 判断特征 |
|---|---|---|---|
| ① **相反关系**（gradable） | 有程度差别，**否定一项不意味肯定另一项** | 老 / 中年 / 年轻；hot / warm / cold | 中间态存在 |
| ② **互补关系**（complementarity） | 只有两项，**否定一项即肯定另一项** | 睁开 / 闭着；胜仗 / 败仗；alive / dead | 无中间态 |
| ③ **关系对立**（relation oppositeness） | 两项意义**相互依存**，一方存在才有另一方 | 教授 / 学生；医生 / 病人；buy / sell | 谈 A 必隐含 B |

**序列关系**：同组词项对立但有**固定顺序**——年份/数字序列、十一点→十一点半→十二点。推动叙事/说明的时间线与阶段感。

## 二、考点（考试怎么考）

1. **态度题反义信号**：作者用一个词的反义场（如 *success / failure*、*praise / criticize*）划出态度坐标——识别反义对 = 锁定态度方向
2. **逻辑推理题**：互补关系常出"非此即彼"推断——否定一项即肯定另一项
3. **关系对立 → 相互依存推断**：文中出现 *cadaver / living*、*begin the process / stop beating*（器官移植文本原例），提示 A 与 B 成对出现、互为条件
4. **对比/转折结构**：反义对常横跨 but/however 两侧——反义信号辅助确认"对比"而非"并列"
5. **排序/流程题**：序列词给时间/阶段锚点

## 三、做题应用

- 选项态度与文中反义对的方向冲突 → 直接排除
- 题干问"为什么提到 X"时，若 X 与 Y 是关系对立，答案常落在"与 Y 对照/依存"
- 互补词（not X → X）做推断题时才可"否定即肯定"；**相反词不行**（not old ≠ young，可能 middle-aged）——**这是相反 vs 互补最高频的坑**
