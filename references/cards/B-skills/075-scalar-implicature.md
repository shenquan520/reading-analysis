# 等级含意：选下位词 = 否定上位词

> **一句话**：文中说 **some / often / possible**，作者就是在**暗示不是 all / always / certain**——量级上下来的那一刻，否定已经发生。

## 一、用法（这是什么）

**等级含意**（scalar implicature，Grice 会话含意的一种）：词语按信息强度排成量级，说话人选了量级中**某一个**词，就同时否定了量级里**比它强**的其他词。

| 量级（强 → 弱） | 选弱词的含意 |
|---|---|
| < all, most, many, some, few > | some +> **not** all / most / many |
| < always, often, sometimes > | often +> **not** always |
| < certain, possible > | possible +> **not** certain |
| < must, should > | should +> **not** must |
| < hot, warm > | warm +> **not** hot |

两个关键性质：
- **只否定上位，不否定下位**：some +> not all，但 **some 不否定 few**（"有些人来了"不含"没几个人来"）
- **可取消**：作者自我修正或补充即取消（"I got **some** of it in Hong Kong – um actually I think I got **most** of it there"）

## 二、考点（考试怎么考）

1. **推断题**："What can be inferred?" → 原文 some of the students → 正确项含 "not all students"；陷阱项 "all students are..." 直接违反等级含意
2. **细节题**：把 some 偷换成 all / every / always —— **量级加强 = 必错的经典干扰项**
3. **态度/确信度题**：possible → not certain，作者用 possible 就是在保留不确定性，不能推出 "the author is certain"
4. ⚠️ **反向陷阱**：作者加了 at least / in fact / even 等修正语时含意被取消，此时 "not all" 不成立——先扫有没有取消标记再下结论

## 三、逻辑（怎么判定）

1. 定位句中找**量级词**：some / many / most / often / possible / should…
2. 检查该句或相邻句有无**取消标记**：at least、in fact、even、actually、or even more、if not more
3. 无取消 → 含意成立：所选词**否定量级里它上面的所有词**（some → not most/all；often → not always）
4. 对照选项：凡比原文量级词**更强**的选项（some→all、possible→certain、should→must）→ 排除；**持平或更弱**的 → 保留

## 四、英语阅读专属提醒

- CET 推断题最爱考 <all, most, many, some> 这一级；高考科技文常考 <certain, possible>
- 这条是**有据推导不是猜**：Grice 合作原则的量准则保证——作者若想说 all 早就说 all 了（何自然书 122-125 例 60-63）
- 注意和"命题真假"分开：即使事实上是 all，作者**说** some 就仍是 some 的含意；推断题问的是作者说了什么，不是世界真相

## 五、典型干扰项

| 原文 | 错误选项 | 正确方向 |
|---|---|---|
| Some of the courses are interesting | All the courses are interesting | Not all the courses are interesting |
| It's possible that they were delayed | They were certainly delayed | They may have been delayed |
| The rules should be stored... | The rules must be... | 有义务但非强制 |
| I've completed some of the required courses | He has finished the program's coursework | 还有课没修完 |

## ⭐ 补：虚拟语气 = 反事实（2026-09-02 六级对照批新招）

**could/would have done ... if ... had done** 的句式，说的**不是已发生的事**，而是与事实相反的假设——**事实恰好是它的否定**。

- 例：`could have increased ... if the issue had been addressed earlier` → 事实 = **问题没有早解决**，增长**没有发生**
- **干扰项手法**：把虚拟当作已发生（选项说 "has increased"）→ 必错
- 六级高频，四级 8 篇未见——是六级的语法层升级招
