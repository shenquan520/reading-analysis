# 语句排序（多句重组）· 定序四步法

> **一句话**：**先砍首句（找没有前指件的），再绑死对（代词/关联词/例证），顺着链子排，结尾找结论标记**——干扰项几乎全是"某个衔接件悬空"。

> **口诀**：**先定首，再绑对，顺着链子排，结尾找结论。**

---

## 一、用法（这是什么）

语句排序 = 把 5-7 个打乱的句子还原成段。它考的是**衔接手段的落点**——每个句子身上都挂着若干"衔接件"（代词、关联词、重复词、逻辑标记），**这些件必须能在前文找到落点**。

> 它是七选五的近亲：**七选五是"往文里塞句子"，排序是"把句子排成文"**，底层能力完全一样（B011-B015 + B004 衔接件检验）。

### 三类"顺序链"（排块序时靠它）

| 链型 | 特征 | 例子 |
|---|---|---|
| **事件/时间链** | 动作有先后，**不可倒** | 发现碎片 → 发掘 → 复原 → 鉴定 → 迁徙 → 结论 |
| **程度递进链** | 数字/程度层层推进 | 40 米 → 23 厘米 → 5 厘米（由粗到细） |
| **由表及里链** | 表面现象 → 实际测量 → 本质 | 明亮通路 → 实际粗 1-40 米 → 发光部分 23 厘米 → 结论 |

---

## 二、考点（命题人怎么动手脚）

1. **指称件悬空**（最高频）：把带 `这具头骨` 的句子排到"头骨"首次出现**之前**。
2. **结论标记错位**：把带 `怪不得 / 可见 / 由此可知` 的句子排到**开头**。
3. **层级倒置**：把总观点句压到段中，把断言句抬到首句。
4. **关联词悬空**：`但是 / 因此 / 实际上 / 例如` 前面没有可承接的句子。

---

## 三、⭐ 定序四步（能照做）

### 第 1 步 · 定首句

**找"无前指件"的句子**——能独立站立的才是首句：

| 排除条件 | 例 |
|---|---|
| 含代词（`这 / 那 / 它 / 其 / 此 / 这种`） | ⑥「**这**是每一个名家读书的共同心得」→ 不能首 |
| 含承接副词（`可是 / 但是 / 因此 / 于是 / 实际上 / 最后 / 甚至 / 例如`） | ⑤「**可是**，现在图书的体量越来越大」→ 不能首 |
| 含"也 / 还 / 再 / 又"（需前文有同类） | → 不能首 |
| 是**举例 / 展开 / 结论** | ③「**例如**，王国维的《人间词话》」→ 不能首 |

> 若首句拿不准，用**选项反推**：四个选项里出现最多的首句，优先验证它。

### 第 2 步 · 找绑定对（主力武器 · 秒级）

三种**死绑**，绑上就不可拆：

1. **指称绑定**：`这具犀牛头骨` 必接"首次提到头骨"的句子；`其他三种` 必接"列出三种"的句子。
2. **成对关联词**：`可是 / 但是` 要求前句存在且语义相反；`实际上` 要求前句是"表面印象"；`因此` 要求前句是原因。
3. **例证标记**：`例如 / 比如` 要求前句是**断言/概括**（例子不能证例子，B017）。

### 第 3 步 · 排顺序链

按第一节的三类链，把绑好的块排成序。**链的方向由内容决定**（时间先后 / 数字大小 / 表里层次）。

### 第 4 步 · 定尾 + 验证

- **结论标记必在尾**：`怪不得… / 可见 / 由此可知 / 这就是为什么 / 总之 / In short`。
- 把选项代回**读一遍**，检查每个衔接件都有落点。

## 四、英语阅读专属提醒

- 英语排序题（CET4/6 的段落排序、高考的六选五排序）里，`This / These / Such + N` 和 `However / Therefore / For example` 的绑定力比中文更强，因为英语**形合**，衔接件必须显性落点。
- 英语常考 **时间状语链**：`In 1978… → Two years later… → By the 1990s… → Today…`，看到就按时间排。
- 注意 `the + N` 的**回指定指**：`the head` 意味着前句必须已提过 head。

## 五、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文 | 错误选项（为什么错） | 正确选项 |
|---|---|---|
| 西藏披毛犀六句（2019 浙江） | **A. ⑥④③①⑤②** —— ④「**这具**犀牛头骨…被复原」排在 ③（首次提到头骨）**之前** → `这具` 悬空 | **B. ⑥③④①②⑤** —— 发现碎片⑥ → 发掘③ → 复原④ → 鉴定① → 迁徙② → 结论⑤（`其他三种` 有落点） |
| 闪电五句（2020 联考） | **D. ②⑤③①④** —— ②「**怪不得**我们常说'瘦成一道闪电'」放**首句**，结论标记错位 | **A. ④①③⑤②** —— 现象④ → `实际上`①（40 米）→ `但是`③（23 厘米）→ ⑤（5 厘米）→ 结论② |
| 读书贵于精六句（2021 浙江） | **C. ①③⑤④②⑥** —— ⑥「**这**是…共同心得」的"这"指到 ②（字多），语义不通 → 指称落点错 | **B. ④⑥⑤②①③** —— 观点④⑥（"这"指"读书贵于精"）→ `可是`⑤② → `例如`①③ |
