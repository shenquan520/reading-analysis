# 明褒实贬：弦外之音的推断

> **一句话**：当话语**表面衔接不上**或**答非所问**时，别判错——那是**弦外之音**，要靠**语境 + 语用常识**推断。

## 一、思想源流

- **出处**：语篇语言学家语篇理论教材第九章例 [9.2]
- 理论依据：**连贯（coherence）依赖语境信息与语用知识**（见 A012）
- **记录**：编者（2026-09-01）

---

## 二、⭐ 经典例子

> **A: How did you like the performance?**
> **B: It was a nice theatre.**

| 层面 | 内容 |
|---|---|
| **字面** | B 说"剧场不错" |
| **实际** | B **回避**了"表演怎么样"这个问题 |
| **推断** | 剧场好 ≠ 表演好 → B 在**明褒实贬**：表演不怎么样，只是客气地说场地还行 |
| **需要什么** | 语境（剧场 vs 表演的差别）+ 语用常识（回避问题 = 不想给正面评价） |

**这就是"衔接弱但连贯"**——A 听得懂，因为共享语境和语用知识。

---

## 三、为什么重要

**"答非所问"在阅读理解里是高频考点**，而且命题人**就爱考这种**：

| 题型 | 怎么考 |
|---|---|
| **推断题** | "What does B imply?" → 答：表演不怎么样 |
| **态度题** | "B's attitude toward the performance is…" → 答：不甚满意 / 敷衍 |
| **句意题** | "It was a nice theatre" 在文中的含义 → 答：委婉的负面评价 |

**如果只按字面理解 → 必错。**

---

## 四、⭐ 推断步骤（四步）

| 步 | 操作 |
|---|---|
| 1 | **看问题是什么**：对方问/上文要的是什么信息？ |
| 2 | **看回答给了什么**：实际提供的是不是那个信息？ |
| 3 | **找偏差**：给了什么**别的**？为什么给这个而不是那个？ |
| 4 | **推断意图**：结合语境与语用常识，推出言外之意 |

### 常见偏差类型

| 偏差 | 可能的言外之意 |
|---|---|
| **答非所问**（问表演答剧场） | 回避 → 不愿给正面评价 |
| **只说次要的** | 主要的不好，只好说次要的 |
| **过度客套** | 实际不满 |
| **轻描淡写** | 实际严重 |
| **转移话题** | 不愿谈 / 有隐情 |

---

## 五、⚠️ 两个注意

### ① 不是所有"不通"都有深意

先排除：是**我没看懂衔接**，还是**真有弦外之音**？
- 用 B026 无标连接的方法先检查语义关系
- 确认衔接确实弱 → 再考虑连贯层面的推断

### ② 推断要有依据，不能乱猜

> 推断必须**基于语境和语用常识**，不是凭感觉。
> 检验：把推断结果代回，看整段是否**说得通**。

---

## 六、与「功能观」的呼应（A005）

弦外之音本质上是**功能的错位**：
- 字面功能：评价**剧场**
- 实际功能：**回避评价表演**（= 委婉的负面评价）

> **问功能，不问内容**（B024 的口诀在这里同样适用）。

---

## 七、做题怎么用

1. **遇到"奇怪"的回答/句子** → 别跳过，标注出来
2. **问：它在回避什么？**
3. **用四步法**推断言外之意
4. **代回验证**：推断结果让整段通顺吗？
5. **选答案**：选那个**推断出来的**，不是字面那个

## ⭐ 格赖斯机制：为什么有弦外之音（2026-09-01 增强）

本卡推断四步的**理论根基**（何自然语用学教材第三章，书 101-143）：

### ① 弦外之音 = 公然违反合作原则的产物

说话人四准则（量：信息足量 / 质：真实有据 / 关系：有关联 / 方式：清楚简炼）总体被遵守；**说话人公然违反某条准则且让听话人察觉时，他仍在合作——弦外之音就藏在违反处**。

| 偏差类型（本卡第四节） | 对应违反的准则 | 书中经典例 |
|---|---|---|
| 答非所问 | 关系准则 | 问"有女朋友吗"答"他每周末开车去纽约" |
| 只说次要的 / 信息不足 | 量准则 | 推荐信只夸"英语好、出勤好" → 不宜聘用 |
| 轻描淡写 | 质准则 | "a little intoxicated" → 酩酊大醉；反语 "a fine friend" → 坏朋友 |
| 过度客套 | 质准则（守礼貌） | "Not at all. This is the least I could do." |

### ② 推导的完整版（Levinson 六步，书 134）

四步法第 1-2 步的理论依据：**先假设作者/说话人合作（说的每句话都有目的），字面与语境的落差处就是要推的含意**。六步：S 说 P → 假设 S 合作 → S 要合作又说 P，必想表达 Q → 双方都清楚须假设 Q → S 无法阻止听话人想 Q → S 意图让听话人指 Q。

### ③ 两条做题铁律

1. **不可分离性**：含意依附内容+语境，**同义替换去不掉**——"Jack is a genius" 换成任何近义说法仍是反语。⇒ 句意题选项改写后含意消失的 = 干扰项。
2. **命题真假 ≠ 含意真假**：即使原文没证实命题，含意照样成立。⇒ 推断题别用"原文没说是真的"否决含意推断。

### ④ 文化差异警告

准则有文化相对性（马达加斯加人习惯保留信息）。**跨文化题材里人物"答得含糊"可能只是文化规范，别一律读成负面态度**。

## 九、⭐ 理论互证（接受美学家，2026-09-01 增补）

- **「靠不住的叙述者」**（接受美学家接受美学著作书 245–246，布特命名）：叙述者不可信，因「他的评价不再是暗隐的作者视点的代表」——本卡的学理命名与出处。
