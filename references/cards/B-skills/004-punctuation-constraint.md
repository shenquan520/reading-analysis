# 标点与句法形式约束（七选五第零步过滤器）

> **一句话**：**先看空前后的标点，再看内容**——逗号 → 空处必是从句/半句；句号 → 空处必是完整句；破折号/冒号 → 空处必是解释或清单。**形式不符的选项直接划掉，一个字都不用读。**

> **口诀**：**逗号填半句，句号填整句，破折号填解释。**

---

## 一、用法（这是什么）

七选五的空**不是语义填空题，是完形填空题**。空前后的**标点**已经把答案的**语法形状**定死了一半。

| 空后标点 | 空处必须是什么 | 反例（一看就错） |
|---|---|---|
| **`，` + 小写主句** | 从属分句 / 状语短语（`When…` `If…` `Although…` `By doing…`） | 填完整句 → 逗号拼接错误（run-on） |
| **`，` + 大写主句** | 也可能是**连接副词**衔接，优先按从句找 | — |
| **`.` 后接新句** | **完整句**（主谓齐全，能独立成句） | 填 `If you're…` / `When you…` → 残句 |
| **破折号 `—`** | 解释、同位、举例（常是名词短语或完整句） | 填与前文无关的新话题 |
| **冒号 `：`** | **清单**（后面必跟并列项） | 填抽象论断 → 冒号无着落 |
| **问号 `？`** | 设问/反问 → 下句**必须作答** | — |

> ⚠️ **这是过滤器不是判定器**：形式过滤通常能砍掉 2-4 个选项，剩下的靠功能/层级定（B024 第二步、第三步）。

---

## 二、考点（命题人怎么动手脚）

1. **半句陷阱**：命题人故意放一个**内容完美但语法是完整句**的选项，等你看内容对就选（case-001 第 (1) 空的 F）。
2. **逗号误判**：看着像逗号，其实是**前一句的句末逗号**（如 `fertilizers (肥料). [38] However,`），此时空处要能接 `However` 的**转折前提**。
3. **残句诱饵**：`If…` / `When…` 开头的选项**内容很对**，但空后是句号 → 不能选。

---

## 三、⭐ 第二条过滤器：衔接件悬空检验（判多余项专用）

拿到一个选项，**先看它身上挂了什么"需要前指的形式件"**，再回原文找落点。**找不到落点 → 判多余。**

| 前指件 | 需要什么 |
|---|---|
| `And` / `Also` / `So` / `However`（句首） | 需要一个可并列 / 可承接的上一句 |
| `another` / `other` / `others` | 前面必须已出现过**同类事物** |
| `this` / `that` / `these` / `such` / `the + N` | 前面必须有明确先行词 |
| `it` / `they` / `them` | 前面必须有可回指的名词（注意单复数一致） |
| `This knowledge` / `This skill` / `Such + N` | 前面必须真的讲过那个"知识/技能" |

> **这比"读一遍感觉内容沾不沾边"快，而且可复核**——你能指着原文说"它前面没有 X"。

---

## 四、逻辑（怎么判定 · 能照做）

1. **看空后第一个标点**，按第一节表给候选选项做**语法分堆**。
2. **划掉形式不符的**（不用读内容）。
3. **对剩余选项逐一看"身上挂的前指件"**，回原文找落点；找不到 → 划掉。
4. **剩余 ≤2 个** → 交 B024 第二步（问功能）/ 第三步（同层级对应）定夺。
5. **回填读一遍**，确认标点读起来顺。

## 五、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文空位 | 错误选项（为什么错） | 正确选项 |
|---|---|---|
| 「…get work done. **（1）**，there are several ways…」（空后逗号） | **F.** It might seem unkind to cut people short when they interrupt you.（内容沾边，但**完整句 + 逗号** = 语法不成立） | **B.** When you want to avoid interruptions at work（从句，形式对 + 总起功能对） |
| 「…make good use of it. **（5）**.」（空后句号） | **D.** If you're in the other person's office or in a public area（**残句** + 缺 door 的落点） | **G.** Leave it open when you're available to talk and close it when you're not（完整句 + it=door） |
| 全文多余项 | **E.** Gardening is **another** great activity for helping kids develop **this skill**.（`another` 与 `this skill` **双悬空**） | — |
| 全文多余项 | **B.** **And** we can't forget science education.（`And` 无并列对象） | — |

## 六、英语阅读专属提醒

- 中文讲义里这条叫「**半句话没说完的都要说完**」，英语里更硬：英文**不允许逗号连接两个完整句**（comma splice），所以"空后逗号"这条约束在英语里是**语法硬规则**，不是经验。
- 破折号 `—` 在英语七选五里常引出**举例清单**（`—music, acting, drawing, building, photography`），看到它就直接找带**上位词**的选项。
