# 宏观结构：叙述五段 / 问题解决四段

> **一句话**：故事和问题型文章都有**固定骨架**——先找到骨架，细节自动归位。

---

## 一、Labov 1972：叙述语体结构（五段）

**来源**：Labov 1972

> 叙述是**重现过去的经验**，方法是**语言的小句序列与实际发生的事件序列配合**。

**五段结构**：

| # | 段 | 内容 | 是否必有 |
|---|---|---|---|
| 1 | **梗概**（abstract） | 开头叙述故事前往往有一个梗概 | **任意** |
| 2 | **走向**（orientation） | 确定**时间、地点、人物、情景** | 通常有 |
| 3 | **叙述过程**（complication） | 一般用**过去时**，按**时间顺序**介绍 | ✅ 必有 |
| 4 | **结尾**（coda） | 一个任意的结尾正式示意叙述终了 | **任意** |
| 5 | **评估**（evaluation） | 指出叙述的**角度和理解** | 通常有 |

---

## 二、Hoey 1983 / Jordan 1984：问题解决模式（四段）

| # | 段 | 内容 |
|---|---|---|
| 1 | **情景**（Situation） | 背景 |
| 2 | **问题**（Problem） | 出了什么事 |
| 3 | **解决**（Response/Solution） | 怎么办 |
| 4 | **评估**（Evaluation/Result） | 结果如何、怎么评价 |

**在剧本或小说中的变体**：
> **背景和展示 → 复杂化 → 解决 → 结局**

---

## 三、⭐⭐ 为什么这是"叙述文最强框架"

原话要点：
> 「**叙述文/故事类阅读的最强框架**——任何故事都按『梗概/背景/过程/结尾/评估』组织，或『情景—问题—解决—评估』。读故事先找到这四/五段，结构就清晰了。**这是阅读『找主旨』『理结构』『预后文』的硬功夫。**」

**三个直接用途**：
1. **找主旨** → 主旨通常在**评估段**（作者的态度和理解）
2. **理结构** → 四/五段一划，段落关系立现
3. **预后文** → 知道现在在第几段，就知道下一段该是什么

## 四、⭐ 与已有体系的对应

### ① 与「结构化推进」（A009）的关系

| | 结构化推进 | 宏观结构 |
|---|---|---|
| 层级 | **段落群**内部 | **全篇** |
| 举例 | 总句说"有 ABC"→ 下面讲 ABC | 情景—问题—解决—评估 |
| 性质 | 推进方式之一 | **推进方式的整体蓝图** |

**宏观结构是结构化推进在"全篇"尺度的具体形态。**

### ② ⭐ 「评估段」= 主旨所在

**这是最实用的一条**：

| 框架 | 主旨落在哪 |
|---|---|
| Labov 五段 | **第 5 段——评估**（指出叙述的角度和理解） |
| Hoey 四段 | **第 4 段——评估**（结果如何、怎么评价） |

**为什么**：**评估是作者跳出故事做判断的地方——那就是他的意图。**

**⭐ 跟主次三原则完全一致**：评估段对主旨贡献最大，**权重最高**。

### ③ 与「功能观」（A005）的关系

每一段都有**功能**：
- 情景段 = **引入背景**（B016 功能清单里的一类）
- 问题段 = **提出问题**
- 解决段 = **主体**
- 评估段 = **点明主旨 / 升华**

**宏观结构 = 篇章尺度的功能分配。**

## 五、做题怎么用

### ① 记叙/故事类阅读：先划骨架

读完第一遍，先标出：
```
[情景] 第 1-2 段
[问题] 第 3 段
[解决] 第 4-6 段
[评估] 第 7 段 ← 主旨大概率在这
```

### ② 主旨题：优先看评估段

- 评估段的**评价性语言**（形容词、情态动词、转折后判断）就是答案线索
- **回到主次三原则**：评估段权重最高，因为有主旨

### ③ 七选五：看空缺在第几段

- 空缺在**情景段** → 应该选背景信息
- 空缺在**问题段** → 应该选"出了什么事"
- 空缺在**解决段** → 应该选"做了什么"
- 空缺在**评估段** → 应该选**评价性**内容

**⭐ 这跟 B024 七选五的「同层级对应」是同一套**：
> **段的层级对了，功能方向还要对。**

### ④ 说明/议论类也有对应结构

虽然本框架针对叙述文，但**问题—解决**模式在说明文极常见：

| 段 | 内容 |
|---|---|
| 现象 / 问题 | 提出某个现象或问题 |
| 分析原因 | 为什么 |
| 解决办法 | 怎么做 |
| 评价 / 展望 | 效果如何 |

**这是高考说明文、CET 阅读的高频结构。**

## 六点五、⭐ 补充：两种靠"形式"就能抓的宏观结构（2026-09-01 实战补）

> 原卡讲的是**语义层面**的宏观结构（情景—问题—解决—评估）。
> 实战里还有两种**纯形式**的宏观标记，看到就能用，**不用先读懂内容**。

### ① 段落排比（无连接词的同构并列）

**长什么样**：连续 2-5 个段落**结构同构**（同样的句法骨架、同样的展开顺序），段落之间**有没有 Secondly/Thirdly 都无所谓**。

**实例**：
```
段2：观点句(A) → 操作序列（道歉→解释→改期）
段3：操作句（set hours）→ 观点句(E) → 结果句（It can help…）
段4：条件句(D) → 比较句（更容易脱身）
段5：指令句（make good use）→ 操作句(G) → 验证句（If someone knocks…）
```
四段**都是"一条对策 + 它的展开"**，没有 Secondly / Thirdly / Finally——**靠结构同构维系并列**。

**判定价值**：
- 段落排比 = **"这几段互为同层并列"** 的形式证据（但**权重仍由主旨定**，见主次判定三原则）
- 若某段缺了"对策句"，那一段的段首/段中空就是**补对策句**的位置（配合 B007）
- 若某段多出一个"总结句"，它多半是多余选项的藏身处

> **讲义原话**（七选五讲义第 7 条）：「**形式大于内容：句式排比；段落排比；and, or, but 并列的部分形式一致**」

### ② 总—分—总的「首尾呼应定位法」

**长什么样**：开头提一个判断，**结尾用另一套说法复述同一个判断**（常带 `这就是…的原因` / `这就是为什么…` / `总之`）。

**判定动作（可照做）**：
1. 读**首句**和**末句**，各圈出 1-2 个实词；
2. 看这两个实词是不是**同一语义**（原词 / 同义 / 上义）；
3. 是 → **主旨就在首尾两句的交集上**，四个选项里找那个"能同时罩住首尾"的。

**实例**：
```
首：含量基本上保持恒定 ← 因为处于"边增长、边消耗"的动态平衡
分1：增长 80% + 20% ｜ 分2：消耗 75% + 5%
末：这就是多年来…0.03% 始终保持不变的原因
```
首句「恒定 / 平衡」↔ 末句「保持不变」= **同一语义** → 主旨 = **平衡** ✓
→ 干扰项 B（来源）只覆盖分 1，D（消耗）只覆盖分 2，A（含量）是引子层。

> **一句话**：**总—分—总的结构，主旨就在首尾句的交集上。**

## 六点六、⭐ "四步主旨操作链"——写作对象→文体→主题→末段验（2026-09-01 实战补）

> 讲义在讲义（2023 全国甲卷 D 篇《人与自然》）的解题思路里给出一条**可照做的 4 步链**，用于"先定主旨，再做主旨题"。原话是「①关注文章的写作对象→②关注文章的文体和写作目的→③区分重要信息和次要信息→④末段重要信息一定与全文主题主旨高度一致」。这条链的颗粒度（4 步）比"六大构造分类"对做题者更友好。
>
> **出题方材料验证**：讲义解题思路部分。

### ① 第一步：写作对象（写给谁？为谁说话？）

- 看首段开头的人称/对象词（"your teen"/"Willie Sutton"/"grizzly bears"/"the author"）
- 区分**第一人称 I/we**（作者自述）vs **第二人称 you**（面向读者）vs **第三人称 + 专名**（介绍对象）

### ② 第二步：文体与写作目的

| 文体 | 写作目的（讲义表格） | 主旨题的答案方向 |
|---|---|---|
| **说明文**（事实/研究） | 介绍事物特点/研究结论 | 主旨=研究结论/事物本质特征 |
| **议论文**（行为/意识） | 教育读者 / 引起重视 | 主旨=作者立场（"应该 X" / "X 值得关注"） |
| **应用文**（广告/指南/记事） | 吸引购买 / 提供帮助 / 讲个人感悟 | 主旨=该应用文的功能 |
| **记叙文**（记事/写人/心理） | 通过事件讲感悟 / 塑造人物 | 主旨=感悟/人物品质（防正能量误读） |

### ③ 第三步：主题词（反复出现的实词 + 写作对象的上义词）

- 扫全文找**重复 3 次以上**的实词（grizzly bears / Americans / humans）
- 找写作对象的**上义词**（grizzly bears → nature / wildlife；Willie Sutton → criminals）
- 主旨 = 主题词 + 作者对它的态度/动作

### ④ 第四步：末段验（最关键的一步）

- 末段含主题词的同义/反义/操作化表达 → 主旨题答案在这
- 末段是收束段（态度/建议/展望）→ 主旨题答案=主题词 + 态度
- **末段主旨题（题干含 last paragraph）** → 直接去选项找主题词的同义（B036）

### ⭐ 主旨统摄排除法（讲义的"一刀切"用法）

> 讲义在 排除 B/C 时直接说「B 选项"应该留在公园里"和 C 选项"有很高的科学价值"**均为背离主题的选项**」——主题一旦确定，**所有题型的干扰项都可以先用"是否服务主题"过一刀**。

**操作**：
1. 主题确定后，把四个选项挨个过"这个选项讲的是不是主题？"
2. 偏题的（B/C 背离"人与自然"）→ 直接杀
3. 剩下的（A/D 沾边）→ 再用细节/因果/偷换等微观构造精筛

**这条与六大构造的关系**：六大构造是**微观精筛**；主题一刀切是**宏观预筛**。**做题时先宏观后微观**，不要一上来就硬归六大构造——这是典型的步骤重问题。

## 六点六、⭐ 说明文「设问开头」模式

**结构**：首段以问句（Can / Will / What / How ...）提出一个现象/问题 → 后文**必给出肯定/具体答案**，并解释「为什么」或「怎么样」。

**判定价值**：
- 问句本身往往**包含全文核心元素**（写作对象 + 关键效果）。
- 后文所有段落都是对这个问题的回答 → 抓住问题 = 抓住主旨。

**实例**（2022 全国乙卷 C 篇）：
> P1 问：「Can a small group of drones guarantee the safety and reliability of railways and ... save billions of euros each year?」
> → 核心元素：drones + railways + safety + save money
> → 后文 P2-P4 分别回答：可行（类比高压电线）、省钱（维护成本）、未来功能（预警）。
> → 标题题、 功能题都可用这一核心元素快速定位。

**操作**：看到首段问句，立刻圈出 2-4 个核心实词；做题时反复用它们过滤选项。

## 六点七、⭐ 段落主旨题的双约束

**规则**：段落主旨题的正确项必须同时满足：
1. **段落内最重要信息**（常为转折后/评价句/段末句）
2. **与全文主题密切相关**（段落是全文的一部分，不能偏离主题）

**判定动作**：
1. 读段落，标出最重要信息（but/however 后、评价性句子、段末句）。
2. 把选项与该信息匹配，先排除明显不沾边的。
3. 剩余项再问：「这个选项讲的是不是全文也在讲的东西？」偏题项再杀。

**实例**（2022 全国甲卷 D 篇 ）：
- P1 最重要信息：but 后「it is the harbor that makes the city」
- 全文主题：城市新旧并存/保留传统
- 选项 C「The key to Sydney's development」既对应 harbor makes the city，又对应全文城市发展主题 → ✅
- A/B/D 均为 P1 细节，且与全文主题关联弱 → ❌

> 「段落主题必然是段落内部最重要的信息；段落主题必然吻合全文的主题。」

## 六点八、⭐ 段内分层定位

**场景**：细节题定位到某一段，但该段很长，包含背景、关键信息、引用等多重信息。

**判定动作**：
1. 用题干关键词给段内句子分层：
 - **直接相关层**：含题干关键词或同义表达
 - **间接背景层**：铺垫信息，可略读
 - **引用/例证层**：重要性天然低一级（讲义：人物话语引用重要性低一级）
2. 优先在「直接相关层」找答案；找不到再向下扫。

**实例**（2022 全国甲卷 C 篇 P3）：
- 第一层：After taking a degree ... traveled the world ... taught in Japan and Chile（学位/环球背景 → 间接）
- 第二层：in Chile she discovered ... last-minute cheap deals on ships going to Antarctica（直接相关 → 答案 C）
- 第三层："I just decided I wanted to go ..."（人物引用 → 可略读）

> → **分层定位避免被长段淹没**，尤其适用于高考 D/C 篇的复杂段落。

## 六点九、⭐ 中文注释附近找答案

**场景**：高考英语阅读真题中，命题人会给部分生词加中文注释。这些注释词不是随意加的——**它们往往与某道题直接相关**。

**判定动作**：
1. 扫全文中文注释，圈出注释词。
2. 看哪个注释词与某道题干关键词同义或相关。
3. 优先在注释词所在句/段找该题答案。

**实例**（2022 全国乙卷 D 篇 ）:
- 题干关键词：drinks companies
- P4 中文注释：「制造商」= manufacturers
- manufacturers 与 companies 直接对应 → 答案就在 P4 第一句「had their sugar levels cut by manufacturers」→ D「reduced their products' sugar content」

> 「在阅读理解中所有给注释的词，都是与解题有密切关系的词，这也就解释了为什么正确答案的对应信息往往在中文注释附近。」

**注意**：此法是**速判信号**，不是绝对规则——找到注释词后仍需回原文验证。

## 六点十、⭐ 研究类文章「also confirmed」= 支持证据段

**场景**：研究类说明文的段落主旨题。

**规则**：段落首句若含 also confirmed / further supported / consistent with / in line with 等，通常提示该段是对前文研究结论的**支持证据**。

**判定动作**：
1. 看到 also confirmed 等标记，立即标注该段为「支持证据段」。
2. 段落主旨题优先选含 supporting evidence / evidence / confirmed the findings 的选项。

**实例**（2022 新高考 I 卷 D 篇 P5）：
- P5 首句：「Analyses of a language database also confirmed that there was a global change ...」
- → 段落主旨 = supporting evidence for the research results → 选 A

> 「你首先需要想的问题反而是：文章里有这么多段，为什么命题者要问第五段的主旨呢？当然是第五段有重要的信息提示值得考查主旨了，所以相对于整段话的具体内容，我更希望你注意到段落开始的『also confirmed 也证实』，答案就直接选 A 选项了。」

## 六点十一、⭐ 文体四排除 + 议人/假物 + 历史变迁

### 6.11.1 文体四排除
- **场景**：题目问文章出处/文体时，**反向排除三种文体 → 兜底第四种**。
- **四排除清单**：
 | 选项 | 排除信号 |
 |---|---|
 | **新闻报道** | 无开头导语（"According to ..." / 时间地点要素）、无客观时效事件 |
 | **短篇小说** | 无时间顺序（once upon / then / later）、无人物情感变化 |
 | **研究文章** | 无科学依据（study/research/data）、无实验方法描述 |
 | **书评/读后感** | 三种排除后的兜底 + 看 P1（故事=重点）+ 看末段（短=主题）|
- **实例**：四选项 = news report / short story / book review / research article → 讲义明示"新闻报道不见开头导语，短篇小说不见时间顺序，研究文章不见科学依据" → 排除 A/B/B（重复）→ 选 C book review
- **实例**：四选项 = diary / guidebook / novel / magazine → 排除 A/B/C（叙事类/应用文/小说）→ 选 D magazine（新事物说明文常见出处）
- **讲义要点**：「文章是读后感...出现'我的'的文章往往是记叙文和写作文...新事物类说明文常见于杂志」

### 6.11.2 议人 vs 假物
- **场景**：开篇段落描述"现状/背景/问题" → 暗示作者如何解决
- **两种解决模式**：
 - **议人** = 对人提要求/给方法/调动主观能动性 → **议论文**
 - **假物** = 通过技术/工具解决问题 → **说明文**
- **判定动作**：
 1. 看 P1 末句或 P2 开头动词 → 找"propose / call on / urge / require"（议人）vs "come up with / develop / design / create"（假物）
 2. 全文后续 = 议论文（观点冲突）or 说明文（技术介绍）
- **实例**：「Researchers from Georgia Tech say that they have come up with a low-cost device」→ "come up with" = 假物 → 说明文
- **讲义要点**：议人 = 对人提要求、给方法、调动主观能动（议论文走向）；假物 = 用实际技术或工具有针对性地解决问题，并重点介绍事物的特点与作用（说明文走向）。说明文」

### 6.11.3 新事物 vs 旧事物长期共存 → replace 类选项不合理
- **场景**：题干问"新发明的目的是什么"，干扰项含 "replace / 替换 / 取代"
- **判定**：新事物一定和旧事物**长期共存**（不是替代关系）→ 排除 "replace" 类选项
- **实例**： C "To replace the password system" → 错误（智能键盘和密码系统共存，不是替代）
- **讲义要点**：新事物与旧事物长期共存——所以 replace（替换）这类选项不合理。

### 6.11.4 历史变迁类
- **场景**：描述过去某事物从 A 状态变为 B 状态的"变迁/演变"
- **标志词**：`but / however / revolution / change all that / transform / shift` 等转折 + 变化
- **结构**：被标志词切成**前后两部分** → 前 = 旧情形 / 后 = 新情形
- **判定动作**：
 1. 找标志词 → 标记前后分界
 2. 前半段找"旧状态"，后半段找"新状态"
 3. 主旨 = "从旧到新" 的变迁过程
- **实例**：「But the revolution that was taking place in the 1830s would change all that」→ 切前后 → 旧（昂贵+枯燥+受众单一）/ 新（penny paper 廉价+大众）
- **讲义要点**：文章分成前后两半：前半写旧情形（旧报纸三大问题——贵、枯燥、受众单一），后半写新变化恰好逐条对应这三点。

### 6.11.5 事实类说明文段位错位反模式
- **场景**：题干指定段落段位 → 选项内容却在**另一段**（如题干 P1，选项 P2 内容）
- **判定动作**：
 1. 题干明确指段 → 标段位
 2. 选项内容**段位不符** → 立即排除（不必细看）
- **实例**：（题干 P1）+ A "They produce oxygen"（P2 内容）→ 段位错位 → 排除
- **讲义要点**：「制造氧气」只是第二段的内容细节，与题干所问不符。

### 6.11.6 说明文/议论文经典"表面现象—背后原因"逻辑
- **场景**：段落含**"现象" + "because/therefore/in order to"**结构 → 现象在前，原因在后
- **判定动作**：
 1. 找 `because / in order to / for the purpose of / so as to` 等标志词 → 标注"原因链"
 2. 题目问"为什么 X" → 直接找 because 后的原因
- **实例**：P3 现象（leaves/branches 不接触）+ 原因（to prevent the spread of diseases / make life more difficult for leaf-eating insects）→ 答案 = C "For self-protection"
- **讲义要点**：表面现象（枝叶互不接触）之后，接的不是原因就是应对办法——现象与原因/办法的相邻关系是命题点。

### 6.11.7 过去-现在对比型事实说明文：时间标志 + 时态切换
- **适用题型**：阅读理解主旨题 / 结构题 / 细节题（事实类说明文）
- **场景**：文章描述一个**从过去到现在持续变化的现象**（如语言数量减少、环境变化、技术演变）
- **标志词**：
 - 显式：`at present / today / now / in recent times / nowadays / currently`
 - 隐式：**时态切换**（P1-P2 一般过去时 → P3-P4 一般现在时）
- **判定动作**：
 1. 扫各段首句，标时间词/时态
 2. 找到"现在"锚点 → 它前面是"过去"，后面是"现在/结果"
 3. 主旨 = 变化趋势（从 A 到 B），不是单纯"描述过去"或"描述现在"
- **主旨题陷阱**：选项若说 "make a comparison / compare A and B" → **往往是手段不是目的**；对比只是作者呈现变化的写法，正确答案要指向变化趋势或变化原因
- **实例**：
 - P3 首句 "At present, the world has about 6,800 languages" → 现在锚点
 - P1-P2 过去时（was populated / started settling / became）→ 过去段
 - P3-P4 现在时（has / is / are）→ 现在段
 - 主旨 = 语言数量从过去到现在持续减少 → C "Human development results in fewer languages"
- **讲义要点**：「现在」一出现，就是过去与现在的对比，结构立刻清晰；对比是手段不是目的——主旨题里 make a comparison 这类选项常是错的。

## 六点十二、⭐ 问题型议论文主旨题：正确选项常指向「问题反面 / 解决方案」

**场景**：议论文先抛出某个问题（problem）并分析其危害/原因，末段不直接给解决方案，但主旨题选项常把「问题的反面」或「隐含呼吁」作为答案。

**判定动作**：
1. 识别 P1 核心论点：「X is a significant problem」
2. 扫全文：作者是否给出明确解决方案？
 - 若给出 → 主旨 = 解决方案
 - 若未给出 → 主旨 = **问题的反面**（即应该避免 X / 转向与 X 相反的方向）
3. 选项中找同时满足：① 含主题词同义 ② 方向与问题相反的项

**实例**：
- P1 论点：「short-termism is now a significant problem in industrialised societies」
- 全文分析危害与心理原因，末段无显性建议
- 主旨题 正确项 A「Far-sighted thinking matters to humans」= 问题「short-termism」的反面「far-sighted / long-term thinking」
- 「主题是‘短期主义是个大问题，只有从短期变长期才能解决问题’，所以 A 选项‘有远见的思考对人类很重要’是解决问题的关键」

> **一句话**：问题型议论文的主旨题，答案往往不在原文原句，而在**「如果问题成立，人应该怎么做」的反向推导**。
