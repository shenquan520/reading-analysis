# 邻近配对：对话的基本单位

> **一句话**：对话不是一句句说的，是**一对对**说的——**第一部分制约第二部分**。

---

## 一、概念与五特征

**提出**：Schegloff & Sacks 1973

**定义**：轮次之间存在有机结合的**成对结构**。

**常见配对类型**：

| 第一部分 | 第二部分 |
|---|---|
| 问 | 答 |
| 给与 | 接受 / 拒绝 |
| 问候 | 问候 |
| 埋怨 | 申辩 |
| 陈述 | 确认 |
| 请示 | 指示 |

**⭐ 五特征**：

1. 涉及**两个语段**
2. 两语段**相邻近**
3. 由**两人分别**说出
4. **第一配对在第二之前**出现
5. ⭐ **第一部分制约第二部分**（**可选回答的范畴有限**）

---

## 二、案例

| 例 | 第一配对 | 第二配对 |
|---|---|---|
| [10.7] Joyce | "It's Stephen, sir."（**请示**） | "Let him in. Let him in."（**指示**） |
| [10.8] | "Why, Sir?"（**问**） | "Because she never let them in."（**答**） |
| [10.9] 雷雨 | 鲁贵："你看着管过你啦。走吧，跟太太说一声……"（**指示**） | 四凤："知道，忘不了。"（**确认**） |
| [10.10] 雷雨 | 四凤："你连叫我都不敢叫。"（**埋怨**） | 蘩漪："所以我要离开这儿呢。"（**申辩**） |
| [10.11] 雷雨 | 蘩漪："今天晚上我预备到你家里去。"（**提出**） | 四凤："不，我今儿回来。"（**拒绝**） |
| [10.6] | "Good day, Mr O'Rourke." | "Good day to you." |

## 三、⭐⭐ 做题怎么用（这是最强的对话题工具）

### ① 预测下一句

**原话要点**：
> 「这是阅读对话题的**最强工具**——能**预测说话人下句会说什么**。」

**操作**：
- 听到**问** → 下一句应该是**答**
- 听到**请求** → 下一句应该是**接受或拒绝**
- 听到**埋怨** → 下一句应该是**申辩**

**七选五/补全对话**：看空缺前一句属哪种第一部分，**第二部分的类型就被限定住了**。

### ② ⭐ 判断对话是否"完整/合理"——**发现潜台词**

原话要点：
> 「**五特征是判断『对话是否完整/合理』的标准。**」
> 「阅读中遇到**不完整的配对**（如不答、答非所问），**多半是潜台词——蕴含义或态度信号**。」

**⭐⭐ 这是本卡最值钱的一条**：

| 现象 | 潜台词 |
|---|---|
| **该答不答**（问了不回应） | 回避、抗拒、心虚 |
| **答非所问** | **回避话题**（呼应 B027 明褒实贬） |
| **用另一配对类型回应**（问→反问） | 质疑、不接受前提 |
| **延迟回答** | 犹豫、为难 |

**例子**（曹禺《雷雨》[9.4]）：
> 甲：四凤！甲：四凤！
> 乙：喝，真热。

**该应答而不应答**（叫名字应回应，却说天气）→ **回避** → 潜台词靠情景语境补（A014）。

## 四、⭐ 与「预示力」配合

**预示力（predictive force）**：
> 「读对话/语篇时**主动预测每句话的交际功能**（要求/提供/问候/抱怨），**预判能力决定阅读速度**。」

**这是阅读速度的核心变量**：
- 不会预判 → 被动接收每个词
- 会预判 → 提前缩小可能性范围

**⭐ 这跟 B024 七选五法是同一套动作**：
> 看到空缺 → 判断它该是哪种交际功能 → 选项里只留符合的

## 五、与其他卡的关系

| 卡 | 关系 |
|---|---|
| **A014 语境三层** | 不完整的配对靠**情景语境**补出含义 |
| **B027 明褒实贬** | 答非所问 = 偏差 = 潜台词（**同一现象的两个描述**） |
| A012 衔接≠连贯 | 配对是**连贯**（交际层），不是衔接（形式层） |
| B024 七选五 | 配对类型限定选项范围 |
| B016 句子功能清单 | 配对的第一部分就是**功能** |
