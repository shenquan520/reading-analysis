# B083 选项位置判别（主张 · 结果 · 机制）

> **一句话**：干扰项最爱用「原文出现过的词」——先问这个词在原文因果链里站在**主张位、结果位还是机制位**；**位置错，词再熟也错**。

## 一、为什么立这张卡（病灶统一）

CET 对照批 5 篇 9 例的统一病灶：**正确项与最强干扰项共享原文词汇，区分点全在「结构位置」**。

| 出处 | 干扰项 | 错法 |
|---|---|---|
| 实战案例 -B | genetic diversity | **结果**冒充主张 |
| 实战案例 -D | messy nature | **机制**冒充功能 |
| 实战案例 -A | new concept | **所属对象**被换 |
| 实战案例 -C | hormones for dominance | **下游效果**冒充原因 |
| 实战案例 -A/C | 不学乐理者→乐迷 / subtle 挪位 | **所属对象**被换 |
| 实战案例 -E | 同一研究的 E 段 | **研究设计**冒充研究结论 |
| 实战案例 -K | 同一专家的 K 段 | **话题切分**错位（同人跨段） |
| 实战案例 -C / -C | 吸收快 / 缺纤维升风险 | **方向**相反 |

| # | 类 | 错法一句话 |

| 1 | **因果链位置** | 结果冒充主张、机制冒充功能、下游效果冒充原因 |

## 二点五、三位置判定法（核心操作，遇到选项带原词时必查）

| 位置 | 是什么 | 常见错位 |
|---|---|---|
| **主张位**（结论/论点） | 作者要证明的那句话 | 把结果、机制、例证拿来当主张 |
| **结果位**（因果链末端） | 被主张推出/导致的东西 | 结果冒充主张（-B 型） |
| **机制位**（怎么发生的） | 中间过程、手段、设计 | 机制冒充功能/结论（-D 型） |

**操作**：
1. 选项出现原文词 → **别高兴**，这是干扰项最常用的伪装
2. 回原文找这个词在因果链里的**位置**
3. 问题干要的是哪个位置——不一致 → 排

## 三、与既有卡的分工

- **B052 推理边界**：管「越界」（推得太多）；**本卡管「错位」**（位置不对）
- **B013 指称**：管「对象是谁」（发出者/承受者）；**本卡管「位置在哪」（主张/结果/机制）**——配合用
- **B035 同义排除**：管「语义等价互排」；**本卡管「原词伪装」**
- **A003 信息层级**：位置判别的理论基础——主张=层 1，结果/机制=层 2
