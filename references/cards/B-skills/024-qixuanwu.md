# 七选五（五步法）

> **一句话**：七选五的本质是**判断空缺处的功能**——它该起什么作用，反推它该是什么；**层级对了不够，功能方向也要对**。

## 二、⭐ 五步法

### 第零步（2026-09-01 实战补）：⭐ 形式过滤 —— 先砍一半，再谈功能

> **原来的五步法一上来就问"这段是哪种推进"，太重了。**
> 实战证明：七选五的**第一道筛子是形式，不是语义**——而且**不用读内容就能做**。

按顺序过三把筛：

| 筛 | 动作 | 挂卡 |
|---|---|---|
| **筛 1 · 标点** | 看空后第一个标点：逗号→从句；句号→完整句；破折号→解释；冒号→清单 | **B004** |
| **筛 2 · 空后信号词** | `Instead`/`Or`/`But`/`By doing`/`It`/`them`/`例如` → 反过来规定空处长什么样 | **B006** |
| **筛 3 · 衔接件悬空** | 选项身上挂的 `And`/`another`/`this skill`/`This knowledge` 在原文找不到落点 → **判多余项** | **B004 第三节** |

**⚠️ 全局约束（原卡完全漏了）：选项互斥。**
7 选 5 = 每个选项最多用一次。**已确定的选项立刻从候选池划掉**，且可以用"剩余空数 vs 剩余选项数"互证——剩 5 空、剩 5 项时，就是一一对应，不能再犹豫。

### 第一步：判断这段是哪种推进

| 推进方式 | 特征 |
|---|---|
| **自然流动** | 对象靠语义场关联（图书馆→书） |
| **空降式流动** | 对象本无关联，靠**关系词**开凿支流（草莓→橘子） |
| **结构化推进** | 按篇章结构走（总句说"有 ABC"→ 下面按顺序讲） |

**结构化推进最好判断**——看空缺在结构中的**位置**就知道它该是什么。

### 第二步：⭐ 问"这个空缺该起什么功能"

用 B016 的 16 种功能表：

| 位置 | 可能的功能 |
|---|---|
| 段首 | 总起 / 引入 / 承接上文 |
| 段中 | 论证 / 举例 / 转折 / 解释 |
| 段尾 | 总结 / 升华 / 引出下文 |
| 两段之间 | **承上启下** |

> **问功能，不要问内容。**

### 第三步：⭐ 同层级对应（编者的核心原则）

空缺常与上下文形成**配对**，两半须过**双检（功能对位+粒度匹配，见 A005 配对双检原则）**——两半不必同层级：

| 配对关系 | 两半必须同层 |
|---|---|
| **问题 ↔ 对策** | 宏大问题↔宏大对策；具体问题↔具体对策 |
| **现象 ↔ 解释** | 宏观现象↔宏观解释 |
| **观点 ↔ 例证** | 例证的抽象度要匹配观点 |
| **总说 ↔ 分述** | 分述之间互相并列同层 |

> **宏大问题 + 具体对策 = 错配，直接排除。**

### 第四步：看复现，但别迷信复现

| 情况 | 判断 |
|---|---|
| 复现的是**主干**对象 | 强线索 |
| 复现的是**枝干**对象 | **弱线索，可能是干扰** |
| 没复现，但**对得上功能** | **仍可能是答案** |

> **复现用来排除很有效；用来确认要小心**（A006 六点六）

### 第五步：验证（回到语义和主旨）

1. 代入读一遍通不通？
2. **连接词只是路标**——选项有 but，要检查前后**语义上**是不是真拐弯
3. 是否符合**主旨**？

## 三、⭐ 三句口诀

> **1. 问功能，不问内容。**
> **2. 层级对，还要方向对。**
> **3. 复现是线索，不是证据。**

---

## 四、典型陷阱

| 陷阱 | 长什么样 | 怎么破 |
|---|---|---|
| **内容对，功能错** | 讲的事是对的，但放这儿起不到该起的作用 | 回到第二步问功能 |
| **层级对，方向反** | 同层级，但"带动者"填成了"被带动者" | 看功能方向 |
| **枝干复现** | 复现了一堆次要对象，看着很像 | 问：主干还是枝干？（A006） |
| **关系词误导** | 选项有 however，但前后语义没拐 | 回语义验证（A010） |
| **宏大配具体** | 上文宏大问题，选项具体对策 | 同层级对应（第三步） |

---

## 五、为什么这套比"看连接词"强

市面上教的是"空后有 however 就选对立内容"——**这是经验规律**。

**五步法的优势**：即使**没有连接词**（无标连接）也能做——因为你看的是**功能和层级**，不是标志词。

## 六、## ⭐ 选项语义分析清单（2026-09-02 编者补充）

七选五分析**选项**时，逐选项做两套检查：

### ① 语义多维对照（A024 扩展版）

| 维度 | 查什么 |
|---|---|
| 对象（主体/承受者） | 选项谈的对象跟段落对象是不是同一个？换了对象=错位 |
| 情感色彩 | 褒贬方向与段落一致吗？ |
| 程度 | all/some/most 的范围词与原文匹配吗？ |
| **时间** | 时态/时间状语与上下文时间线一致吗？ |
| **空间** | 地点/范围词有没有被偷换？ |
| **特殊要素** | 金钱、数字、专有名词等"硬信息"——出现必回原文核对，是强约束线索 |

### ② 句型 → 功能信号

| 句型 | 功能预判 |
|---|---|
| **祈使句** | 多半是**提对策/建议**——配"问题—对策"结构的空 |
| 疑问句 | 引出问题/过渡——配段首或转折位 |
| There be / 定义句 | 引入新概念——配首次提及位 |
| 概括性陈述（对象为抽象概念） | 高层级信息——配主旨/总结位（A003 层级判定规则） |

> 维度对照管"内容对不对得上"，句型功能管"位置合不合适"——两个都过才放进空。

## ⭐ 全局回读校验（作答流程级 · 2026-09-04 实战立项）

**七选五五空共享选项池——逐题做对不等于全对，交卷前必须全局回读**：

1. **唯一归属检查**：每个选项只归一个空——若某选项"既像这题又像下题"，说明其中一题的归属错了（真题实证：正确答案被先排掉，选中了下题的答案，两连炸）
2. **连贯通读**：五空填完后**把全文连读一遍**——任何一处"读着卡"都说明有错位；七选五填对后全文是丝滑的，卡顿=错位信号
3. **铁律**：这步是**检查动作，不依赖状态**——晕着也能走。高考状态波动不可控，程序防线才是最后保险（同 B084 规则 8 哲学）
