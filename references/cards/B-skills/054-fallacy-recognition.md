# 论证谬误速查（Fallacy Recognition · 干扰项原型库）

> **一句话**：谬误 = 违背正确论证规则的误导性论证——阅读题的错误选项大多是某条谬误的化身，认识谬误 = 认识干扰项。

## 一、用法（这是什么）
韦斯顿附录一列了 21 项常见谬误，阅读题里最高频的 8 个：
1. **人身攻击**（ad hominem）——攻击人而非论证。区分：质疑专家资质（合法，规则 14）≠ 因立场否定其论证（非法）。
2. **诉诸群众**（ad populum）——「每个人都这么做」当证据。
3. **诉诸无知**（ad ignorantiam）——「没人证明错」当「对」。
4. **肯定后件 / 否定前件**——两种非法演绎：q 成立→所以 p；非 p→所以非 q。本质 = 忽略其他原因/路径。
5. **假二难**（false dilemma）——只给两个对立选项（要么爱国要么出国），第三条路被藏起。
6. **稻草人**（straw man）——把对方观点歪曲得更容易反驳再打倒。
7. **偷换概念**（equivocation）——同一个词先一个意思后另一个意思（男女「平等=相同」→「平等=同权利」）。
8. **复述结论**（mere redescription）——「催眠功效」= 帮入睡；前提是结论换皮，无独立理据。

## 二、考点（考试怎么考）
1. 推断题错误选项 = 肯定后件/否定前件/假二难的化身（B051、B052 的底层）。
2. 态度题错误选项 = 把「作者驳斥的稻草人/引述的观点」当作者立场（B053 勾连）。
3. 词义题/句意题 = 偷换概念：选项把原文关键词换成另一义项。
4. 例证细节题 = 复述结论/诉诸群众：看似有据实为空转。
5. 「作者会同意哪句」题 = 选项藏人身攻击或诉诸无知的推理。

## 三、逻辑（怎么判定）
1. 找出选项的隐含论证：前提是什么 → 结论是什么（没有前提 = 复述结论/诉诸情绪）。
2. 对照检查表：攻击人？→ 人身攻击。只有两个选项？→ 假二难。结果倒推原因？→ 肯定后件。关键词换义？→ 偷换概念。
3. 看谓语强度：all / must / only 常伴随假二难与以偏概全。
4. 让步段里的观点先贴标签：是稻草人（被歪曲）还是真实反方？→ 影响态度题。

## 四、英语阅读专属提醒
- 错误选项命名直觉：**越绝对越像谬误**（all→以偏概全/假二难；because 乱接→肯定后件；攻击作者动机→人身攻击）。
- 转折词后的作者立场若仍含 critics argue...，警惕连环让步——先摆 A 再摆 B，别把最后一层当唯一立场。
- 高考 D 篇「 BEST title / infer / suggest」里，正确项几乎从不包含谬误结构——这是排除法最快通道。

## 五、典型干扰项
1. 原文：Some say the policy is useless; however, data show... 错误项：Policy supporters are naive idealists（人身攻击/扣帽子）。正确项：The author rejects the criticism with data。
2. 选项：Either we ban all cars or accept endless pollution. ——原文从未二选一（假二难 + 稻草人）。
3. 原文：The program is successful because it works well. 错误项（若作推理题）：The program has clear evidence of success（复述结论）。正确项：The passage gives no independent evidence of success。
