# 正例反用：讲完问题，给的是「做对的样子」

> **一句话**：作者讲完一个问题之后，**不接着说「谁没做对、后果多惨」（反例），而是说「做对了会怎样」（正例）**——
> 这一手**一次给两样**：既让你看见问题，又让你学到解法。
> ★ **看到"问题段后面跟正例"，就要意识到：作者是建设性的，不是在纯揭露。**

## 一、这条卡是怎么来的

**来源**：2026-10-02，同一篇 CET 文章（模拟器 / 组织变革篇），编者指出。
**编者原话**：
> 「他虽然说前面讲你可能会有哪些问题，但后面其实就是说给你点希望，
> 他会用个**正常的例子**——比如他做对了某些事情，有了什么好处，避免了坏的结果。
> 这就是有点像六级中会出现的**正例反用**。」

### 原文证据（★ 铁证级：同义位置上作者选了正例）

> **〔讲问题〕** Most organizations aspire to deploy significant change programs,
> **only to find them nearly impossible to implement.**
> **〔给原因〕** That is largely because successful change requires more than a vision,
> it requires a workforce that **not only doesn't resist change, but embraces it.**

**注意最后半句。** 作者本可以只写：

> ❌ `it requires a workforce that **doesn't resist change**`（**反例写法**：员工会抵抗 → 所以难）

他却**把话头硬扭到正面**：

> ✅ `a workforce that **not only doesn't resist change, but embraces it**`
> （**正例写法**：员工**拥抱**变化 → 这才是解法）

**在同义位置上，作者有「反例」和「正例」两种写法可选，他选了正例。**
**这个"选择"本身就是信号**——它不是修辞偏好，是有功能的。

## 二、两种写法的对照

| | **反例写法**（常见） | **正例反用**（本例） |
|---|---|---|
| 接在问题段后面写 | 「谁没做对」→「后果多惨」 | 「**做对了什么**」→「**有什么好处**」→「避免了坏结果」 |
| 读者得到 | **只有问题**（压迫感） | **问题 + 解法**（双收） |
| 作者姿态 | 批判 / 揭露 | **建设性** |
| 下文走向 | 可能继续罗列问题 | **常引出"怎么解决"** |

## 三、为什么作者要这么写（三层动机）

### 3.1 一次给两样（编者点出的核心）

- 一方面你知道了**有哪些问题**
- 一方面你又学到了**具体的解决方法**

**这比"只讲问题"信息量更大**——读者拿到的不只是诊断，还有处方。

### 3.2 避免文章变成"抱怨"

通篇讲问题会让读者疲惫、也让作者显得只剩批判。
**给一个"做对的样子"，文章就有出口。**

### 3.3 为下文铺路（★ 与 B087 映射原理联动）

正例常常就是**下文的选题**：

```
问题段 →（正例 = 做对的样子）→ 下文展开「怎么才能做对」
```

**所以"问题段后面跟正例"是预测下文的信号**：
下文八成要讲**怎么做到那个正例**，而不是继续罗列问题。

## 四、题型意义（★ 这是本卡最实用的部分）

### 4.1 例子作用题：别把它当"反证"

**B002/B017 讲的是**「例子是为了证明论点；**反面**例子是为了反证论点」。

**正例反用要单独看**：**正例不是来反证的，是来给方案的。**

| 问法 | 反例该答 | **正例该答** |
|---|---|---|
| "作者举这例子是为了……" | 反证某观点的重要性 | **指出解决问题所需要的条件／给出正确做法** |

⚠️ **误判症状**：把正例当反证 → 答成「说明问题很严重」「证明做不到」← **方向反了**。

### 4.2 作者态度题：有正例 = 建设性

| 信号 | 态度倾向 |
|---|---|
| 通篇问题 + 无出路 | 批判 / 悲观的 |
| **问题 + 正例（做对的样子）** | **建设性的**（他相信能做到） |

⚠️ **干扰项**：说作者「只揭露问题」「认为无解」「持悲观态度」→
**被正例直接否掉**（他既然写了"做对的样子"，就说明他认为有解）。

### 4.3 推断题 / 主旨题

- **推断下文**：正例之后常接「怎么做」（见 3.3）
- **主旨**：问题 + 正例 的文章，主旨**不在"问题有多严重"**，而在**"该怎么应对"**
  （与 B048「段意在结构层不在样本层」配合使用）

## 五、操作：三步识别

**第 1 步：定位——问题段之后是什么**

读到「某问题 → 某事很难 / 常常失败」之后，**看紧接着写的是"谁没做对"还是"做对了会怎样"**。

**第 2 步：验真伪——是不是"同义位置选了正例"（★ 最硬的判据）**

> **把作者的正例"翻转"成反例，看意思通不通。**
> 通 → 这里本来**可以**写反例，作者选了正例 → **是正例反用**。
> 不通（原句本来就是正面陈述，翻过来不成立）→ 不是本卡场景。

**本例验真**：

- 原句：`a workforce that doesn't resist change, **but embraces it**`
- 翻成反例：`a workforce that **resists change**` ← **意思通，而且是更常见的写法**
- ⇒ **作者本来可以写反例，他选了正例。确认。**

**第 3 步：读出双收——问题是什么？解法是什么？**

把这两样分开写出来，**下文走向和对作者的判断就都有了**。

## 六、边界：与近邻卡的分工

| 卡 | 管什么 | 与本卡的区别 |
|---|---|---|
| **B009 正反概括** | 「不是 X 而是 Y」这类句式**概括时只留 Y** | 那是**概括动作**（怎么取舍）；本卡是**作者选材**（为什么写正例） |
| **B002 论点骨架** | 「**反面**例子为了反证论点」 | 讲的是**反例的功能**；本卡讲**为什么不用反例、用正例** |
| **B034 宏观结构** | 「例—论—例」结构里 **P3 起常是正例** | 那是**观察到的现象**（在哪个位置）；本卡是**这个现象的理由与用法** |
| **B017 例证题** | 例子的作用题怎么答 | 只管"答什么"；本卡还管**作者为什么这么选材** |
| **B087 映射原理** | 把结构映射到新对象 | **联动关系**：正例常是「结构映射」的下一个对象（先给问题，再给"做对的样子"）|

> 一句话分工：**B034 说"正例在哪"，本卡说"正例为什么在那、它要干什么"。**

## 七、可迁移

| 场景 | 用法 |
|---|---|
| **中文阅读 / 概括题** | 问题后的正例 = **材料给的"对策"信号**，概括时别漏 |
| **写作（自己写）** | 讲问题之后给正例 → 文章立刻从"抱怨"变"建设" |
| **论述文阅读** | 有正例 → 作者立场是**可以做到**，不是"做不到" |
| **工作汇报 / 方案** | 同上：指出问题后**配一个"做对的样子"**，比只列问题更专业 |
