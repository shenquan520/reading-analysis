# 末段主旨验（Last Paragraph = Main Idea）

> **一句话**：**末段是主旨的回收站**——主旨题问"从某段可推断"且该段是末段时，答案=主题词的同义改写或操作化表述。看到末段主旨题，先找全文主题词，再去选项里找它的同义。

> **口诀**：**末段主旨题，去找主题词同义。**

---

## 一、用法（这是什么）

高考阅读理解里有一类**末段推断题**（题干常含 "from the last paragraph" / "can be inferred from the final paragraph" / "末段可推断"），和普通的段内推断题不同——它的答案**不在末段内部找一个细节**，而是**末段在回收全文主题**。

**判定标志**：
1. 题干明确指向 "last paragraph" / "末段"
2. 末段是文章的**收束段**（无新的事实展开，多为态度/建议/展望/措施）
3. 选项的概括度**接近主旨**（不只是一句末段的细节）

---

## 二、考点（命题人怎么动手脚）

1. **反向偷换**：把末段措施的方向偷换（「remove food」→ A. 「Food should be **provided**」）
2. **以偏概全**：只取末段一个措施当全部（「electric fencing」→ D. 「Technology can **protect** grizzlies」，忽略「remove food」和「clean place」）
3. **无中生有**：加末段没有的概念（「a special **path**」）
4. **细节伪装**：把末段措施当答案，但概括度不够（停在「remove food」层而非「和谐共处」层）

---

## 三、逻辑（怎么判定 · 能照做）

1. **找全文主题词**（高频实词 / 写作对象 / 文体目的的关键词）
2. **末段里圈出主题词的同义/反义/操作化表达**（measures, attitudes, expectations）
3. **扫选项**：含这些表达的 = 候选；明显反向/以偏/无生 = 排除
4. **匹配主旨级概括**：候选里挑那个**概括度能罩住全文**的
5. **回填验证**：把选项放回末段，看是不是"末段在讲这句话"

---

## 四、英语阅读专属提醒

- 末段常含**作者态度/建议/展望**（`we should / our hope is / it is worth / the potential implications are enormous`）——这些**评价性语言**就是主旨的信号
- 末段的**措施/让步**（`remove X, do Y`）要概括到**抽象一层**（「措施」→「和谐/平衡/共处」），不要停在措施本身
- 反向陷阱（选项常用 not / never / 提供 / 忽略 偷换 remove / 不 learn）——**逐词比方向**

---

## 五、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文末段 | 错误选项 | 正确选项 |
|---|---|---|
| P5「If people **remove food and attractants**... bears can pass through without trouble」+「Putting **electric fencing** around chicken houses」+「**clean, attractant-free** place where bears can pass through **without learning bad habits**」 | **A.** Food should be **provided** for grizzlies.（**反向偷换** remove→provide） | **B.** People can **live in harmony** with grizzlies.（回收主题"人与自然和谐共处"，概括全部三措施） |
| 同上 | **D.** Technology can be introduced to **protect** grizzlies.（**以偏概全**——只取 electric fencing 一例 + 偷换"驱逐"为"保护"） | 同上 B |
| 同上 | **C.** A special **path** should be built for grizzlies.（**无中生有**——path 文中无） | 同上 B |

## 六点五、⭐ 末段引新国家/新角度 = 拓宽广度，不等于主题

**场景**：主旨题遇到末段提到了**另一个国家/新视角/新对象**，考生易被"跨国对比"误导，选"不同国家生活方式"。

**判定规则**：
- **新闻报道类**的末段引新国家 = **拓宽报道广度**（不是换主题）
- **作者是否把新对象当主题** → 看新对象是否占据**段落重心**（包含具体例证/数据/分析）vs 只是**一句带过**（= 拓宽广度）

**判定动作**：
1. 看末段引新对象时，**该对象的展开篇幅**：
 - 一句带过（"In India, particularly outside cities..."）→ 拓宽广度
 - 一整段展开（具体数据/例证/分析）→ 真换主题
2. 看新对象是否**回扣 P1 主旨词**（如 multigenerational families）：
 - 回扣 = 仍是同一主题的延伸
 - 不回扣 = 真的换主题

**实例**：
> 「Stories like that are more common in parts of the world, where multigenerational living is more firmly rooted. **In India**, particularly outside cities, young women are expected to move in with their husband's family when they get married.」

- 印度 = 一句带过
- 仍回扣 multigenerational living
- → 拓宽报道广度，不是"主题是跨国对比"

**讲义原文**（P158）：
> "虽然文章最后一段提到了印度，但是作者绝对不是把它当作主题进行讲述，只是针对这种现象拓宽了报道的广度而已，而且 A 选项明显是进行对比的说明文的主题。"

**做题应用**：
- 末段主旨题看到"X 国/Y 地" → 先问"是不是一句带过"
- 一句带过 = 拓宽广度 → 答案不在跨国对比
- 真换主题 = 跨国对比 → 答案可以是不同国家

## 七、⭐ 删内容找主题句

> **场景**：事实类说明文（"什么现象 + 为什么"），文章由大量事例/数据/引用构成，主题句**被淹没**在内容里。

### 7.1 方法（5 步）
1. **列出全文事例/数据/引用**：事例（人物/故事）、数据（统计/百分比）、引用（名人话语）
2. **逐项删除**：删掉所有事例/数据/引用
3. **看剩下的句子** → 通常只剩 3-5 句
4. **这些剩余句子** = 主题句（最可能包含主旨）
5. **把主题句与选项比对** → 选覆盖最广的

### 7.2 实例
- P1：Marian Bechtel 的具体事例引入 → **删除**
- P2：每句话都有具体数据 → **删除**
- P3：Bechtel 的事例和引用 → **删除**
- P4：Andrew Mazoleny 的事例和引用 → **删除**
- P5：最后一句 Laurie Demeritt 的引用 → **删除**
- **剩下的**：P5 前三句 + P5 后两句
 - "That freedom to choose is one reason more people like to eat alone."
 - "Now, we have our smartphones to keep us company at the table."
- → **主旨 = "独自吃饭趋势"**（ 答案 A）

### 7.3 优势
- 比起"通读再总结"，节省 50%+ 时间
- 适用于四段并列的事实类说明文（占高考 C/D 篇约 30%）

### 7.4 与本卡原方法的对比
- 本卡原方法：**末段=主旨回收站**（适合议论文/说明议论文/有主旨升华的文章）
- 删内容找主题句：**删事例找剩余句子**（适合事实类说明文/全是数据和例子的文章）
- 两种方法互补，根据文体选择

## 八、⭐ 建议/措施题去后段/末段找动作动词

**适用题型**：阅读理解细节题（题干问 "What should... do?" / "How should...?" / "What is the author's advice?"）

**判定动作**：
1. 题干问建议/措施 → 预期答案在文章**后 1/3 或末段**
2. 到后段找**动作动词**（step in / make / plan / take / set aside / encourage / limit / replace 等）
3. 把动作抽象为选项：
 - step in + make reading list + plan family trip → **家长参与/以身作则**
 - replace old products with new electronics → **停止使用旧设备**
4. 排除未出现的动作（write reports / set up groups / talk with teachers / recycle / upgrade 等）

**实例**：
- 题干：How should parents encourage their children to read more?
- 定位：P6-P7
- 动作："serving as examples" / "step in" / "make their own summer reading list" / "plan a family trip to the library or bookstore"
- 抽象：家长自己参与、以身作则 → A "Act as role models"
- 排除：B write book reports / C set up reading groups / D talk with teachers（均未出现）

**讲义原文**（p213）：
> "说明文和议论文的建议是作者用来给文章收尾的方法之一，所以往往在文章靠后的位置，而你要去找的，就是出现了哪些具体的动作。"

**注意**：此法适用于**作者明确给出建议**的文章；若文章纯描述现象无建议段，则不适用。

## 九、⭐ 细节题基本动作

**场景**：阅读理解细节题（题干问具体信息 / 特点 / 方法 / 原因）。

**判定动作（能照做）**：
1. **题干关键词 → 回原文对应段落**：题目问什么 → 找哪段，不要过度推理。
2. **选同义替换**：正确项 = 原文对应句的同义改写，不要脑补。
3. **不要兜圈子**：例证的细节题答案在例子描述段，不在论点段；研究的细节题答案在研究描述段。

**实例**：四道细节题全部按"题干关键词 → 对应段落 → 同义替换"完成（→P1，→P3，→P4-P5，→P7）。「配合题目要求，去文章对应段落落定位重要信息选出正确答案」。

**讲义原文**（p325）：「这是阅读理解最基本的能力要求。」

## ⭐ 推断题主题相关度一票筛选
- **规则**：推断题（尤其末段推断）四选项先问**哪个与文章主题关系最密切**——与主题无关的先排，剩下的再回原文核细节。
- **适用题型**：阅读理解·推断题；不适用七选五还原。

---

## ⭐ 对照批六级大批补丁（2026-09-02）

**话术是台词不是方法论**：引号里的话可作论据，「该做什么」取 It is best to... 这类方法论句——台词与建议分属两轨（Q55-D 团结文）。**建议取祈使句主句**：let's commit to... 是总纲，论据分句与消极从句都不是建议（Q55 气候文）。

## ⭐ 考研批补丁（case-205/206，2026-09-04 主会话落卡）

**定位段只给事实→跨段拼装（考研结构性特征）**：定位段若只有事实/例证、没有观点句，答案句在邻段——缺口栏二次命中（case-205 Q34 / case-206 Q38 同型）。考研篇遇事实段，**直接向两侧各扩一段找观点**。
