# B047 写作方法五分类 + 介绍说明类骨架（Writing Methods × Introductory Expository Skeleton）

> **一句话**：英语阅读中"作者基于什么"类细节题 = 问**写作方法**（分类/举例子/列数据/做比较/加引用）；介绍说明类文章 = **客观特点—主观评价**两段式骨架。
> **口诀**：**问"基于什么"→ 五方法选一；介绍类 → 客观+主观。**

---

## 一、用法（这是什么）

高考阅读里有两类题目直接考**写作方法**：

| 题型 | 题干标志 | 实际在问 |
|---|---|---|
| **细节·写作方法题** | "The author's statement is based on ___" / "作者陈述基于什么" | 作者用了什么写作手段（不是讲了什么） |
| **细节·证据题** | "Which of the following is an example of ___" | 文章用了哪种论证/说明手段 |

**写作方法五分类**：

| # | 方法 | 标志词 / 表现 | 答案方向 |
|---|---|---|---|
| 1 | **分类** | "可以分为三类" / sorts/types/kinds | 选含 categories / types / classifications 的项 |
| 2 | **举例子** | such as / for example / like | 选含 examples 的项 |
| 3 | **列数据** | 具体数字（百分比/总量/对比） | 选含 statistics / data / figures 的项 |
| 4 | **做比较** | compared with / however 转型 / than | 选含 comparison / contrast 的项 |
| 5 | **加引用** | said / according to / a researcher reports | 选含 quotation / reference / authority 的项 |

---

## 二、考点（命题人怎么动手脚）

1. **"家庭传统"陷阱**：看到"过去 vs 现在"对比就选"tradition"——讲义明示"过去不是这样，哪来的传统呢？"。
2. **"财政报告"陷阱**：把"原因"（费用高）当"陈述基础"——B 选项。
3. **"大众观点"陷阱**：把"个例"（Nick 一家）当"公众"——D 选项。
4. **答非所问**：选了一个"内容"而非"方法"（细节题 vs 写作方法题混淆）。

---

## 三、逻辑（怎么判定 · 能照做）

1. **看题干关键词**：
 - "based on" / "based upon" → 问**基础/依据** = 写作方法
 - "is supported by" → 问**支撑手段**
 - "can be proved by" → 问**证据类型**
2. **回原文找证据类型**：
 - 数字（325,000 → 419,000）→ **列数据** → C Published statistics
 - 例子（Nick 一家）→ **举例子** → 例证 / case study
 - 引号（"said / according to"）→ **加引用** → quotation / authority
 - 对比（"20% vs 16%"）→ **做比较** → comparison / contrast
3. **匹配选项动词/名词**：选项里出现 statistics / examples / comparison / quotation / categories → 对应五方法之一。

---

## 四、英语阅读专属提醒

- **"作者的陈述基于什么" ≠ "作者陈述了什么"**：前者问**方法**（怎么说的），后者问**内容**（说了什么）。题干里"based on"是关键信号词。
- **数据三件套**：百分比（20% / 16%）+ 总量（1.8 million）+ 趋势对比（2001→2013）= 典型的**列数据**论证。
- **"例证" vs "例子本身"**：选项若说"养牛人的环境适应"（例子本身）≠ 问"例子说明什么"（例证作用）。讲义明示"例子的作用当然不是为了说明例子自己"。

## 五、⭐ 介绍说明类骨架

讲义明示：

> "无论是介绍事物还是介绍人物，背后的写作思路是完全相同的，你要**选择介绍对象的两到三个闪光点**，然后配以自己对这些闪光点的感想，**体现的内在逻辑就是'客观特点—主观评价'**。"

**两段式骨架**：

```
[客观特点段] 列举对象的 2-3 个闪光点（细节/列举/数据）
[主观评价段] 作者对这些闪光点的感想/评价/升华
```

**实例**：
- P2-P3 客观特点：人物（Rustam/Oleg/Natasha）+ 经历（Samarkand/Bukhara/Ferghana/Karakalpakstan）
- P4 主观评价："a fine and vivid description of the purest of Central Asian traditions"（升华）

**做题应用**（介绍说明类目的题 = ）：
- 看到介绍一本书/一地方/一人物的文章 → 答案 = "To introduce X"（A 类）
- 排除项：
 - B "To explain a cultural phenomenon" → 介绍的是具体对象不是文化现象（**偷换对象**）
 - C "To remember a writer" → 变成人物记叙文（**文体错位**）
 - D "To recommend a travel destination" → 变成应用文（**文体错位**）

**介绍事物 vs 介绍人物**（讲义明示差异）：
- 介绍**事物**（一本书/一个地方）→ 学生容易守"客观+主观"思路
- 介绍**人物**（一个人）→ 学生**容易产生写作偏差**（写成单纯赞美或罗列事迹，缺主观评价）

## 六、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文 | 错误选项 | 正确选项 | 干扰类型 |
|---|---|---|---|
| P6-P7「325,000→419,000 / 20% vs 16% / 1.8 million」 | A. Family traditions（**无中生有**——过去不是这样） | **C. Published statistics** | 无中生有 + 偷换（tradition ≠ data） |
| 同上 | B. Financial reports（**偷换概念**——文中是"原因"不是"基础"） | 同 C | 偷换概念（reason ≠ basis） |
| 同上 | D. Public opinions（**张冠李戴**——Nick 一家 ≠ 大众） | 同 C | 张冠李戴（个体 ≠ 群体） |
| 全文 = 介绍一本书 | B. To explain a cultural phenomenon（**偷换对象**——书 ≠ 文化现象） | **A. To introduce a book** | 偷换对象（具体物 → 抽象现象） |
| 同上 | C. To remember a writer（**文体错位**——人物记叙文） | 同 A | 文体错位（说明文 → 记叙文） |
| 同上 | D. To recommend a travel destination（**文体错位**——应用文） | 同 A | 文体错位（说明文 → 应用文） |
