# B042 研究结论优先法（Research-Conclusion-First Reading）

> **一句话**：**研究类说明文中，先抓研究结论，再用结论指导所有题目。**
> **口诀**：**结论在手，四题我有。**

---

## 一、原理（为什么成立）

研究类说明文（research-based expository text）的结构高度固定：
- **首段/第二段**：提出研究结论（核心发现）
- **中间段**：背景、方法、证据、延伸解释
- **末段**：专家解读、意义、展望

所有内容都围绕研究结论展开。因此，**先抓住结论，就能把无序的细节题变成有方向的验证题**。

---

## 二、研究结论常见位置与标记

| 位置 | 常见标记 | 例句 |
|---|---|---|
| 首段末句 | A study shows that ... | "A ground-breaking, five-year study shows that diet-related changes in human bite led to new speech sounds." |
| 第二段首句 | Researchers found that ... | "Now a team of researchers ... has found how and why this trend arose." |
| 第三段首句 | They discovered that ... | "They discovered that the upper and lower front teeth of ancient human adults were aligned..." |

> 结论句通常含因果/变化关系，是全文最重要的句子。

---

## 三、判定步骤（能照做）

1. **扫首段/第二段**，找含 "study shows / researchers found / discovered / revealed" 的句子。
2. **简化结论**：把结论压缩成「A 导致 B」或「X 与 Y 有关」的核心逻辑。
3. **做题时先用结论过选项**：
 - 与结论同向 / 是结论的具体化 → **保留**
 - 与结论无关 → **排除（无中生有）**
 - 与结论方向相反 → **排除（因果倒置 / 偷换概念）**
4. 结论不能直接解决的题 → 按题文同序回对应段落找细节。

---

## 四、支持证据段标记

研究类文章中，以下表达常提示该段是对结论的支持证据：

| 标记词/短语 | 段落功能 |
|---|---|
| also confirmed | 进一步证实 |
| further supported | 进一步支持 |
| consistent with | 与……一致 |
| in line with | 与……一致 |
| the findings suggest | 发现表明 |

→ 段落主旨题中，这些标记常对应 **supporting evidence** 类选项。

## 七、补充：研究对象 vs 道具区分

> 研究类说明文中，常出现"演员/实验设备/实验材料"等"道具"和"参与者/被试"等"研究对象"。**研究目的是观察研究对象的反应，不是看道具在做什么**。

### 7.1 判定动作
1. 题干问"为什么 X / X 的作用是什么" → 先确认 X 是**道具**还是**研究对象**
2. 道具（actor、device、equipment）→ 问"为什么用这个道具" = 看研究目的，不是看道具本身
3. 研究对象（participants、subjects、students）→ 问"为什么研究他们" = 看他们的反应

### 7.2 实例
- 题干："Why did the researchers hire the actor?"
- 易错：选 C "看她会在两个实验里做什么" —— 把研究对象**偷换为道具**
- 正确：A "看她如何影响参与者" —— 演员是**道具**，参与者才是**研究对象**
- **讲义原文**：「研究对象就都变成演员本身了，但是实际上演员只是个道具而已，研究者要看的是参与者的反应...研究吃什么饭伴对我们食量的影响。答案选什么？选 A 选项'看着她会如何影响参与者'」

### 7.3 干扰项识别
- **对象偷换型干扰项**："看 X 在做什么" / "X 怎么操作" → 错（除非 X 就是研究对象）
- **道具有效型干扰项**："选 X 是因为 X 优秀/有效" → 错（X 是工具，不是研究目的）

## 八、⭐ 研究结论的呈现方式与速战用法

### 8.1 结论可能由连续多句构成，需概括为一句

**场景**：研究类说明文首段不只一句结论，而是两到三句共同表达一个结论。

**判定动作**：
1. 找到首段/第二段所有含 "study shows / researchers found / indicates / suggests" 的句子
2. 把这些句子**压缩成一句话**：主语（研究对象）+ 谓语（发现/关系）+ 结果
3. 做题前先把这句话写在脑子里，作为"主 filter"

**实例**：
- P1 句 1："we keep using our old devices well after they go out of style"
- P1 句 2："these outdated devices consume much more energy than the newer ones"
- 概括结论：**旧设备过时后仍被使用，且比新设备耗能高**
- "概括下来就是，'使用旧设备不环保，新设备比旧设备节能'"

### 8.2 每选项先过"是否与结论密切相关"

**操作**：
1. 结论明确后，四个选项逐个问："这个选项讲的是不是结论里的事？"
2. 与结论同向/是结论的具体化 → 保留
3. 与结论无关 → 直接排除（省掉细看微观构造的时间）
4. 与结论反向 → 排除

**实例**：
- 问作者对新设备看法：结论 = 新设备比旧设备节能 → 只有 A "environment-friendly" 同向 → ✅
- 问研究目的：结论 = 能耗比较 → 只有 D "find out electricity consumption" 相关 → ✅
- "在做每一道题的时候，都应该确保选项和这个结论的关系密切"

### 8.3 技术迭代/产品代际类研究文：最新代际常对应最优解

**适用题型**：研究类说明文细节题（涉及产品、技术、设备按年代/代际介绍）

**判定动作**：
1. 文中出现多个年份/代际（1992 / 1997 / 2002 / 2007 / Generation 1/2/3）
2. 题干问"哪个最 X"（最节能、最高效、最先进等）
3. 先找**年份最大 / 最新一代** → 大概率对应正确答案

**实例**：
- 文中产品：1992 desktop / 1997 digital camera / 2002 MP3/smartphone/LCD TV / 2007 tablet
- 题干问"哪个耗能最低"
- 最新 = 2007 tablet → B 正确
- "文章里白纸黑字地写着年份，选择数字最大的即可，所以选择 B 选项 2007 年的 tablet"

**注意**：此法是**速判信号**，需回原文确认该最新产品确实被描述为"更优"（如本文 "cut energy consumption by 44%"）。

## 九、⭐ 实战补三则

### 9.1 研究类议论文"主题重复强调"
- **场景**：研究类议论文，作者在不同段落**重复核心结论**。
- **规则**：核心结论被重复强调 → 题目常**直接问主题**，无需逐段细读。
- **实例**：Fryer 研究在 P3+P4 重复 "input > output"， 直接问作者主张 = 主题。「研究结论直接秒杀」——抓住 "input > output" 主题，4 道题全部秒解。

### 9.2 研究类说明文 = 全题秒杀
- **场景**：研究类说明文（标题/首段含 "a new research suggests / study shows"）。
- **规则**：① 看到研究标志 → **不必逐段细读** ② 4 道细节题答案多在 **P1（结论）+ P2（方法）+ P3/P4（解释）** → 直接对应题干关键词。
- **实例**：- 全部"研究结论直接秒杀"。「本题研究结论直接秒杀，毫无难度。」
- **讲义原文**（p350）：「不管有没有标题，你总能够在文章的开头看到类似 'a new research suggests 一项新的研究表明' 这样的标志短语... 第一句话是研究结论，请务必看懂。」

### 9.3 研究类说明文段首总括句 = 题目来源
- **场景**：研究类说明文，段落首句常是总括句，且直接对应题干。
- **规则**：① P1 段首 = 结论 ② P2 段首 = 方法 ③ P3/P4 段首 = 结果/解释 → 题目答案常直接对应这些段首句。
- **实例**：P1 段首=（结论）/ P2 段首=（方法）/ P4 段首=（解释）/ P5 段首=（进一步发现）。
- **联动 B048**：段首总括句 = 段落主题句（B048 二），研究类文章尤其规整，题目多考这些段首句。

## ⭐⭐ 研究结论秒杀三规则

1. **多段合并提问的元信息**：题目问"前 X 段主要关于什么"时传递四条信息——这几段是整体；重要信息一致；**任选一段读与全读等效**；选**篇幅较短或有明确标志的段**读（通常是研究结论段）。
2. **施影响方 / 受影响方方向判断**：词义题先从研究结论确认"谁是施加影响方、谁是承受方"——如"气候变暖→海洋变色"中变暖是施影响方，承受影响的一方（phytoplankton）的 vulnerable = sensitive 而非 beneficial。
3. **选项全含核心词 → 比相关度**：四个选项都含主题词时，题目实际在问"哪个与结论直接相关"；同时**人名只是例子**，涉及人名/模型"目的"的选项降权（model 预测的是海洋变化，不是以浮游植物变化为目的）。
4. **结果链层次**：研究结论是"因→果"链（变暖→变色）；**结果之结果**（变色后再带来什么）不在文章讨论范围——写作目的题选结论本体，不选结果的延伸。

**适用题型**：阅读理解·研究类说明文全题型（段意/词义/细节/写作目的）；不适用七选五还原。

## ⭐ 三题速战文：首题必落首段研究结论
- **场景**：三道题的研究结论类说明文（速战速决型）。
- **规则**：首题（研究结论题）答案必然落在**首段研究结论句**

---

## ⭐ 补：**⚠️ 适用边界（考研批 case-205）**：「结论前置」在**评论/观点类**文章失效——评论类常把核心判断放中后段（甚至用虚拟/让步包裹）。研究报道文才用「首段结论句」锚定；评论类改走 B036 跨段拼装 + A032 整体通道。

> conclusion 题的正确项必须是**主张**（研究想证明的那句）；干扰项常把**因果链末端的结果**包装成结论——如 `resulting in a lack of vital genetic diversity` 是**结果**不是结论。区分靠 B083 位置判别。；选项信息若来自尾段/对比细节，属**段位错位**直接排除——信息位置与题干层级不匹配。
- **实例**：结论=「压力影响权衡利弊方式（关注快乐忽略后果）」→ A keep rewards better in memory ✅；C risky decisions 来自尾段男女对比 → 段位错位排除。
- **适用题型**：阅读理解·细节题（研究结论类）；不适用七选五还原。

## 增强

- **段旨题 process vs method 区分**：段旨题选项常在「研究过程（process）」和「研究方法（method）」之间下刀——
 - 过程 = first / then / later / a second test 这类**时间链**主导的段 → 选 process。
 - 方法 = how it works / mechanism 这类**机制层**主导的段 → 选 method。
 - 判据：段落由时间推进词串联 = 过程；由因果机制词串联 = 方法。
 - 案例：AI 隐性学习 D 篇，P2 全是实验操作细节，干扰项 D「The methods of subliminal learning」——段的命题功能是「展示研究发现的过程」，不是「教隐性学习怎么操作」（描述≠功能，红线4）。

## ⭐ 沧海遗珠三扫补丁（2026-09-03，case-151/154/155 汇聚）

**研究描述的三种结构读法**：
1. **对照实验**：control participants / significantly greater belief——读法=「对照组是谁、实验组多在哪、显著到什么程度」三问（case-151）
2. **三理论并列题**：题干 one of the theories 不指明哪个——三个选项各对应一个理论，**先回原文给各理论定位再排除**，不逐选项硬怼（case-154）
3. **立场句 vs 让步句分层**：Set aside the familiar argument...（让步）→ The argument here is...（立场）——经济评论常让步在前立场在后，态度题认准立场句（case-155/156 结构性归因 vs 归咎传统同理）
