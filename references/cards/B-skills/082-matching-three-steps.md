# B082 长篇匹配三步定位（段落信息匹配）

> **一句话**：长篇匹配不考主旨考定位——**题干扫关键词 → 回原文找同义替换锚点 → 身份词对齐到人**。

## 一、三步操作

1. **题干扫关键词**：圈出题干里的"硬词"——数字、专有名词、身份词（judge/officer/teacher）、独特概念词
2. **同义替换锚点**：回原文扫段，找复现链——**原词复现**（36/39/44 题）、**同义替换**（fears→eased / worth→validate the value / pay→costs nothing / marketable→commercially feasible）、**数字复现**
3. **身份词对齐**：题干给身份不给名字时，回原文找这个身份对应的具体人——judge→Cleaver（L 段）、chief executive→Kampfner（B 段）

## 二、实战配比

| 定位方式 | 占比 | 例 |
|---|---|---|
| 同义替换 | 5/10 | 43 题 marketable = commercially feasible |
| 原词/数字复现 | 4/10 | 36 题 training/support 原词 |
| 身份定位 | 2/10（与其他叠加） | 38 题 judge → Naomi Cleaver |

## 三、⚠️ 题型边界

- 长篇匹配 = **复现定位题**：不分析主次、不判主旨，考"同义替换识别速度"
- 与七选五（还原文本，考衔接逻辑）和仔细阅读（考主旨/推断）**是三种不同的题**——别拿主旨题的打法套它
- 一段可选多次（题目说明允许），别被"每段只能选一次"的旧经验误导
