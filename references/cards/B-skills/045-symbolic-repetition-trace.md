# B045 象征性线索识别（Symbolic Repetition Trace / Leitmotif Test）

> **一句话**：记叙文中**反复出现的核心词 = 主旨象征线索**，正确项 = 该词在全文中累积的**主题词同义替换**。识别法：① 找文中出现 ≥ 3 次的关键词；② 看它在每次出现的语义是否变化；③ 末段出现的该词=该线索的"主题回收"。
> **口诀**：**找复现词、看它如何变、末段回收即主题。**

**判定步骤**：
1. 找文中出现 ≥ 3 次的核心词/短语
2. 第一次出现 = 该词的初始义（常是字面义）
3. 中间出现 = 语义扩展（多种引申义）
4. 最后出现 = 主题回收（升华为抽象情感/主题）
5. 主旨题答案 = 该抽象主题的同义替换

**干扰项三栏**：
- 原文：全文 "Safe" = cool/hello/don't worry/well done/don't worry/don't worry（多义集合）→ P6 末"Safe" 仍是归属暗号
- 错项：Children should learn a second language（无中生有）/ Sport is necessary（以偏概全）/ Seeing the world is a must（范围扩张）
- 正项：Children need a sense of belonging（Safe 累积主题 = belonging）

**英文名别名**：Symbolic Repetition Trace / Leitmotif Test
**scope**：高考（记叙文 / 主旨题）

**实战验证**：2021 全国甲卷 C 篇—— Safe 7+ 次出现，主题 = belonging

> 来源：实战案例。由续跑会话从 case 内嵌「【新建】B045」小节重建落盘。
