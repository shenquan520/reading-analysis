# 词汇复现（Reiteration）

> **一句话**：词汇复现是七选五的**高频线索**——正确选项**通常**与前后文有词汇呼应（原词/同义/近义/上义/概括词），**但复现是线索不是证据**（A006 六点六）。做题时圈出空位前后的实词，去选项里找呼应词。

## 一、用法（这是什么）

同一个语义在语篇中反复出现（不一定用同一个词），形成衔接。Halliday 的复现渐变群（cline）：

```
原词重复 → 同义词 → 近义词 → 上义词 → 概括词
 dog...dog dog...canine dog...animal dog...creature
```

**距离越远，衔接越"弱"但越高级**——这是作者避免重复同时保持连贯的手段。

## 二、考点（考试怎么考）

1. **七选五**：空后若出现新话题词，空前必须有它的"复现来源"（同义/上义/原词）
2. **完形填空**：选项是原文某词的同义词/上义词 → 高概率正确
3. **主旨题**：反复出现的实词 = 主题词；正确项通常包含它（高频词法）
4. **词义猜测题**：上下文复现关系提供线索（并列=同义、转折=反义）

## 三、逻辑（怎么判定）

1. 找出空位前后 1-2 句的**实词**（名词/动词/形容词）
2. 去选项里找**呼应**：原词重复 / 同义替换 / 上义包含 / 概括词收拢
3. 有呼应 → 候选；无呼应 → **仅用于排除**（⚠️ 不能用于确认——见下方「边界」）

## 三点五、⚠️ 边界：复现是线索，不是证据（A006 六点六）

> **复现只能用来"排除"，不能用来"确认"。**

| 情况 | 强度 | 说明 |
|---|---|---|
| 复现的是**主干**对象 | **强线索** | 主干持续流动到底 |
| 复现的是**枝干**对象 | **弱线索** | 可能是干扰项（枝干也可能复现） |
| **没复现**，但对得上**主干功能** | ⭐ **仍可能是答案** | 不能因无复现就划掉 |
| 有复现，但只是枝干偶然重合 | **不能据此选它** | 回到主次三原则 |

**验证**：代入后，选项与前后文能构成"同一语义的反复出现"

## 四、英语阅读专属提醒

- **词汇衔接独立于指称一致性**：两个词不需要共同所指就能衔接（如 boys...boy）。所以"词没重复"不代表"没衔接"——同义/上义也算
- **专有名词重复 ≠ 自动衔接**：John...John 不自动等于同一个人（需 he 标记）；the Fawn...the Fawn 才是（the 提供指称一致性）
- **封闭类词（the/do/good）衔接力低**：因为频率太高，重复它们不构成有效线索——找复现要盯实词
- **概括名词 = 现成的复现终点**：the idea / the move / the thing 回指前文一大段，是作者给的概括提示

## 五、典型干扰项

| 类型 | 原文 | 错误选项 | 正确选项 |
|---|---|---|---|
| 无复现 | "They planted apple, pear, and orange trees..." | 选讲养蜂的选项（无词汇呼应） | 选含 fruit/trees 的选项 |
| 假复现 | "...recycling programs..." | 选项有 recycle 但话题跑偏（只呼不应） | 选项 recycle + 与全文话题一致 |
| 专名误判 | "John...John..." | 认为两个 John 必然同一人 | 需 he 才锁定同一人 |

## 六、⭐ 补充：两种原卡漏掉的复现（2026-09-01 实战补）

### 6.1 反义复现（对立词构成的词汇链）

原卡的复现渐变群只覆盖**同向**语义（原词→同义→近义→上义→概括词）。
但**对立词同样构成衔接**——作者用反义对照维系语篇时，两个词互为线索：

```
open ↔ close increase ↔ decrease problem ↔ solution
pessimist ↔ optimist awake ↔ asleep lose ↔ have left
```

**实例**（2017 新课标2 第 5 空）：
> 「If you have a door to your office, make good use of **it**. [空] If someone knocks…when **the door is closed**, you're not to be disturbed.」
> 正确项 **G**「Leave it **open** when you're available to talk and **close** it when you're not」
> → `open ↔ closed` 构成反义复现链，`it` 一链到底指 door。

**判定动作**：圈出空前后的实词后，**同时想一下它的反义词**——选项里若出现其反义词且逻辑成立，往往是答案。

### 6.2 形式复现（句式/结构排比）

复现的不只是**词**，还可以是**结构**：

| 形式复现 | 例 |
|---|---|
| **引号排比** | `"You'll actually show up if you know someone is waiting…" while another reason: "[空]"` → 空处须是同型 `You'll…` 句 |
| **祈使句群** | `Learn to…` / `Stop…` / `Find the right…` → 小标题群同型 |
| **并列结构** | `A, B and C` 三项须同一语法位 |
| **段落排比** | 四段同构（条件句→操作句），见 B034 |

> 讲义原话（七选五讲义书中相应位置 第 7 条）：「**形式大于内容：句式排比；段落排比；and, or, but 并列的部分形式一致**」—— ⭐ 这条我原卡完全没有。

### 6.3 名词词义题：同词复现 + including 解释

**结构**：名词 X 在句中首次出现 → 同一句或下一句再次提及 X，并用 `including / such as / that is / in other words` 给出具体内容。

**判定动作**：
1. 找到划线名词。
2. 在同一句话或紧随其后的句子中找该名词是否复现。
3. 找 `including ...` 或同位语结构——其内容往往就是词义题答案。

**实例**（2022 全国乙卷 C 篇 ）：
> 「...huge savings in **maintenance** costs ... It is calculated that ... spend approximately 20 billion euros a year on **maintenance**, **including** sending maintenance staff ... to **inspect and repair** the rail infrastructure.」
> → maintenance = inspection and repair ✅

> 「名词的对应内容、名词相关的动作、名词的性质」——复现是最直接的呈现方式。

## 八、词义猜测短语/单词补充

> **场景**：词义题不只考名词词义，**短语/动词词组/专有名词**也考。下面 5 个是讲义 第 2 批实战中讲义明示的常见词义点。

### 8.1 `make it = 取得成就/成功`
- **原文**：`make it to market` = 成功上市
- **拆解**：`make it` 是固定短语，= 达到目标/取得成就/成功；`to market` = 到市场
- **讲义原文**：「你需要理解的就是'make it to market'里面的基本短语'make it 达到目标、取得成就、成功'，'成功到市场'，正确理解就是'成功上市'」
- **考点**：避免望文生义（"make" ≠ "制造"；"it" ≠ "它"）

### 8.2 `review = 审查/检查`
- **原文**：`Engineers come and really do an in-person review` = 工程师亲自审查产品
- **拆解**：`review` 在"产品 review"语境下 ≠ "评估/回顾"，而是"审查/检查"
- **讲义原文**：「这道题其实也就是对'review'这个核心词的考查...当然是 A 选项'检查'了」
- **易错**：把 review 误作 grade（打分）→ "Grade their homework" 错

### 8.3 `on a first-name basis = 以名为基础 = 直呼其名 = 彼此熟悉`
- **原文**：`chat up the barkeeper with whom he's on a first-name basis` = 跟熟悉到能直呼其名的酒吧老板聊天
- **拆解**：`first name` = 名（≠ family name 姓）；`basis` = 基础；以名为基础 = 称呼对方的名 = 不加姓 = 彼此熟悉
- **讲义原文**：「'first name'是'名'的含义，什么叫'以名为基础'？就是你和对方的交谈中，你能直接称呼对方的名，不需要加'姓'，表示一种彼此熟悉的感觉」
- **应用**：推断人物关系（熟悉度）

### 8.4 `healthy adjustment = 健康调整 = adaptable 适应能力`
- **原文**：`likability can lead to healthy adjustment` = 受欢迎能带来健康的调整
- **拆解**：`adjustment` = 调整/适应；`healthy` = 健康/正面；`adaptable` = 有适应能力的
- **讲义原文**：「本身话语不详，何况还是在'while 虽然 尽管'后面的内容...所谓'健康的调整'，就是能根据不同情况做出合理的、正确的自我改变，也就是 B 选项所说的'adaptable 有适应能力的'」
- **考点**：复杂抽象名词 → 拆解 + 同义替换（adjustment = adaptable）

### 8.5 `penny（英）= cent（美）= 一分钱`
- **原文**：`penny paper` = 一分钱报纸；文中出现 `cent` 同义复现
- **拆解**：`penny` 是英式常用说法，`cent` 是美式常用说法，二者等价
- **讲义原文**：「penny 和 cent 都是'一分钱'的意思，前者是英国常用的说法，后者是美国常用的说法」
- **考点**：英美文化背景文章中的等价单位/词

### 8.6 应对"命题奇怪题"（与主题无关的细节题）· · case-029
- **场景**：题目的四个选项与全文主题都没有直接关系，命题人故意出这种题（讲义吐槽"命题思路有点迷"）。
- **应对**：不靠主题判断，回到原文找细节对应（"on a first-name basis" 细节）。
- **讲义原文**：「这道题的命题思路有点迷，也是高考真题阅读理解里为数不多的、让我不理解为什么要这么出的题目...题目答案只能是 D 选项，'他和酒吧老板很熟'」

## ⭐ 动词近义链
- **规则**：空前空后谓语动词的近义串联（be **protected** → **preserve** → **keep**）是相邻句内容对应的强依据——动词作依据较罕见（动词含义灵活），但三动词近义+宾语呼应（most important memories ↔ what matters）时极强。
- **适用题型**：七选五还原 / 复现判断。

## ⭐ 反义对也是并列关系；但并列 ≠ 地位均等（编者 2026-09-02 补）

**从词义上看，一个事物的正反两面本身是对等对称的——生与死、上与下、左与右，都是并列关系**（反义衔接的本体：不是冲突，是并列的两侧）。

**但词义并列 ≠ 文中地位均等**：

- 原理（经典分析思维）：**想认识一个事物的全面，必须看到它的对立面；事物依附其对立面而存在**——聊 A 想聊得彻底，必须聊 A 的对立面 B
- 但**文章想突出的可能只是 A**——B 是为衬托 A 而存在的（与「对比反衬抓正面」咬合）
- **权重回主旨**：作者花笔墨写对立面，不代表对立面是重点——衬托者笔墨可以很多，被衬托者才是主旨所向

**做题含义**：反义对照段里，问作者态度/主旨的题，答案落在**被衬托的一方**；问细节的题才需要分侧取用。
