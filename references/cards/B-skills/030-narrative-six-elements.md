# 记叙文六要素 + 主次取舍

> **一句话**：记叙类文章的概括，先把**六要素**找全，再按主次**砍掉一半**。

---

## 一、先判断：这是记叙类吗？

讲义编者列出的**记叙类文体**：

> **新闻、记叙文、叙事散文、叙事诗、小说、戏剧**

**这类文体的概括方法**：
> 「**常常把记叙的六要素合并成一句话**」

**⚠️ 与说明/议论文不同**：
- 记叙类 → 抓六要素（时间、地点、人物、起因、经过、结果）
- 议论类 → 丢论据，留论点
- 说明类 → 保留主要特征

（详见：不同体裁的概括方法不同——**别拿一套方法打天下**）

---

## 二、六要素与主次取舍

| 要素 | 主次 | 处理 | 理由 |
|---|---|---|---|
| **人物** | ⭐ 主要 | **保留** | 概括句**以主要人物为主语** |
| **起因** | ⭐ 主要 | **保留** | 事件的起点，删了说不清 |
| **经过** | ⭐ 主要 | **保留** | 事件的核心 |
| **结果** | ⭐ 主要 | **保留** | 事件的落点 |
| 时间 | 次要 | 视情况 | 通常是背景，除非时间本身有意义 |
| 地点 | 次要 | 视情况 | 同上 |

**讲义编者的原话**：
> 保留**人物 / 因果 / 主目的**；省略**地点、起因、熟悉环境**

**⚠️ 注意这里有个看似矛盾的地方**：

| 出处 | 说法 |
|---|---|
| | 省略「**起因**」 |
| 六要素通用规则 | 保留「起因」 |

**裁决**：**起因是主要还是次要，看它对结果的解释力。**
- 起因是理解结果的必要条件 → 保留
- 起因只是铺垫、谁都能猜到 → 省略

**⭐ 回到主次三原则**：**留不留，看它对主旨的贡献，不因为它是"起因"就自动保留或删除。**

---

## 三、⭐ 概括句以主要人物为主语

讲义编者明确的一条操作规则：
> **概括后的语句，以主要人物为主语。**

**为什么**：概括句要回答"**谁做了什么**"，主语自然落在施动者身上。

**英语阅读的对应操作**：
- 找**主干**：主语 + 谓语（+ 宾语）
- 定语、状语、补语是"枝叶"，压缩掉（B016 / 单句主干找法）

**中英对照**：

| | 中文概括 | 英语阅读 |
|---|---|---|
| 保留 | 人物 / 因果 / 主目的 | 主语 / 谓语 / 宾语 |
| 压缩 | 地点 / 时间 / 程度 | 定语 / 状语 / 补语 |

**这印证了「文段与句子全息」**：
> 整篇文章综合的结果，要么是单句内部的关系全息，要么是复句内部的关系全息。
> **复句的关系在分清主次、保主舍次后，大多可以裁剪为单句的形式。**

## 四、做题怎么用

### ① 记叙文/小说类主旨题：套六要素

**步骤**：
1. 找主要人物（谁）
2. 找起因（为什么）
3. 找经过（做了什么）
4. 找结果（怎么样）
5. **合并成一句话**：「谁 + 因为什么 + 做了什么 + 结果如何」
6. **再往上提一层**：这句话说明什么？（**这一步常是主旨题的答案**）

### ② 概括后做主次检验

用**奥卡姆剃刀**（A013）逐项问：**删掉它，故事还成立吗？**

### ③ ⭐ 新闻类：导语 → 标题的层次


- **导语**：综合各要素概括成一句话
- **标题**：进一步抓主要要素，丢掉次要一点
- **「新闻标题是新闻最核心、最主要的要素」**

**所以新闻主旨题，答案往往就是"标题那一层"——最少最核心的要素。**

## 五、常见错误

| 错误 | 为什么错 |
|---|---|
| 六要素全保留 | 那是复述，**不是概括** |
| 用次要人物当主语 | 没分清主次人物 |
| 把"经过"的细节当主旨 | 细节是论据，主旨要**再提一层** |
| 说明文/议论文也套六要素 | **体裁不对，方法不对** |

## 五点五、⭐ 补充：事件链不可倒（排序题专用）

> 六要素原卡用于**概括**（抓要素、压成一句话）。
> 但"经过"这个要素，在**排序题**里还有第二个用法：**用动作的先后顺序定句序**。

### 判定动作

把每个句子压成一个**动作**，然后问：**这几个动作在物理上/逻辑上能不能倒过来？**

| 链 | 能不能倒 | 例 |
|---|---|---|
| **事件链** | ❌ 不能 | 发现碎片 → 发掘 → 复原 → 鉴定 → 迁徙 → 下结论 |
| **制作链** | ❌ 不能 | 备料 → 加工 → 组装 → 检验 → 出厂 |
| **认知链** | ❌ 不能 | 观察现象 → 提出假说 → 实验验证 → 得出结论 |

**实例**（2019 浙江 · 西藏披毛犀六句排序）：
```
⑥ 发现一枚犀牛寰椎、一排上颊齿列
③ 经过一周发掘，找到完整头骨、下颌骨、颈椎
④ 这具犀牛头骨在实验室被复原
① 经过鉴定，被确认为全新物种
② 冰期显现后离开高原，形成另三种披毛犀
⑤ 这一发现证实了它是其他三种的祖先
```
→ **⑥③④①②⑤**（发现 → 发掘 → 复原 → 鉴定 → 迁徙 → 结论）
→ 干扰项 **A（⑥④③①⑤②）** 把"**这具**头骨被复原"排到了"找到头骨"**之前** → 事件链倒 + 指称悬空，双错。

> **一句话**：**事件有先后，句子不能倒；倒了的选项，一票否决。**

## 五点六、⭐ 记叙文结构速判：段落长短/位置定功能

**观察**：记叙文各段功能常可通过**篇幅**和**位置**快速推断：
- **开头短段**：常是倒叙引入 / 场景梗概
- **中间长段**：多为「经过」——事件发展的详细描写
- **中间较短段**：多为「起因」或「转折」
- **结尾短段**：多为「感悟/升华/评估」（主旨所在，权重最高）

**实例**（2022 全国甲卷 C 篇）：
| 段 | 篇幅 | 位置 | 推断功能 | 验证 |
|---|---|---|---|---|
| P1 | 短 | 开头 | 倒叙引入/梗概 | 到达南极、企鹅迎接 |
| P4 | 长 | 中间 | 经过 | 登船、旅途见闻 |
| P5 | 短 | 结尾 | 感悟/升华 | precious land, to be respected |

> → 与 B034 的「评估段=主旨」一致；**位置+篇幅是形式证据，情感升华句是语义证据**。

### 主旨题「上下位包含排除」

**规则**：若选项 D 的语义完全被选项 B 包含，则 D 是细节、B 更可能是主旨。

**实例**：
- D. Meeting animals in Antarctica（只覆盖 P1 企鹅、P4 鲸鱼）
- B. An unforgettable experience（覆盖全文 trip）
- D 是 B 的**子集** → 选 B

> → 上下位关系是主旨题排除「以偏概全」的有效工具。

## 五点七、⭐ 哲理型第一人称叙事散文：P1 即中心

**识别**：第一人称 I/we + 叙事中带感悟/理念（非纯讲故事）

**结构**：
- **P1**：直接提出作者理念/感悟（全文中心）
- **P2-Pn**：用亲身经历作例证，具体解释 P1 理念

**做题操作**：
1. 看到 I/we 叙事 → 预判哲理型叙事散文
2. 主旨题/标题题优先回 **P1 找中心句**，而非仅看结尾
3. 后文例子只起支撑作用，不要被细节带偏

**情感转折信号**：
- "The good news is that ..." / "fortunately ..." / "however ..." 等常标志从问题/疑虑转向作者真正要表达的理念
- 转折后 = 作者真正立场/理念

**实例**：
- P1 中心："I can help my own kids learn earlier than I did how to live more with less"
- P2：Georgia 捐赠/售卖物品
- P3-P4：Shepherd 一球之乐
- 主旨/标题 → "Live More with Less"（P1 中心句直接对应）
