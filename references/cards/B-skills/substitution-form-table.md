# 替代形式总表

> **一句话**：英语替代词分非重读（已知信息）和重读（新信息）两档；遇到 one/so/do 先定位类型，再判断焦点。

## 一、用法（这是什么）

系统功能语言学家 & Hasan 给出的替代形式总表：

| 类型 | 语义 | 非重读（已知信息） | 重读（新信息） |
|---|---|---|---|
| **名词性** | 事物（可数名词） | one(s) | the SAME |
| **名词性** | 名物化/过程/修饰语/事实 | so | do/be/say the SAME |
| **动词性** | 过程 | do | DO SO |
| **小句** | 引述/条件/情态（肯定） | so | SO |
| **小句** | 引述/条件/情态（否定） | not | NOT |

## 二、考点（考试怎么考）

1. **完形填空**：根据信息焦点选择非重读或重读形式。
2. **推断题**：通过重音/焦点判断作者强调什么。
3. **改错题**：*I want same → the same；*He did so（若只是简单重复，可能用 do 即可）。
4. **长难句理解**：先定位 one/so/do 属于哪一类替代，再还原被指代内容。

## 三、逻辑（怎么判定）

1. **先看词类环境**：
 - 在名词词组中 → 名词性替代（one/so/the same）
 - 在动词词组中 → 动词性替代（do/do so）
 - 在整句层面 → 小句替代（so/not）
2. **再看信息焦点**：
 - 已知信息、不强调 → 非重读形式（one/so/do）
 - 新信息、要强调 → 重读形式（the SAME/DO SO/SO）
3. **最后看否定**：
 - 小句替代有 not；名词性/动词性替代用 no/not 修饰对应成分。

## 四、英语阅读专属提醒

- 书面语中没有语音强弱，通过上下文和词语选择判断焦点。
- 重读形式往往表示对比或新信息；非重读形式只是延续前文。
- 这张表是处理 one/so/do 多义问题的总纲。

## 五、典型干扰项

| 类型 | 原文 | 错误选项 | 正确选项 |
|---|---|---|---|
| 焦点误判 | I could grow red ones. | 强调"相同" | 强调"红色" |
| 焦点误判 | I could grow the same. | 强调"红色" | 强调"相同" |
| 类型误判 | He said the same. | the same 替代名词 | the same 替代小句/事实 |
| 否定误判 | I hope not. | not 替代名词 | not 替代小句 |
