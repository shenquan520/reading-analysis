# 并列关系

> **一句话**：并列 = **信息层级相同**、在同一**维度**上平行的关系；**概括并列的钥匙是找到那个维度**（上位概念）。

## 一、用法（这是什么）

并列的严格定义是**信息层级相同**——不是"用 and 连接"，也不是"没有重心"。

### ⭐ 重心问题（必须说清）

> **重不重心跟逻辑关系没有任何关系。**
> 权重由**主旨**定，不由"这是不是并列"定。

概括方法讲义里**两种情况都举了例子**：

| 情况 | 说明 | 出现频率 |
|---|---|---|
| **无重心的并列** | a 与 b **对称、等价、地位相等** | **更常出现** |
| **有重心的并列** | 形式并列，但主旨让其中一方更重 | 也有，别否认它 |

**用理科说法理解"无重心"**：a and b 时，它们是**对称的、等价的、地位等价的**。

⚠️ 所以：
- **"并列无重心"是常见情况，不是定义**
- 看到并列**不能自动推出"都没重点"**——要回主旨验证

## 二、⭐⭐ 维度（本卡核心）

**并列和递进都需要存在「维度」**：

| 关系 | 维度怎么用 |
|---|---|
| **并列** | 各项共享**同一个维度** |
| **递进** | 可以在一个维度内递进，也可以从一个维度递进到另一个维度 |

**例子**：
> 中国、美国、英国 —— 它们的维度是「**国家**」

### ⭐ 概括并列的方法：先掌握维度

> **概括并列关系，要先找到它们的维度。**
> **维度 = 上位概念 = 概括的结果。**

| 并列项 | 维度（上位概念） |
|---|---|
| 中国、美国、英国 | 国家 |
| 苹果、香蕉、橘子 | 水果 |
| 红、蓝、绿 | 颜色 |
| 跑步、游泳、骑车 | 运动 |

**这跟「信息层级」完全一致**：
- 并列项 = 同层
- **维度 = 上一层**
- 概括 = 从同层提取上层 → **就是提取维度**

## 三、考点（考试怎么考）

1. **概括题**：给一组并列项，要求概括 → **找维度**
2. **七选五**：空缺在"分述"位置 → 选项应与前后**同维度、同层级**
3. **干扰项**：
 - **取一丢多**：只说其中一项（以偏概全）——注意这属于"以偏概全"，不是并列特有的
 - **维度错**：用了近似的维度但不对（如把"国家"说成"城市"）
 - **层级错**：把上层说成下层，或反之

## 四、逻辑（怎么判定）

1. **看层级**：各项是否在同一信息层级？
2. **⭐ 找维度**：它们共享什么上位概念？（找不到共同维度 → 可能不是真并列）
3. **判断重心**：回到**主旨**看有没有侧重（不要默认无重心）
4. **概括**：维度就是概括结果

## 五、典型干扰项

| 干扰项 | 怎么错的 |
|---|---|
| 只提一个并列项 | 以偏概全（取一丢多） |
| 维度找错 | 上位概念不对 |
| 层级跳错 | 把"分"说成"总"或反之 |
| 默认"并列都没重点" | 忽略了有重心的并列 |
