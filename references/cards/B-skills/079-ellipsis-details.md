# B079 省略细节（零替代 / 数的一致 / 缩略红线）

> **一句话**：省略 = **零替代**——必须能被结构还原；all/both/any 作主词有数的坑，be/have 的肯定形式绝不能缩略。

## 一、总原则：省略 = 零替代

- 省略必须**有结构预设**——能被前文结构还原才合法；还原不了的"省略"是理解断点信号
- **衔接省略必须用指称项替代被预设成分**（书内批注）：省略不是"没了"，是"零形式的指称"

## 二、数的一致坑

| 主词 | 规则 | 例/坑 |
|---|---|---|
| **all/both** | 可省略中心名词；**回指单数名词词组时表现为复数** | 前面说 the team（单数），后面 all are... 里 all 预设 team 成员群 |
| **any/no/either/neither** | 作主词时**单复数区别被中和** | Any of the books works? 单复数都可，靠语境判 |
| **any of them** | ⚠️ **是指称，不是省略** | of them 给了完整指称对象，不属于零替代 |

- all/both 的**指代范围可能有歧义**——靠上下文和结构并列判断
- 指示词（this/that/these/those/which）和所有格也可作省略名词词组主词

## 三、比较级/最高级省略

- **the + 比较级 单独作主语/宾语 = 省略中心名词**：I'll buy you some prettier.（= prettier ones）
- **无 the 的比较级在表语位置通常不是省略**
- 歧义与外指：the whiter 可指"更白（for it）"或"两者中更白"；**外指预设**依赖情景：the latest = news/fashion，the weaker = those
- **非最高级/比较级形容词一般不在省略中作主词，颜色词例外**：the green（= the green one）

## 四、动词性省略与缩略红线

- **to 在句末且无词汇项 = 省略了不定式动词**：I'd like to. → to 后动词全省了
- **be / have 的有标记肯定形式（is, has, was, had）不能缩略**：
 - Yes, he **is**. ✅ / Yes, he's. ❌
 - 答句、强调肯定时，完整形式是硬规则
- 判断动词省略：**必须看共现语境**——没有共现动词词组可还原，就不是省略
