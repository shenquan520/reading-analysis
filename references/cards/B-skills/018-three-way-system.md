# 复句三分系统（因果 / 并列 / 转折）

> **一句话**：汉语语法学家把复句关系划为**三大块**——因果类、并列类、转折类；**每块下含三种细分**。判断关系时**先看大类别，再细分具体句型**。

## 一、思想源流

- **出处**：汉语语法学家复句研究教材
- 原文："本书里，我们把复句的关系类别划分为**三大块，即因果类复句、并列类复句和转折类复句**，并由此建构汉语的复句三分系统。"
- 配套方法：**"从关系出发，用标志控制"**
- **记录**：螺丝（2026-09-01 提炼）

## 二、⭐ 三大类及各自三种细分

### A 组 · 因果类

| 细分 | 标志 | 例句 |
|---|---|---|
| **据实说明因果** | 因为…所以… | **因为**老师有事，下午我们自学 |
| **据理推断因果** | 既然…就… | **既然**老师有事，下午我们自学 |
| **假言推断因果** | 如果…就… | **如果**老师有事，下午我们自学 |

### B 组 · 并列类

| 细分 | 标志 | 例句 |
|---|---|---|
| **并列** | 既…又… | 同学们**既**划了船，**又**参观了博物馆 |
| **连贯** | 先…然后… | 同学们**先**划了船，**然后**参观了博物馆 |
| **递进** | 不但…而且… | 同学们**不但**划了船，**而且**参观了博物馆 |

### C 组 · 转折类

| 细分 | 标志 | 例句 |
|---|---|---|
| **直转** | …可是… | 这套书很贵，**可是**我也买回来了 |
| **让步转折** | 虽然…也… | **虽然**这套书很贵，我也买回来了 |
| **假转** | …否则… | 这套书很贵，**否则**我就买回来了 |

## 三、⭐ 与英语的对应

| 汉语三分 | 英语 discourse relation |
|---|---|
| **因果类** | cause / result / reason / condition |
| **并列类** | coordination / addition / sequence |
| **转折类** | contrast / concession |

**对应英语标志**：
| 三分 | 英语常见标志 |
|---|---|
| 因果 | because / since / as / so / therefore / if |
| 并列 | and / both…and / not only…but also / then |
| 转折 | but / however / although / though / yet / otherwise |

**判断价值**：英语阅读中判断篇章逻辑关系，**先看大关系类别，再细分具体句型**。

## 四、判定步骤

1. **看大类别**：这组句子是因果、并列，还是转折？
2. **看细分**：是据实/据理/假言？并列/连贯/递进？直转/让步/假转？
3. **回到语义验证**：连接词只是路标（见 A010「显示」功能）
4. **若多种可能**：作者是在"选示"其中一种（见 A010）

## 五、⚠️ 注意：这只是"逻辑关系"的一部分

**三分系统管的是「复句层面的逻辑关系」**——主要指分句之间的逻辑。

**但语篇中的「关系」不止这一种**（编者 2026-09-01 指出）：

| 层次 | 关系类型 | 例子 |
|---|---|---|
| **复句 / 逻辑** | 因果、并列、转折、递进、让步、条件、假设、目的、选择 | 因为…所以… |
| **认知 / 哲学** | **现象与本质**、内容与形式、偶然与必然、主要与次要 | 透过现象看本质 |
| **篇章结构** | 总-分、问题-解决、现象-解释、观点-论据 | 总分关系 |

**三分系统只覆盖第一行。** 分析时不要以为"关系"只有逻辑关系。
