# B081 选词填空槽位过滤三步（15选10）

> **一句话**：选词填空先不看词义——**语法槽位定词性（能定掉 8 成空）→ 语义搭配二筛 → 主题验证收尾**。

## 一、第一步：语法槽位定词性（CET-4 第一过滤器）

| 槽位信号 | 定什么 | 例 |
|---|---|---|
| **并列结构**（X and strategic） | 与并列项同词性 | 26 题：and strategic → 形容词 → complex |
| **than + __ + 过去分词** | 副词 | 27 题：than __ known → previously |
| **to be + __ + by** | 过去分词（被动） | 28 题：be __ by those → accepted |
| **从句缺谓语 + 主语单数** | 三单动词 | 29 题：what __ a reputation → constitutes |
| **介词 + __** | 动名词 | 30 题：for __ a reputation → building |
| **will/can + __** | 动词原形 | 31/32 题：vary / understand |
| **冠词/形容词 + __** | 名词 | 33 题：different __ → audiences |
| **动词词组中（pop __ into）** | 副词 | 35 题：suddenly |

> 词库 15 个词先按词性分堆（名词/动词/形容词/副词），每堆只剩 2-4 个候选——**分堆先于选词**。

## 二、第二步：语义搭配二筛

1. **固定搭配**（B012）：build a reputation 这类直接锁死
2. **发出者/承受者**（B013/A024）：28 题孩子是被接纳方 → accepted 不选 selected
3. **反义互补**（B072）：34 题 succeed in...and where they __ → 互补位 → struggle
4. **同义复现**（B011）：31 题 alter（上文）→ vary

## 三、第三步：主题验证

把所选词代回全文主旨（研究类文章：结论词性方向是否与"新发现"一致）——27 题 previously 呼应 new findings。
