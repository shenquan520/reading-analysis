# 指称与指代消歧

> **一句话**：it/this/that/they/the 等指称词的作用是"靠参照他物来解释"——做题时**往上找最近的、语义匹配的先行词**，语义优先于语法。这是代词指代题的理论依据。

## 一、用法（这是什么）

指称是衔接五类型之首：用代词/指示词/比较词指向语篇内外的对象。

**四分法**：
```
外指（指向情景）── 内指（指向语篇）
 ├── 回指（向上文）⭐ 最常见
 └── 下指（向下文）⭐ 罕见（this 是唯一重要的下指衔接）
```

**三类型**：
- 人称指称：he / she / it / they / his / her
- 指示指称：this / that / the / here / there / now / then
- 比较指称：same / similar / different / more / better

## 二、考点（考试怎么考）

1. **代词指代题**：it/this/they 指什么 → 往上找语义匹配的先行词
2. **七选五代词铁律**：空后出现 they/it/this → 空前必须有它的指代对象
3. **it 的延伸指称**：it 可指整个事件/过程/现象（不只具体人/物）——高频考点
4. **the 的识别**：the + 名词 = 特指某个已提过的对象（回指确认）

## 三、逻辑（怎么判定）⭐ 消歧三步

1. **语义优先**：找与指称词语义匹配的先行词（性别/数/可不可数/语义类别）
2. **倾向 ≠ 必然**（编者 2026-09-02 纠正）：前句的**话题起点（主位）**是**可能的**指称目标之一，但**指代不一定指主语**——可指向宾语、定语、甚至整句/整个事件（见上文 it 的延伸指称）。**具体指向什么，靠语义匹配判断，不同文本各不相同**
3. **就近原则**：多个候选时，取最近的语义匹配项；若最近的不匹配再往上找

**⚠️ 两条术语澄清（编者 2026-09-02）**：
1. **主位 ≠ 主语**：主位 = 句子的**话题起点**，可以是主语，也可以是时间/地点状语、宾语前置、整个小句等。若一个词在句子里永远等于主语，那"主位"这个概念就没有存在必要——它的价值恰恰在于**话题不一定是主语**（如 "Yesterday I..." 里 Yesterday 是主位，主语是 I）。做题若拿不准，直接问"这句在谈谁的什么事"即可，不必绕术语。
2. **指代对象 = 具体情况具体分析**：代词可能回指主语、宾语、定语、整句事件——**没有"默认指主语"的规则**，唯一的裁判是语义匹配（本卡第一步）。

## 四、英语阅读专属提醒

- **有指称形式 ≠ 有指称关系**：them 可能与先行词不是相同指称；it/this 可能指宾语而非指称——不要见代词就认定回指
- **指称可消除前句歧义**：前句本身歧义时（如 a play），后续指称项（it）可帮助锁定所指
- **him ≠ John（定指性差异）**：用代词回指恰恰是为了锁定"那个特定的人"——这是回指存在的根本理由
- **the 的典型功能是回指确认**；下指仅见于文学悬念等特殊用法——日常文本按回指读，文学文本留意例外
- **this/that 有情感距离**：this=说话者说过/情感近；that=对话者说过/情感远
- **人称转换不破坏衔接**：转述引语中 I 的衔接功能等于 he（指称对象没变，链不断）

## 五、典型干扰项

| 类型 | 原文 | 错误选项 | 正确选项 |
|---|---|---|---|
| 指代落空 | "John told **his** mother. She was upset." | 把 She 指成 John | She = John's mother |
| 延伸指称漏看 | "He missed the bus. **This** made him late." | This = the bus | This = 错过公交这件事 |
| 就近误判 | "The cat chased the dog. **It** was scared." | It = the cat | It = the dog（语义：被追的害怕） |

## 六、⭐ 补充：指称件的「反向用法」与「正向用法」（2026-09-01 实战补）

> 上面五节讲的都是**被动消歧**（给你一个代词，找它指谁）。
> 实战里更常用的是另外两个方向——**卡里原本没有，本次补上**。

### 6.1 反向用法：后句代词**规定**空处必须是什么

空缺题（七选五 / 完形）里，**空后那句开头的代词会反过来约束空处内容**：

| 空后出现的 | 空处必须提供 |
|---|---|
| `It / This / That / Such` | 一个**可被回指的事件/做法/命题**（注意：it 常指整件事，不只是名词） |
| `They / Them / These` | 一个**复数名词** |
| `It can help…` / `This will…` | 一个**具体措施**（结果句需要措施作主语） |
| `He / She` | 一个**具体的人**（性别要一致） |

**⚠️ 强度说明（2026-09-01 更正）**：它是**强过滤器，不是判定器**。
实例：2014 新课标1 第 38 空后是 `There are a dozen different things you can do with **them**` —— `them` 要求空处含复数名词，7 个选项里带复数的仍有 **4 个**（materials / characters+stories / jobs / ideas），**还得靠语义再筛一层**。
→ 不要以为"有代词 = 一击命中"，它只是把范围砍掉一半。

### 6.2 正向用法：用「有无前指件」定句序（排序题）

见 **B014 语句排序**第 1 步：
- **无前指件**（不含代词、不含承接副词）→ **可作首句**
- **前指件悬空**（`这具头骨` 排在"头骨"首次出现之前）→ **该选项直接排除**

### 6.3 衔接件悬空 = 判多余项的通用法（七选五）

选项身上挂的前指件（`And` / `another` / `this skill` / `This knowledge` / `them`）**在原文找不到落点 → 判为多余项**。
详见 **B004 第三节**。

## ⭐⭐ 同一替换：外延相同才可换，内涵可以不同（编者 2026-09-01 补）

### 原理（编者口述）

> **同一替换一般指的是：在这个语境下，它的外延相同，它的内涵可以不一样——这种情况才能统一替换。**

| 概念 | 是什么 | 例子 |
|---|---|---|
| **外延** | 在语境里**指向的那个对象** | "晨星"和"暮星"都指金星——外延相同 |
| **内涵** | 表达式**携带的描述属性** | "晨星"=清晨出现的那颗；"暮星"=傍晚出现的那颗——内涵不同 |

**同一替换的成立条件**：外延同一（语境下指同一个对象）→ 指称上可以互换；
**但内涵不必相同**——换了之后，**描述属性的信息就变了**。

### 三种情况

| 情况 | 能否替换指称 | 例子 |
|---|---|---|
| **外延同 + 内涵异** | ✅ 可以（但信息有别） | "那个高个子" = "我们队长"（同一个人，描述不同） |
| **外延异** | ❌ 不可以 | "John...John"（B013 专名误判：不必然同一人） |
| 表面相似、外延不清 | ⚠️ 先验证再说 | "the Fawn...the Fawn"（the 提供同指标记才锁定） |

### 做题应用

1. **指代/指称题**：判定替换是否成立，**只问一件事——语境下外延是否同一**（是否指向同一个对象）。别被内涵描述的差异骗了。
2. **同义替换选项（七选五/细节题）**：两个层次检查——
 - 第一层：**外延**同不同？（选项的说法和原文是否指向同一个对象/事实）
 - 第二层：**内涵**变没变？（属性、程度、侧重点是否被偷换——"晨星"换成"暮星"，指称没错但侧重点变了）
 - ⭐ 命题人最爱在**第二层**设错：指称没错，**内涵被偷换**（程度加重、属性增删、侧重点偏移）
3. **与专名误判的关系**：专名误判（John...John）是"外延不清就当同一"——同一替换原则的反面教材。

### 来源

- 编者口述（2026-09-01）
- 逻辑学背景：同一性替换原则（莱布尼茨律）+ 内涵语境对它的破坏（弗雷格语义学经典论文的经典问题）
- **⭐ 语义学正名（2026-09-01 补）**：语义学家语义学教材Ch2/Ch6 为「外延同、内涵可异」给出学术表述——
 1. **同义词的限制定义**（Ch2 书 14）：几乎找不到概念意义与社会意义都相同的两个词（"真同义词不存在"）→ 语义学家把 **synonymy 限定为概念意义等价**，让概念同义词在语体上对照：steed（诗）/ horse（通用）/ nag（俚）/ gee-gee（儿语）——**同一批马，换了词，社会意义全变**。这就是"外延相同才可换、内涵不同信息就变"的语义学版本。
 2. **准同义词至少跨两个平面**（Ch2 书 21）：stick/put 不只差语体——*?He stuck the key slowly in his pocket* 不成立，证明还有概念差（"carelessly and quickly put"）。→ 同义替换检查不能只查一层。
 3. **同义的最终检验在句子层**（Ch6 书 98）：孤立比 scared/frightened 会被情感/语体杂音干扰；**放进句子按真假判**——选项与原文能否同真同假。"放回原句验证"由此有了方法论根据。
 4. **同义=成分式相同**（Ch6 书 90）：adult 与 grown-up 同义因共享 +HUMAN +ADULT；义项不齐（多义词）时同义关系不成立——呼应上文"义项对齐"。
 详见 理论拆解笔记 条目 4/10/15。

## 七、⭐ 题文同序 + that 唯一一句 = 画线词题锁定

> 代词指代题（it/this/that）的标准解法在第三节"消歧三步"，但**画线词 that 题**（"that 指代什么"）有一个更快的两步法，讲义明示。

### 7.1 画线词 that 题的"题文同序 + 唯一一句"法

**判定动作（两步锁定唯一候选）**：

| 步骤 | 动作 | 原理 |
|---|---|---|
| **第一步** | 找**上一题**的定位句/段（题文同序） | 细节题考查顺序 = 文章细节出现顺序 |
| **第二步** | 在上一题定位句/段**之后**、画线 that **之前**之间找**唯一一句** | that 是代词，必有且只有一个指代对象 |

**为什么"唯一一句"**：
- that 指代 = 紧邻上文**最近**且**语义匹配**的对象
- 题文同序保证上一题在 that 之前
- 两者之间**通常只有一句**（代词不会跨越大段指代）

### 7.2 实例

**题干**：What does the underlined word "that" in paragraph 2 refer to?

**应用两步法**：
1. **找上一题 定位**：「What made Mr. Bissell return to Uzbekistan?」→ 答案在 P1（still attracted to the country）
2. **P1 末之后 + P2 that 之前** 找唯一一句：
 > P1 末：「he returned to Uzbekistan to write an article about the disappearance of the Aral Sea.」
 > P2：「His visit, however, ended up involving a lot more than **that**. Hence this book...」
3. → 唯一候选 = "write an article about the disappearance of the Aral Sea" → 选 D（Writing an article about the Aral Sea）

**讲义要点**：
that 作代词指代的一定是上文已出现的内容；细节题的考查顺序与文章细节出现顺序一致——两条合用可锁定答案区。

### 7.3 与消歧三步的关系

- **消歧三步**（语义/主位/就近）= 通用代词指代题解法
- **题文同序+唯一一句** = 画线词 that 题的**快速锁定法**（当 that 在题文中明确画线时）

**做题顺序**：
1. 看到画线词 that 题 → 试用"题文同序+唯一一句"快速锁定
2. 锁定后用消歧三步验证（语义是否匹配）

### 7.4 段落首句 that 回指上段核心，优先抓转折后重点

**场景**：画线词 that 出现在**段落首句**（尤其是 P3 首句指代 P2 内容）

**判定动作**：
1. 回看上段，找核心事件/问题/态度
2. 若上段含 **Despite / However / But / though** 等转折，that 优先指代**转折后的重点/问题**
3. 用态度极性验证：若 that 后动词为 change / solve / address 等，that 常指代一个**负态度问题**

**实例**：
- P2 转折后："the jazz audience continues to shrink and grow older, and the music has failed to connect with younger generations"
- P3 首句："It's Jason Moran's job to help change **that**."
- → that = jazz 不受年轻人欢迎 / 听众萎缩的问题

**讲义要点**：that 只能指代前文内容；它出现在第三段首句，所以指向第二段——重点抓第二段转折之后的负态度。

## ⭐ all this 指代复数
- **规则**：this 单数形式受 **all** 修饰时（all this = 所有这一切）可指代**复数**内容——七选五中勿因 this 形式单数而误杀复指多项列举的选项。
- **适用题型**：七选五还原 / 阅读理解指代题。

## ⭐ this 回指动作
- **规则**：空后出现 "help you do this / by doing this" 类结构 → this 回指**动作**，填入句必含**动词短语**（如 show yourself some forgiveness）；只含名词概念的选项不合格。
- **适用题型**：七选五还原 / 指代题。

## ⭐ 动作宾语反推指代
- **规则**：选项中的代词（them/it）指代不明时，用**谓语动作的宾语特征**反推——"竖着插在食物里/交叉使用"的宾语只能是筷子（stick upright / cross 限定宾语形状与用法）→ F 锁定 37 空。
- **适用题型**：七选五还原 / 指代题。

## ⭐ these+复数名词→填句含复数可指代项
- **规则**：空后 "In these places / these centers..." → 填入句必须提供**复数**地点/事物作指代对象；唯一含复数可指代项（recovery centers / Healing Gardens）的选项锁定。
- **适用题型**：七选五还原 / 指代题。

## ⭐ 与词汇衔接的边界（编者 2026-09-01 终裁 #9）

系统功能语言学家：词汇衔接**独立于指称**——靠同义/反义/上下义就能成立，不需要共同所指；但实战中两者**常伴生**（复现链与指称链织在一起）。做题两条链分别查：指称词问"指什么"，复现词问"跟哪呼应"。
