# 空后信号词的反向约束（下句规定上句）

> **一句话**：别只问"这个空该说什么"，要问"**空后面的那个词，要求前面的空必须是什么**"——`Instead` 要求空处是被否定的做法，`Or` 要求空处是同型疑问句，`By doing` 要求空处是 How 设问。

> **口诀**：**往下看一个词，往上定一句话。**

---

## 一、用法（这是什么）

常规做法是"看上文推下文"（顺向）。但空缺题里，**空后的信号词往往给出更硬的约束**——因为信号词本身带有**未完成的关系预设**，它要求前一句长成特定形状。这叫**反向约束**。

### 反向约束清单（⭐ 优先级从高到低）

| 空后出现的词 | 它要求空处必须是什么 | 强度 |
|---|---|---|
| **`Instead`** | 一个**被排除的做法 / 担忧 / 误解**（常含否定或负面揣测） | ⭐⭐⭐ 一击命中 |
| **`Or`**（句首） | 一个**同型的疑问句**（或同型的并列项） | ⭐⭐⭐ |
| **`But` / `However` / `Yet`** | 一个**语义方向相反**的陈述 | ⭐⭐⭐ |
| **`It` / `They` / `This` / `Such`** | 一个**可被回指**的内容（注意单复数） | ⭐⭐ 强过滤器，非判定器 |
| **`them` / `these`** | 一个**复数名词** | ⭐⭐ 同上 |
| **`By + doing`** | 一个 **How 设问**（`How can we…?`） | ⭐⭐⭐ |
| **`For example` / `例如`** | 一个**断言 / 概括**（例子不能证例子） | ⭐⭐⭐ |
| **`Because` / `That's why`** | 一个**结果** / 一个**原因**（方向别搞反） | ⭐⭐⭐ |
| **`So` / `Therefore`** | 一个**原因或前提** | ⭐⭐ |
| **`list / the following / write down`** | 一个**清单标题或指令**，下句必是清单 | ⭐⭐ |
| **`The reason why… is due to…` / `这是因为…`** | 一个**需要被解释的现象**（不是原因本身） | ⭐⭐⭐ |

---

## 二、考点（命题人怎么动手脚）

1. **反向约束是命题人的"送分口"**：他必须保证答案唯一，所以常把信号词留在空后。**看不到它 = 白丢分**。
2. **方向反了不报错**：填进去读起来"也通顺"，但逻辑打架（如 Instead 前填正面建议）。
3. **连词在空后 vs 在空内**：连词在**空后** → 约束空处；连词在**选项开头** → 约束选项的上文（B004 衔接件检验）。**两种情况都要查。**

---

## 三、逻辑（怎么判定 · 能照做）

1. **定位空位后，先读空后第一句的第一个词**（连词 / 代词 / 副词 / 介词短语）。
2. **查上表**，写出"空处必须满足的关系预设"。
3. **拿这个预设去筛选项**——不满足的直接划。
4. **若空后无信号词**（无标连接，B026），改用 B024 第二步"问功能"。
5. **回填**：把选项放进去，检查空后那个信号词**还成不成立**。

### ⭐ 联合用法：空前最后一个词 + 空后第一个词，两边都要看（2026-09-01 补）

一个空被**两个信号词夹住**时，取两条约束的**交集**，命中率远高于只看一边。

**实例**（2016 新课标1 第 40 空）：
> 「**[空]** **However**, it is **also hard** to keep a code book secret for long.」

| 信号词 | 约束 | 筛后剩余 |
|---|---|---|
| 空后 `However` | 空处须是"看起来站得住、但后文要反驳"的说法 | 5 个 |
| 空后 `also hard` | `also` 要求同极 → 空处须含"难"（B010） | **1 个** |
| **交集** | → **A**「It is **very hard** to break a code without the code book.」 | ✅ |

> **操作提示**：别只盯着空后。**空前的最后一个实词**（尤其是 just / only / not / doesn't 这类）同样会规定空处。

## 四、典型干扰项（原文 · 错项 · 正项 三栏）

| 原文空位 | 错误选项（为什么错） | 正确选项 |
|---|---|---|
| 「…be thankful for all of the good in your life. **（?）** **Instead**, it's a healthy way to work through…」 | **D.** Remember that you can expect the best in return.（**正面建议**，与 Instead 打架：Instead 前须是被否定的担忧） | **G.** Seeing the positive side of things **doesn't mean** you're ignoring what happened.（否定式澄清，正好被 Instead 接走） |
| 「First of all, decide what you want from that person. **（2）** **Or** do you just want to be physically fit…?」 | **C.** You'll work harder if you train with someone else.（陈述句，`Or` 无法并列） | **D.** Do you want to be a better athlete in your favorite sport?（`Or` 要求同型疑问句） |
| 「The jobs of the future have not yet been invented. **36** **By** helping them develop classic skills…」 | **B.** And we can't forget science education.（`By doing` 是答语，需要前句是 How 设问） | **F.** So how can we help our kids prepare for jobs that don't yet exist?（How 设问 → By 作答） |

---

## 五、英语阅读专属提醒

- `Instead` 是**最强的反向约束词**——它要求前句是一个"看起来对但要被排除的"命题。看到 Instead，直接找含 `doesn't mean` / `not` / `seems` / `might seem` 的选项。
- `By + doing` 作**答语**时，前句一定是 `How` 问句；但 `By + doing` 也可能只是**方式状语**，此时不触发约束。**判据：看它在不在句首 + 前句是不是问句。**
