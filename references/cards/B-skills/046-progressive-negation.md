# B046 递进否定信号（Even-Worse Intensification Marker / Progressive Negation）

> **一句话**：段落或句子中含 `Even worse / Worse still / What was even worse / 更糟的是` 等递进否定信号时，**该句/段=对前文否定的进一步加深**（不是新论点）。判定：① 信号词本身含 worse 否定；② 后半句是对前句否定的"再否定"或"加重"。
> **口诀**：**见 Even worse，不是新论点，是旧否定再加重。**

**判定步骤**：
1. 看句/段是否有 Even worse / Worse still 等递进否定标志
2. 看前半句是否已含否定
3. 看后半句是否比前半句更负向（行动 < 观念 / 重结果 < 轻结果）
4. 推论：该句=对前段否定的**递进加深**，正项必匹配更负向的事实

**干扰项三栏**：
- 原文：P4「girls are less likely to say ... 'really, really smart.' **Even worse**, girls act on that belief: ... they start to avoid activities ...」
- 错项：They think themselves smart（态度反向）/ They look up to great thinkers（无中生有）/ They see gender differences earlier（以偏概全）
- 正项：They are likely to be influenced by social beliefs（act on belief = influenced）

**英文名别名**：Even-Worse Intensification Marker / Progressive Negation
**scope**：高考（议论文 / 推断题）

**实战验证**：2021 全国甲卷 D 篇—— "Even worse" 锁定"信念→行动"递进
