# B058 议论文六规则（论证方法手册第八章）

> **一句话**：韦斯顿的议论文六规则 = 英语议论文的标准骨架——**开门见山 → 明确主张 → 路线图 → 驳反对意见 → 求反馈 → 谦虚**；读 D 篇议论文先找"路线图"，全篇骨架立现。

## 一、六规则总表

| 规则 | 是什么 | 对英语阅读的价值 |
|---|---|---|
| **34 开门见山** | 直入实际问题，砍掉空话开头 | ⭐ **主旨句定位**：砍掉空话后的第一句实义句 = 主张 |
| **35 明确主张** | 建议要具体；结论必须存在 | 找不到主张的文章（评议型）→ **结论常在末段直说** |
| **36 遵循提纲** | 首段末给**路线图**，主体每前提一段，长文引回路线图 | ⭐⭐ **段落地图**：读议论文先抓路线图段，全篇结构立现 |
| **37 驳反对意见** | 花篇幅呈现反对论证再驳（两层：釜底抽薪 + 反向比较） | ⭐ 让步-反驳段标准形状（已入 B053） |
| **38 搜集反馈** | 写作是过程，靠他人眼睛发现问题 | （无阅读应用） |
| **39 要谦虚** | 结论据实以告，不说死话 | ⭐⭐ **态度词库**：判断作者态度的依据 |

## 二、⭐⭐ 规则 36：路线图 = 英语议论文的段落地图

**原书**：「议论文骨架 = ① 开头总概括段（用一小段把基本论证连结论整体呈现 = 路线图）② 每个前提一段：重申前提 → 展开 → 证明 ③ 复杂前提内部嵌套 ④ 长文适时引回路线图 ⑤ 全文靠术语一致联结」

**做题操作**：
1. **首段末句**找路线图（预告全篇结构）——**读完它，全篇骨架就出来了**
2. **主体段首句** = 重申该段前提（= 段落主题句，呼应 B048）
3. **引回信号**："as noted above / to return to our earlier point" = 作者在提醒你"我们走到哪了"
4. 长文读不懂时，**回头找路线图重新定位**

## 三、⭐⭐ 规则 39：态度词库（作者态度题的依据）

| 结尾用词 | 态度 |
|---|---|
| remains uncertain / worth trying / overall promising | **谨慎支持** |
| no objection stands / we must act now | 强势断言（好文章少见） |

**做题**：态度题正确项的"谨慎程度"通常与作者一致——作者说"值得一试"，选项不能选"必须马上做"。

## 四、⭐⭐ 问题—解决型议论文：P1 负态度词 → 后文找 solution

**识别信号**：
1. P1 出现 **worse / struggle / uncomfortable / fail / problem** 等负态度词，描述一个不良现状
2. P2 常用 **But / However** 转折，提出解决/主张："the next time ..., consider that ..." / "... is worth the trouble"
3. 后文用专家观点、研究、例子论证该 solution 的好处

**做题操作**：
- 主旨/标题题：**不选“问题”当标题**（如 Uncomfortable Silence），应选指向 solution/论点的选项（如 Benefits of Small Talk）
- 长难句论点识别：**But + 时间状语从句（the next time / the moment ...），逗号后祈使句/主句 = 作者主张**
- 适用题型：阅读理解主旨题、标题题、态度题；**不适用七选五还原**

## 五、规则 34/35：主旨句定位

- **主张** = 首段砍掉空话后的**第一句实义句**
- 空话开头特征：「几个世纪以来，哲学家们一直在争论……」→ 跳过
- 正确开头：「本文将证明……」→ 直接定位
- **评议型文章**（比较两方）→ 结论常是"双方均无定论"，在**末段直说**——别硬找主张

## 六、⭐⭐ 复杂议论文 P1 结构：论点句 → 展开句 → 引用/例子

**识别**：北京卷/难题常见 P1 结构：
1. **S1 论点句**：研究者共识 / 作者主张（最重要）
2. **S2 展开句**：解释/细节/后果
3. **S3 引用/例子**：专家引用、数据、案例（服务论点，读不懂可跳过）

**做题操作**：
- 读不懂全文时，**只抓 S1 论点句**
- 引用/例子题（如 “作者引用 X 主要是为了”）→ 回 S1 论点判断功能
- 引用在论点之后 → **强化/解释论点**；引用在论点之前 → 才可能引出话题

**实例**：
- S1: "short-termism is now a significant problem in industrialised societies"（论点）
- S2: "The inability to engage with longer-term causes and consequences leads to some of the world's most serious problems..."（展开）
- S3: Francis Cole quote（引用，强化问题）
- → 引用目的 = highlight a problem

## 九、⭐⭐ 抽象说明文/议论文“看不懂也无所谓”策略

**场景**：北京卷 C/D 篇、研究类说明文、抽象议论文，专业术语多、句子复杂，考生容易“看不懂”。

**核心策略**：细节读不懂 ≠ 题做不对。把精力集中在**主题词 + 作者态度**上，宏观题（态度、主旨、标题、部分推断）往往能直接解决。

**判定动作**：
1. 快速定位主题词：首段反复出现的核心名词（如 ALife / short-termism / systems thinking）
2. 判断作者态度：
 - 找正/负态度词：unavoidable / significant / essential / promising（正）vs problem / fail / uncertain（负）
 - 看末段：作者常在末段明确态度或升华
3. 用“主题 + 态度”过滤选项：
 - 与主题无关 → 排除（如把类比对象 AI 当主题）
 - 与作者态度相反 → 排除
 - 方向正确但未升华 → 比较概括度

**实例**：
- 主题：ALife（人工生命研究）
- 作者态度：正（P5「the rise of ALife will prove unavoidable」）
- 态度题：supportive ✅ / puzzled / unconcerned / doubtful ❌
- 标题题：D「Life Evolves. Can Attempts to Create ALife Evolve, Too?」✅（含 ALife + evolve + attempts）
- 「你只要抓住了文章主题，这四道题目就很简单。」「看不懂也无所谓。」

> **一句话**：抽象文章抓主题和态度，看不懂细节也能做对宏观题。

## 十、⭐⭐ 北京卷 3 题抽象文章：速战速决 + 例子段服务主题

**场景**：北京卷 C 篇有时只有 3 道题（标准 4 题），说明文章要求高但题目要求低，应快速解题。

**判定动作**：
1. 看到 3 道题 → 提醒自己：**不必读懂全文，速战速决**
2. 首段设问/引入 → 作用 = introduce the topic（不是 illustrate/highlight/predict）
3. 文中例子段（如 P3 "Take nutrition"）→ 直接判为服务于前文的论点段（P2 systems thinking），例子本身不是主旨

**实例**：
-：P1 问题 → introduce the topic ✅
-：P3 nutrition 例子 → 答案必须指向 systems thinking 目标未实现，不能在 nutrition 本身兜圈子
- 「三道题的文章，要求相对较低，你要牢记四个字：速战速决。」「例子在为第二段服务。」

## 十一、⭐⭐ 评议型议论文：作者“没主见”也能写议论文

**场景**：作者自己不直接表态，而是借两位专家/多方观点表达正反两方，自己只作总结或表示信任。

**判定动作**：
1. 识别文体：文中出现多位专家、不同观点、作者用 "I trust both" / "both have a point" 等总结
2. 态度题：找作者对引用对象的**情感共鸣词**（sympathetic / share concerns / trust）
3. 词义题：注意作者选取的褒贬词与主题态度一致（如 prone to hype = 负态度 → open to 炒作）

**实例**：
- 主题：quantum computing 炒作问题
- Johnson：负态度（担忧炒作）
- Taylor：部分正态度（PyQuantum 例外）
- 作者：trust both → 对 Johnson 的担忧 sympathetic
- 标题：D「Will Quantum Computing Ever Live Up to Its Hype?」= 点出“炒作”核心
- 「作者在议论文里的态度只能通过两种方式呈现——不是自己亲口表述，就是借助别人的观点表达。」「用别人的嘴说自己的观点，而且同时兼具正反两种观点，这就是这篇议论文有个性的地方。」

> **一句话**：作者不表态时，态度题看“作者信任谁/共鸣谁”，标题题抓全文争议核心词。

## 十二、⭐⭐ 实战补：标志词定位法 + 北京卷 策略 + 双 however 合并 + 例证型议论文转折段分界

### 12.1 议论文标志词定位法
- **场景**：议论文 D 篇找首尾段重点信息 / 主旨在哪。
- **规则**：标志词是论证推进的**显式锚点**，比"段间关系"更可照做——
 | 标志词 | 之后 = 重点 |
 |---|---|
 | **however / but / yet** | 转折后 = 重点（常是首段负态度 / 问题） |
 | **should / must / need** | 建议后 = 重点（常是末段主张 / 措施） |
 | **moreover / furthermore** | 递进后 = 重点（补充论点） |
 | **therefore / thus** | 总结后 = 重点（结论） |
- **实例**： 标志词 however 之后 = 首段负态度（Disapproving）； 标志词 should 之后 = 末段建议（autonomy/self-regulation）。明示「标志词 however/should 之后」是首尾段重点。
- **做题应用**：做议论文先扫标志词，定位效率高于通读。

### 12.2 北京卷 结构题战略性放弃
- **场景**：北京卷 D 篇最后一道结构题（树状图）。
- **规则**：北京卷已确定**不再考这种题目**（2024 起），遇到可**战略性放弃**，把时间留给其他题。
- **实例**：明示「北京卷已经确定不再考这种题目，所以最后这道难题可以忽略不计」。
- **注意**：平时练习仍需识别"多 SP 嵌套"结构以训练结构感，但考试实战可跳过。

### 12.3 双 however 合并为 Introduction
- **场景**：多段各含一个转折词（如 P1、P2 各一个 however）。
- **规则**：多段各含转折词 → **通常合并为同一功能段**（如 Introduction），呼应转折/并列边界判断。
- **实例**：P1+P2 两个 however 分别引入问题 → 合并为 Introduction。「第一段和第二段里各有一个标志词 however」→ 两段合并。
- **做题应用**：遇到连续段都带转折词，先归为同一功能块，再找后续 Point/Sub-point。

### 12.4 例证型议论文转折段 = 主客观分界线
- **场景**：议论文用大段例子（含"误解"）引入，再用转折段亮出作者主张。
- **规则**：**转折前 = 例子（常含"误解"），转折后 = 正解（作者主张）**。以转折段（However / But）为界，前一半是客观/主观的混淆，后一半是作者真正主张。
- **实例**：P2 是 "An example at hand"（父母干预=例子，含"误认为态度变化"的误解）；P3 "However" 之后 = 正解（技术解释一切）。「以第三段为界线，哪部分是技术，哪部分是态度」。
- **做题应用**：例证型议论文主旨题，答案在转折**后**，不在例子段。

## 十三、⭐⭐ 文章存在性公理

- **规则**：作者针对某问题写文章，恰是因为**问题目前未被重视或没有明确解决方法**——文章的存在 = 唤醒公众意识或提出建议的尝试。「作者之所以会针对某个问题写一篇文章，肯定是问题目前没有得到重视，或没有明确解决方法。」
- **做题应用**：主旨/推断题中，「问题已引起公众关注」「问题已被解决/已受重视」类选项**通常是错的**——它们削弱了文章存在的必要性（如 2017 北京卷 C 篇 B 项 the outbreak attracts public attention）。
- **适用题型**：阅读理解·推断题 / 主旨题 / 态度题；不适用七选五还原。

## 十四、⭐⭐ 纸老虎判型

- **场景**：长篇（400+ 词）科技议论文，段落多、人名多、例子多，看似可怕。
- **规则**：先扫**首段第二句（真问题）+ 末段首句（结论）**——若主题与态度一目了然（如「AI 会造成问题 + 负态度」），此文即"纸老虎"：一戳就破，四道题全靠主题+态度方向秒杀，细节与人名例子全忽略。
- **判定动作**：1) 首题（常考首段重点）答案 = 全文方向锚；2) 后续题先用方向筛（无负态度的选项先排）；3) 方向对但内容不合的，回原文定位。
- **讲义要点**：第一题决定你对全文方向的理解是否正确——开局就抓住作者对 AI 的负态度，后面几题几乎顺推即得。
- **适用题型**：阅读理解·全题型（科技议论文）；不适用七选五还原。

## 十五、⭐⭐ 跨段同义词呼应 = 段间合并判据

- **场景**：判断哪几段是同一功能块（结构题 / 段落作用题 / 多段主旨题）。
- **规则**：两段讲同一弊端或同一主张时，必有**跨段同义复现**——如 P4 "regulate their social behavior" ≈ P5 "monitor and shape student behavior"；有同义呼应 → 合并为一个功能块（本例 P4-5 同为 Point2 的反面论证，SP1/SP2）。
- **配套**：双 however 段合并为 Introduction（12.3）；"equally important" 是并列方案层的显式标志（P3↔P4）。
- **适用题型**：阅读理解·结构题 / 段落作用题；不适用七选五还原。

## 十六、⭐ 议论文末段"改变观点"选项必错
- **规则**：议论文末段推断题中，「作者会改变观点/会放弃主张/很快改变计划」类选项**必错**——作者写这篇文章就是为了表达并坚持立场。同理「作者很固执」这类负评价推断也不合理——**作者写文不会让你推断出贬低作者本人的结论**。
- **配套**：十三 文章存在性公理（作者写文=问题未被重视/无解）。
- **适用题型**：阅读理解·推断题；不适用七选五还原。

## 十七、⭐ 态度词库的语用显影点（2026-09-01 互引，何自然语用学教材）

规则 39 的态度词库管"**用什么词**"，本节补"**在哪儿看**"——作者态度的三个语用显影处（态度题答案常不在明示态度句）：
1. **话语标记语**：actually=警告 / anyway=劝阻 / after all=建议 / still=规劝 / well=委婉 → 详见 **B070**
2. **感情变调**：not bad=有保留赞许 / 省略比较=夸张 / 褒词贬境=反语 / 否定强调=绕着请求 → 详见 **B073**
3. **违反准则处**：答非所问（关系）/信息不足（量）/字面失实（质）→ 详见 **B027**
