# 议论文论点句是骨架

> **一句话**：议论文的中心论点、分论点和概括性语句是文章的"骨架"，其他内容都是围着骨架长的肉；找到骨架，结构题和主旨题就解了一半。

## 一、用法（这是什么）

议论文的骨架由三类句子构成：
1. **中心论点**：作者要证明的核心观点。
2. **分论点**：支撑中心论点的几个侧面。
3. **概括性语句**：段首/段尾承上启下、总结过渡的句子。

英语标记词：
- 论点提出：`argue / claim / contend / maintain / believe / suggest`
- 承上启下：`however / therefore / in addition / on the contrary / in conclusion`
- 总结重申：`in short / in conclusion / to sum up / all in all`

## 二、考点（考试怎么考）

1. **主旨题**：中心论点就是主旨，常在首段末或第二段首。
2. **结构题**：问"某段作用"——往往是分论点/过渡/举例。
3. **例子作用题**：例子是为了证明论点；反面例子是为了反证论点。
4. **段落关系题**：概括性语句是判断段间关系的信号。
5. **作者态度题**：论点句里的形容词/评价动词直接体现态度。

## 三、逻辑（怎么判定）

1. 先读首段末句 / 第二段首句 → 大概率是中心论点。
2. 读每段首句 → 大概率是分论点或过渡句。
3. 遇到 `but / however / yet` → 后面常出现作者真正立场。
4. 遇到 `for example / such as` → 前面是要证明的论点。
5. 遇到 `in conclusion / therefore` → 后面是总结或结论重申。

## 四、英语阅读专属提醒

- 英语议论文作者常把中心论点放在**首段末**，而不是开头第一句。
- 分论点常出现在**段首**，用 `First / Second / Moreover / On the one hand... On the other hand` 等标记。
- 例证题（`Why does the author mention X?`）答案通常是"为了证明某论点"，不是"介绍 X"。
- 类比论证（`A is like B`）是为了用熟悉事物解释抽象论点。

## 五、典型干扰项

| 类型 | 原文 | 错误选项 | 正确选项 |
|---|---|---|---|
| 把例子当论点 | 作者举狄更斯童年例子论证"负重让人进取" | 本文主要介绍狄更斯的成长经历 | 负重能促使人进取 |
| 把铺垫当主旨 | 首段描述社会现象，第二段提出论点 | 本文讨论某种社会现象 | 本文主张某种解决/观点 |
| 忽略结论重申 | 结尾重申中心论点 | 结尾提出新观点 | 结尾强化前文论点 |
| 把反面例子当正面 | 用失败案例反证"心无旁骛"重要 | 作者认为失败不可避免 | 作者强调要专注 |

## 五点五、⭐ 补充：主旨定位三把钥匙 + 干扰项三型（2026-09-01 实战）

> 原卡只讲了"议论文骨架"，**没给"主旨题四个选项怎么选"的操作**。实战补上。

### ① 主旨定位三把钥匙（按可靠性排序）

| 钥匙 | 怎么用 | 例 |
|---|---|---|
| **1. 首尾呼应** | 读首句与末句，圈实词，看是否同义 → 主旨 = 两者的交集 | 2020 福建 CO₂：首"恒定/平衡" ↔ 末"保持不变" → 主旨 = **平衡** |
| **2. 设问的答案** | 找到文中的设问句，**它的答案句就是主旨** | 2018 北京 王国塔：「自降 500 米的原因是什么？**主因就是风**」→ 主旨 = **建筑高度受制于风** |
| **3. 正面对策** | 语篇是"问题→对策"型时，取**正面对策 Y**，丢被否定的 X（B009） | 2019 河南司法所：「不能仅止于道歉自查，**而更应该**严格监管+法律保障」 |

### ② ⭐ 主旨干扰项固定三型

> 主旨四选一里，**错误选项几乎逃不出这三种**：

| 型 | 长什么样 | 破法 |
|---|---|---|
| **A. 问题描述** | 语篇是对策型，却选了"问题有多严重" | 问：这篇是要**解决**它，还是**描述**它？ |
| **B. 被否定的做法 X** | 原文明确说"不能仅止于 X"，选项就是 X | 扫标记词：不能仅止于 / 不是…而是 / rather than |
| **C. 分述细节** | 只覆盖了分述 1 或分述 2 | 问：它能罩住**全部**分述吗？（A013 越级检验的**反向**：这里是不够大） |

### ③ ⭐ 主旨层级优先级：问题 < 结果 < 对策

当一篇同时存在**问题层 / 对策层 / 结果层**时，主旨题取**对策层**：

| 层 | 位置 | 能不能当主旨 |
|---|---|---|
| **问题层** | 常在转折前（"仍存在一定差距"） | ❌ 它是"被解决的那个问题" |
| **对策层** | 常在 `必须 / 应该 / 要` 之后（"必须掌握核心技术"） | ✅ **取这一层** |
| **结果层** | 常在对策之后（"掌握发展主动权"） | ❌ 它是动作带来的结果，不是动作本身 |

**实例**（2019 联考 · 互联网核心技术）：
- A 无中生有（"科技实力的彰显"原文没提）
- **B 取了问题层**（转折前的"仍存在差距"）
- **C 取了结果层**（"掌握主动权"是结果）
- **D ✅ 取了对策层**（"必须掌握核心技术"）

> **⏸ 注意**：本条与七选五讲义书中相应位置 理论要点 3「问题对策对策重要」**一致**；但该讲义另外两条（"虽然但是但是重要""因为所以所以重要"）与主次判定三原则**冲突**，已挂起待编者裁决（TRAINING-STATE K001）。**本条在裁决前照用**，因为它与已被编者确认的三原则不冲突。

### ④ 一句话口诀

> **首尾取交集，设问取答案，正反取正面；问题结果都不选，对策才是主旨。**
