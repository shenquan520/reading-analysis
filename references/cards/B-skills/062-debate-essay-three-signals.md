# B062 辩论类议论文三步识别法（Debate-Essay Three Signals）

> **一句话**：辩论类议论文 = 作者不站队、让正反两方先打——三步识别：**开头争议标志词 → 主体正反两大段 → 作者观点在结尾（赞同/反对/中立三态）**。

## 一、三步识别信号

| 步骤 | 信号 | 操作 |
|---|---|---|
| 1. 定文体 | 开头争议标志词：**heated debate / discussion / controversy / whether / either A or B** | 开头引用可忽略，只抓标志词 + 辩论主题（X 是否 Y） |
| 2. 分阵营 | 主体两大段观点对立；转折标志 = **takes the opposing view**（也可 however 等） | **反向法**：看懂任何一方，取反即另一方；P3 段旨 = P2 观点取反 |
| 3. 找作者 | 作者观点必在两方之后（倒数第二段/末段）；找 **I / these views / both cases** | 三态：赞同某方 / 与两方均不同 / 中立（既不支持也不反对） |

## 二、做题应用

1. **人物观点题**：问 Sauven 就答 Sauven 阵营立场；先**主题词快筛**（选项不含全文主题词 → 排），再分「观点 vs 论据」（细节论据不是人物主张）。
2. **段主旨题**：问反方段 → 正方观点取反；四个选项逐个"取反"检验是否=对方观点，取反后与对方无关的全排（2012 北京 D 篇：C 取反 = P2 立场 ✅）。
3. **作者态度题**：结尾无定论措辞（deserves much more serious thinking / worth debating）= **中立 Objective**；正态度（Optimistic）与负态度（Disapproving/Sceptical）选项均排。
4. **结构题**：CP（争议话题）→ Point1（正方）→ Point2（反方）→ Point3（作者合论）→ C（总结）。

## 三、实例

- P1 "a heated debate on... whether to place wilderness at the heart of what is to be preserved" → 定文体+主题
- P2 John Sauven（绿和）：荒野不可开发；P3 Lee Lane "takes the opposing view"：可开发
- P4 "I look forwards to seeing these views taken further... both cases need to..." → 作者与两方均不同
- P5 "deserves much more serious thinking" → 中立 → Objective ✅
- 辩论类考得少，**了解套路即可**，不必重仓训练。
