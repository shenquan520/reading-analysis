# 卡片库总入口

> 126 张方法卡（B85 + A36 + R5）。分析任何题目**必先来这里检索**——这是铁律二的第一步。

## 检索顺序

1. **按题型快查**：先看 `../QUESTION-TYPE-MAP.md` 的「题型 → 必查卡」对照表，直接定位该题型必查的卡
2. **B 系技能卡**（85 张，答"怎么做"）：`B-skills/INDEX.md` — 逐题解析、干扰项判别、七选五、完形、概括的操作规则
3. **A 系思想卡**（36 张，答"为什么"）：`A-analysis/INDEX.md` — 底层原理：层级、衔接、功能观、双通道等
4. **R 系复盘卡**（5 张，答"怎么防"）：`REVIEW/00-index.md` — 从个人错题提炼的防错规则

## 挂卡要求

- 逐题解析必须标注所用卡号；**零挂卡＝不合格交付**
- 用到了但卡里没有的判断 → 写进「▮缺口」栏（这是卡库进化的源头，禁止留空）

## 新卡入库

写卡前先读 `card-template.md`；新卡放入对应子目录并更新该子目录的 INDEX。
