# Why 维度：为什么

> **一句话**：回答"**为什么**"的那一组关系——⭐ **推断题和作者意图题的主战场**。

**维度**：Why（为什么）　|　**权重**：⭐ 高

---

## 一、这组包含哪些关系

| 关系 | 一句话 | 状态 |
|---|---|---|
| **因果** | 一事为因，一事为果 | ✅ 已裁决 |
| **目的** | 手段所服务的目标 | ✅ 已裁决 |
| **条件** | 前提与结果（与因果**交叉**） | ✅ 已裁决 |
| **让步** | 铺垫 + 重头戏（**预告式**） | ✅ 已裁决 |
| **立场** | 作者的态度、评价、站位 | ⏳ 待裁决 |
| 理由 | （与因果/目的重叠，不单列） | — |

## 二、逐个说明

### ① 因果 ✅
**⭐ 层级不纠结**（编者裁决）：可能同层，也可能不同层。

> **原理**：**我们需要选择适合的层级去表达信息。**
> 有时候把高层级的信息用低层级表达得更具体、更生动。
> - 上提 = 简洁概括
> - **下放** = 更具体生动（高层"他很节俭" → 低层"他把一枚硬币攥出了汗"）

**⭐⭐ 因果 + 留白**（编者原理）：
> **因与果在具体语境中有「可互推性」**——写一方，读者可推出另一方。
> **所以因果可以留白**——这是文学手法。

| 认知功能 | 审美功能 |
|---|---|
| 让读者明白 | 让读者**自己推出来**（留白） |

**概括处理**：⭐ **舍因留果**（"因为草枯萎了，所以踩着更柔软" → 草踩着更柔软）
⚠️ 说明文常考"因"，别一刀切。

**干扰项**：⭐ **因果倒置**（A 导致 B → 说成 B 导致 A）

### ② 目的 ✅
- 标志：so that / in order to / to / for
- ⭐ **目的 = 意图中的结果**（未然）；因果的"果" = 已实现的事实（已然）
- **概括时：目的常比手段更接近主旨**
- ⭐ **目的能反推作者意图**——是"作者维度"的直接入口

### ③ 条件 ✅
**⭐ 与因果：交叉，不是隶属**（编者裁决）

| 区域 | 例子 |
|---|---|
| **交集** | 「**如果**下雨**就**取消」 |
| **条件独有** | 「如果你来我就走」——你来**不是**原因，只是前提 |
| **因果独有** | 「因为下雨所以地湿」——已发生的事实 |

**三种**：充分（只要…就）/ 必要（只有…才）/ 假设（如果…那么）
**⚠️ 高频陷阱**：偷换必要与充分（原文 `only if` → 选项 `if`）

### ④ 让步 ✅
**⭐ 让步 = 预告式结构**（编者裁决：应单列，不与转折合并）

| | 转折 | 让步 |
|---|---|---|
| 定义 | 方向拐弯 | **先承认再转** |
| 预告 | 无 | ⭐ **「虽然」一出，读者就预知重要内容要来** |

**两种**：
- **实言让步**（虽然 = 事实）→ 概括可舍从句
- **虚言让步**（即使 = 假设）→ **不能简单舍**

**⚠️ 与虚言条件区分**：`even if`（结果不随条件变）vs `if`（结果随条件变）

### ⑤ 立场 ⏳
- 立场句是**议论文的骨架**（见 B002）
- 找立场：评价性形容词、转折后的判断、情态动词
- ⭐ 立场属于**作者维度**（你的三维框架）

## 三、⭐ 这组的共同规律

**它们都在回答"为什么"，但角度不同**：

| 关系 | 回答的"为什么" |
|---|---|
| 因果 | **为什么会发生**（原因） |
| 目的 | **为什么要做**（意图） |
| 条件 | **在什么前提下**（前提） |
| 让步 | **为什么后半重要**（铺垫） |
| 立场 | **为什么这么看**（态度） |

**⭐ 所以推断题几乎全在这组**：
> 推断题问的就是"为什么"——不在明面上的那部分。

---

## 四、⭐ 做题怎么用（这组最重要）

### ① 推断题 = 找被省略的 Why

**原文常只写一半，让你推另一半**：
| 原文给了 | 要你推 |
|---|---|
| 果 | **因** |
| 因 | **果** |
| 事实 | **意图/动机** |
| 做法 | **立场** |

### ② 因果倒置干扰项的识别

**检查箭头方向**：回原文确认"A → B"还是"B → A"。

### ③ 目的题：找 so that / to

**题干问 "The purpose is..."** → 回原文找目的标志词。

### ④ 立场题：找评价性语言

形容词、副词、情态动词、转折后的判断句。

### ⑤ ⭐ 检查自己的答案

> 推断题的答案，**必须能从原文推出**，不能是你自己的常识。
> 检验：**这个结论，原文的哪一句支持它？** 找不到 → 错了。

## 五、与其他维度的关系

| 维度 | 关系 |
|---|---|
| **What** | What 是"是什么"，Why 是"为什么"——**举例论证的往往是 Why 组的论点** |
| **How** | How 组是手段，服务于 **Why 组的目的** |
| **A007 关系多元性** | ⭐ 因果/目的/条件常常**同时成立**——看从哪个维度看 |
| **主次三原则** | ⭐ Why 组的成分权重高，但**最终由主旨定** |

## 五点五、实例（均来自原书，带页码）

### ① 因果 · 舍因留果
> 原文："因为这草都枯萎了，所以踩在脚下更感到柔软"
> 概括：**草踩在脚下更感到柔软**

**⭐ 规则**：因果重在"果"——原因是次要的，结果是主要的。

**⚠️ 坑**：不是包含"因为""所以"的就是因果复句。
> "所以出现这些需要研究的领域，说到底是因为环境保护的需要" → 整体是**单句**。

### ② 因果 · 留白（编者原理，例子待补）
> **因与果可互推** → 写一方，读者推出另一方 → **这就是留白**。

**⚠️ 神学家/天文学家的具体例子未在 PDF 中找到（铁律零）——编者 2026-09-01 裁决：不用管了（放弃补正），原理已明确照用。**
**但原理本身已明确**：省略的那一半，往往就是推断题的考点。

### ③ 让步 · 实言 vs 虚言
| | 实言让步 | 虚言让步 |
|---|---|---|
| 标志 | 虽然 / 尽管 | **即使 / 就算 / 哪怕** |
| 承认的是 | **事实** | **假设** |
| 概括 | 可舍从句 | ⭐ **不能简单舍** |

### ④ 立场 · 《爱莲说》
**表面写莲** → **实际表达"不慕名利、洁身自好"的品格**。

**⭐ 这就是托物言志**：读立场要跳过"物"，直取"志"。

### ⑤ 条件 · 必要 vs 充分的偷换
> 原文 `only if`（只有…才）→ 选项换成 `if`（如果…就）→ ❌ **偷换**

**这是推理判断题的经典设错手法。**
