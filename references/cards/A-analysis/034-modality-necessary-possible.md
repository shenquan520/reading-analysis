# A034 模态：必然 vs 可能（含"度"）

> **一句话**：文章说 may/could/some，选项说 must/always/all——**把可能性升格成必然性 = 模态越界**，干扰项最高频手法之一。反向（必然降格成可能）通常是安全的保守项。

## 一、哲学根基

**模态三分**：必然（任何情况下都成立）/ 可能（至少一种情况下成立）/ 不可能——三者之间**只有单向可推**：必然 → 可推出可能；可能 → 推不出必然。

**度（质量互变）**：量的积累到临界点才发生质变——"有助于"与"导致"、"一些人"与"所有人"之间存在度，**说跳档 = 错**。

## 二、判定操作（三步）

1. **圈文章的模态词**：may / might / could / can / tend to / likely / some / suggest / appear
2. **圈选项的模态**：must / always / all / never / cannot / will / prove
3. **比对档位**：
 - 可能 → 必然（升格）= ❌ 越界
 - 必然 → 可能（降格）= ✓ 保守（一般安全）
 - 同档不同词（may = could = might）= ✓ 等价替换

## 三、干扰项原型库

| 原型 | 例子 |
|---|---|
| **some → all**（量的跳档） | 「一些学生受益」→「所有学生受益」 |
| **may → must**（势的跳档） | 「可能延缓」→「必然治愈」 |
| **tend to → will**（趋势→定局） | 「倾向于更健康」→「将会更健康」 |
| **suggest → prove**（证据强度） | 「研究表明暗示」→「已被证明」 |

## 四、与知识网络的咬合

- **B052 推理边界**：B052 管推理**步数**（只许走一步），A034 管推理**强度**（档位不许跳）——步数和强度双重检查
- **A024 程度维**：A024 管"多强"的对照，A034 给出对照的**哲学标尺**（档位单向可推）
