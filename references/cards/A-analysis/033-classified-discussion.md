# A033 分类讨论（按标准切类，对号入座）

> **一句话**：作者把一个对象按某个标准分成几类分别讨论（运动时/静止时、用鼻呼吸的人/口呼吸者、工作联系/亲友群聊）；做题时答案必须与「类」严格对齐——**张冠李戴（把 A 类性质安到 B 类）与抹掉分类限定**是这类文章的两大高频陷阱。

## 一、思想源流（编者 2026-09-02 口述+手写解析原型落地）

议论文和说明文都极常见：**作者不想说绝对的话，就把对象切开，一类一类地说**。

- 呼吸篇原型：「用鼻呼吸的人认知表现更好」vs「口呼吸者」；「运动时宜鼻呼吸、静止时口鼻皆可」——同一种"呼吸"按**场景**和**人群**切成几类分别讨论
- 手机篇原型：紧迫感的来源分三类——软件工程的设计 / 我自己的焦虑 / 两者的结合（"or a combination"）

**为什么作者要分类**：
1. **防绝对化**——全称判断（"所有人/所有情况"）容易被反驳，切成分类的限定判断更严谨
2. **说清机制差异**——不同类的对象机制本来就不同，混在一起讲不清

### ⭐⭐ 分类是什么（编者 2026-09-02 补，源自数学分类讨论思想）

**分类 = 把不确定转化为确定的过程。**

- 为什么不确定？被讨论对象是笼统的（"呼吸""人""紧迫感"），其情况未知
- 分成几类、每一类的情况都掌握了 → **被分类者的具体情况就被完全掌握**——不确定消失
- 做题含义：问「整体如何」的题，任何单一类别都不能代表整体（除非题干已限定某一类）；选项拿一类冒充整体 = 以偏概全

**各分类项之间 = 并列关系**（见下节：并列 ≠ 地位均等）

## 二、判定操作（四步）

1. **识别分类信号**：Some… Others… / when X… when Y… / or a combination / 人物分组（participants vs non-participants）/ 一句话里出现两个以上限定的主语群
2. **找分类标准**：按什么分的？（场景？人群？态度？程度？）——**标准一变，类就全变**
3. **读题先归类**：这道题问的是哪一类的性质？选项说的是哪一类？
4. **对号入座**：类的性质与选项严格比对，错位即错项

## 三、干扰项原型库

| 原型 | 例子 |
|---|---|
| **跨类嫁接**（最高频） | 把「口呼吸者认知差」说成「所有人认知差」；把 A 类好处安到 B 类头上 |
| **偷换分类标准** | 原文按「场景」分类（运动/静止），选项偷换成按「人群」分 |
| **抹掉分类限定** | 「运动时宜鼻呼吸」→ 选项「宜鼻呼吸」（限定没了，变绝对化） |
| **类内混淆** | 三类归因（软件设计/自身焦虑/两者结合）取其一说成唯一原因 |

**与 B083 的分工**：B083 管「这个词在因果链里站什么位置」（主张/结果/机制），A033 管「这个性质属于哪一类」——**先归类，再判位置**，两道关卡串联。

## 四、与知识网络的咬合

- **B011 反义对**：反义=并列（对等对称），但文中突出方由主旨定——分类项同理：**分类项并列 ≠ 每类笔墨均等**，作者可以重点写某一类

- **A003 信息层级**：分类 = 对象层的切分，每一类内部有自己的层级，别跨类比高低
- **A006 语义场流动**：不同类 = 不同语义场，跨类流动要警惕
- **B038 人物代言**：未参与研究者常作为「另一类声音」出现，归类时别跟研究者混
- **B052 推理边界**：文章分类的限定词正是推理的边界线，抹掉限定 = 推理越界
