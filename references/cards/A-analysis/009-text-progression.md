# 语篇推进的三种方式

> **一句话**：语篇往前走有三条动力——**自然流动**（语义场关联）、**空降式流动**（制造逻辑关系）、**结构化推进**（篇章结构指定）。三种可以叠加使用。

## 二、⭐ 三种推进方式对照

| | **自然流动** | **空降式流动** | **结构化推进** |
|---|---|---|---|
| **动力来源** | 语义场关联 | 逻辑关系词 | **篇章结构** |
| **对象关系** | 本来有关联 | 本来无关联 | **结构指定，无需关联** |
| **比喻** | 河水自然流淌 | 人工开凿支流 | **按图纸修渠** |
| **例子** | 图书馆 → 书（包含） | 草莓 → 橘子（递进空降） | 总句说「有 ABC」，下面按顺序讲 A、B、C |
| **作者意图** | 顺着语义走 | 开辟新方向 | **按计划展开** |
| **可预测性** | 中等 | 低（要看关系词） | **高**（结构定好了） |

## 三、⭐ 第三种：结构化推进（本卡重点）

### 总分关系（最典型）

> 开头总句：「我要讲 A，这个东西有 **ABC**」
> 接下来**顺序就是 ABC**，分别详细描述

**关键特征**：
- 对象之间**可能既无语义关联，也无逻辑关系词**
- 靠**结构位置**就知道接下来该讲什么
- 这是**结构决定的推进**，不是语义也不是逻辑

### 其他结构化推进

| 结构 | 推进顺序 |
|---|---|
| **总分** | 总 → 分 1 / 分 2 / 分 3 |
| **问题-解决** | 问题 → 原因 → 对策 |
| **现象-解释** | 现象 → 解释 → 例证 |
| **时间顺序** | 按时间先后 |
| **议论文** | 论点 → 论据 1/2/3 → 结论 |
| **对比结构** | A 面 → B 面 → 结论 |

## 四、三种方式与信息层级的关系

| 推进方式 | 层级变化 |
|---|---|
| **自然流动** | 通常**同层**，或渐变层（上下义时跨层） |
| **空降式流动** | 并列/转折**同层**；**总分跨层** |
| **结构化推进** | **明确跨层**（总在上层，分在下层） |

**这跟功能观一致**：结构化推进的每一步，功能是**结构指定的**（这是总起、这是分述、这是收束）。

## 五、⭐ 做题怎么用

### 概括

- 认出**结构化推进** → 直接按结构取舍：**总句留下，分述按需要**
- 讲义编者的规则：「议论文丢论据留论点」——论据就是**结构化推进里的"分"**

### 七选五

1. 先判断这段是**哪种推进**
2. **结构化推进** → 看空缺在结构中的**位置**（是"分 2"还是"结论"？）
3. 若在"分"的位置 → 选项应与前后的分述项**并列同层**（同层级对应原则，A005）
4. 若在"总"的位置 → 选项应是**上层概括**，能覆盖下面所有分述

### 主旨题

- 结构化推进里，**总句 = 主旨**（信息层级最高）
- 分述句是支撑，**权重由主旨定**（不是由"是不是述位"定）

## 六、三种方式的叠加

真实语篇里三种往往**同时存在**：

> 「**阅读有三把钥匙**：信息层级、功能观、流动性。**信息层级**看纵向位置……**而且**（空降）**功能观**看起什么作用……」

- **结构化推进**（总分：三把钥匙 → 分述）
- **自然流动**（信息层级 → 层级，同词复现）
- **空降式流动**（"而且"开凿支流引出下一个概念）

**分析时三种都要看，不要只盯一种。**
