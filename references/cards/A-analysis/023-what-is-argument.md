# 论证 = 理由支持结论

> **一句话**：论证不是吵架不是表态，是「拿出说服你自己的理由」给结论撑腰——阅读的全部论证分析都建立在这一句上。

## 一、用法（这是什么）
讲义的定义：论证（argument）= 拿出一组理由或证据支持一个结论。两个要件缺一不可：**结论**（要撑的主张）+ **前提**（撑它的理由）。词典里「争论」义是俗用，不是本书义。
两大用途：①**探究**——答案未知时用论证筛选观点；②**辩护**——已有结论后说服他人。名句：「持有与众不同的观点并不是错误。错误在于，除此之外你什么都没有。」

## 二、考点（考试怎么考）
1. 主旨题的本质 = 找全篇的**结论**；其余段落绝大多数是**前提**。
2. 态度/论证评估类材料：分辨作者靠证据说话还是靠情绪词说话（诱导性言论不构成论证）。
3. 理解对立观点题：检验标准是「能否想象对方为何坚信」——想象不出来说明没读懂。

## 三、逻辑（怎么判定）
1. 问「作者最想让我接受哪句话」→ 那是结论。
2. 问「他拿什么撑」→ 那是前提；前提可能是例子、数据、权威、类比、因果（本书第二至六章分别展开）。
3. 前提撑不住（不可靠/无代表性/有反例）→ 结论力量打折 → 这是命题人最爱下手的缝。

## 四、英语阅读专属提醒
- 英语议论文结构高度程式化：结论常在首段末或末段，前提按「例证/数据/权威」分兵把口——先抓结论再回读，比逐句读省一半力。
- 让步结构（it is true that... / admittedly）是作者主动摆出的「表面反例」，作用是先破后立，别当成作者真立场。

## 五、典型干扰项
1. 把**前提**当主旨：首段的长例子只是撑腰的，结论句往往在其后（therefore / thus 引出）。
2. 把**情绪词浓度**当观点强度：满纸 exclamation 与「作者态度鲜明」无关，看理由质量。
3. 让步句当立场：admittedly X, but Y——作者立场是 Y 不是 X。

## 六、来源与版本
- 思想源流：安东尼·讲义论证方法讲义（A Rulebook for Arguments）导论 + 第一章规则 1-3；「理由支持结论」的规则手册传统可上溯亚里士多德《论题篇》。
- 为什么重要：全 skill 的论证维度（立论/驳论、论证方式分类）都以这个定义为公理；B002（论点句是骨架）、B017（例证题）、B050（举例论证五问）都是它的下游。
- 容易混淆：论证 vs 争论；结论 vs 观点（无理由支撑的观点不成论证）；前提可靠 ≠ 推理有效（规则 3 只管前提）。
