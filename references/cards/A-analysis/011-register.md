# 语域与语篇的定义

> **一句话**：**语篇 = 衔接 + 语域一致性**——两个条件缺一不可。衔接管内部连贯，语域管与情景的适配。

## 一、思想源流

- **出处**：系统功能语言学家衔接理论教材第一章
- 原句：
 语篇成立的三个条件：情景语境连贯、语域一致、自身衔接连贯——三者齐备才算语篇。
 情景和语义看似能连起来的话语，缺了衔接手段就不成其为语篇。
 反过来，衔接做得再完美，缺语境一致性（与情景统一的语义连贯）也照样不成语篇。

---

## 二、⭐ 语域三要素

| 要素 | 英文 | 问什么 |
|---|---|---|
| **话语范围** | field | 在讲**什么领域/事件**？ |
| **话语方式** | mode | **口头还是书面**？即席还是有准备？ |
| **话语基调** | tenor | 作者与读者的**关系**？（亲疏/位阶/正式度） |

**例子**（原书推算语域类型）：
> - 范围："晚上进行的个人交流"
> - 目的："借讲述熟悉的事件以增添感情"
> - 方式："口头独白、想象的叙述、即席谈话"
> - 基调："亲密、母亲和三岁孩子"
> → 推断：这是**儿童睡前的故事语言**

---

## 三、⭐ 语篇的完整定义（最重要）

> **语篇 = 衔接 + 语域一致性**

两个维度**缺一不可**：

| 情况 | 结果 |
|---|---|
| 语义连贯 + 语域一致，但**缺衔接** | ❌ 不成其为语篇 |
| **衔接完美**，但缺语境一致性 | ❌ 不成其为语篇 |
| 衔接 ✓ + 语域一致 ✓ | ✅ 完整语篇 |

**这是全书第一章的收尾结论**，也是分析任何语篇的**总纲**。

---

## 四、为什么重要

1. **判断"这是不是一段完整语篇"**——两个维度都要查
2. **判定文章类型**——用三要素反推
3. **理解作者的适配意图**——他为什么用这种口气、这种媒介
4. **解释"语法对但读着别扭"**——往往是语域不一致

## 六、做题怎么用

1. **拿到一篇文章**，先用三要素定性：什么领域？书面还是口头？作者什么身份、对谁说？
2. **判定体裁**：说明文 / 议论文 / 新闻 / 广告 / 故事……
3. **检查一致性**：某段口气突然变了？→ 可能是**转折**或**引用**，注意作者意图
4. **验证主旨**：主旨要同时符合**内部衔接**和**语域适配**

### 例子
- 一篇"说明文"里突然出现亲密的口语 → 很可能是**举例**或**设问**，不是主旨句
- 广告里出现权威数据 → 语域混合，目的在说服
