# A035 主观 vs 客观

> **一句话**：作者观点 ≠ 客观事实——把"X 认为/似乎"说成"X 是"（观点事实化），或把数据说成作者夸张（事实观点化），都是**主客观串门**；### ⭐ 用武之地边界（考研批 case-205 实测）

本卡适合**题干定性**（author holds/suggests → 锁主观侧，Q35 命中）；**不适合选项排除**——同骨架四选项全在主观侧时无区分力（Q33 零贡献）。选项排除交给 B083 逐位比对。，细节题答事实，别串。

## 一、哲学根基

**主观** = 依赖主体的判断、态度、推测（换个人说可能不一样）；**客观** = 独立于主体的可核查事实（数据、实验结果、历史事件）。

休谟的二分："是"（is，事实陈述）与"应当/感觉"（ought/opinion，价值与立场）不能互相推出——**事实推不出态度，态度也改变不了事实**。

## 二、判定操作（三步）

1. **给文中命题贴标签**：
 - 主观侧信号：believe / argue / suggest / appear / seem / in one's view / 形容词评价（genuine joy, impressive）
 - 客观侧信号：study found / data show / according to / 数字 / 时间地点事件
2. **看题问哪边**：态度题（attitude/tone/agree with）→ 问主观；细节题（according to the passage）→ 问客观事实
3. **选项比对是否串门**：跨了侧 = 错项

### 用词分工注记（预防混淆）

- **证据**（evidence）= 客观侧：数据、实验结果、统计（数据段卡 B056 用这个词）
- **论据**（论证的支撑）= 议论侧：理由、事例、引用（论证结构卡用这个词）
- 两者都"支撑"，但证据是客观事实、论据可以是主观理由——A/B 消融语境下勿混用

## 三、干扰项原型库

| 原型 | 例子 |
|---|---|
| **观点事实化**（最高频） | 作者"认为阅读有益" → 选项"阅读被证明有益" |
| **事实观点化** | "研究显示 60%" → 选项"作者夸大了数字" |
| **张冠李戴于立场** | 把反方观点说成作者的（B038 人物代言管"谁在说"，本卡管"说的是什么性质"） |
| **态度强度错位** | 作者 mild 怀疑 → 选项 strong opposition（与 A034 模态咬合） |

## 四、与知识网络的咬合

- **B056 态度词**：B056 管态度词的**定性**（positive/negative/neutral），A035 管这句话**是事实还是立场**——先定性再查串门
- **B038 人物代言**：B038 管"谁在说"（人物的立场功能），A035 管"说的是什么性质"——两句检查串联
