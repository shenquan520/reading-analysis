# 语义分析多维（主体·动作·承受者·情感色彩·程度·时间·空间·特殊要素）

> **一句话**：分析任何一个句子/信息单元，从多个维度拆——**谁（主体）做了什么（动作）对谁（承受者），带什么感情色彩，到什么程度，何时何地，有无金钱/数字等硬信息**（2026-09-02 编者扩展：原五维 + 时间/空间/特殊要素）。这是**语义层的通用脚手架**，与五问框架（信息层）互补。

**提出**：编者（2026-09-01）

---

## 一、五维定义

| 维度 | 问什么 | 例子（"他粗暴地拒绝了所有提议"） |
|---|---|---|
| **主体** | 谁在动（动作发出者） | 他 |
| **动作** | 做了什么（过程） | 拒绝 |
| **承受者** | 作用于谁/什么（受事） | 所有提议 |
| **情感色彩** | 褒/贬/中性（评价） | 粗暴地（贬） |
| **程度** | 多强/多大/多彻底 | 所有（全量） |
| **时间**（2026-09-02 编者扩） | 何时/先后/频率 | —— |
| **空间**（2026-09-02 编者扩） | 何地/范围/方向 | —— |
| **特殊要素**（2026-09-02 编者扩） | 金钱/数字/专有名词等"硬信息" | —— |

## 三、⭐ 做题用法：五维对照法（干扰项识别）

选项和原文**逐维对照**，任何一维被换掉就是错：

| 维度 | 命题人怎么偷换 | 识别 |
|---|---|---|
| 主体 | 张冠李戴（A 做的安到 B 头上） | 问：动作是谁发出的？ |
| 动作 | 换过程（"批评"→"表扬"） | 问：原句到底做了什么？ |
| 承受者 | 偷换对象（作用于 X→作用于 Y） | 问：动作作用在谁身上？ |
| **情感色彩** | ⭐ 褒贬反转（"担忧"→"乐观"；"批评"→"支持"） | 问：作者态度是正还是负？ |
| **程度** | ⭐ 量度被改（程度/频率/时间/范围/确定性被加大或缩小："几乎"→"很多"；"偶尔"→"经常"；"可能"→"必然"；"部分"→"全部"） | 问：量度对不对？是几乎还是很多？是偶尔还是经常？是可能还是必然？ |

**⭐ 程度包含四类**（编者 2026-09-01 补充，不只是范围）：

| 类型 | 例子 | 偷换 |
|---|---|---|
| **范围**（数量） | "有些学生" → "所有学生" | 部分 ↔ 全部 |
| **频率**（次数） | "几乎总是" → "很多"；"偶尔" → "经常" | 高频 ↔ 低频 |
| **时间**（时态/长短） | "曾经" → "一直"；"暂时" → "永久" | 时段 ↔ 持续 |
| **确定性**（语气强弱） | "可能" → "必然"；"据说" → "事实" | 推测 ↔ 断言 |

**核心规律**：
> **前三维错 → 是"事实错"**（细节题丢分）；**后二维错 → 是"态度/程度错"**（推断题丢分）。
> 主旨题、态度题、推断题，**后二维（情感色彩/程度）几乎必考**。

## 四、⭐ 与信息层级的配合

同样的语义内容，可以选择不同层级表达（呼应"选择层级表达信息"）：

| | 低层级表达 | 高层级表达 |
|---|---|---|
| 例 | "他把一枚硬币攥出了汗" | "他很节俭" |
| 五维 | 动作具体、程度暗含（攥出汗=程度强） | 动作抽象、程度藏进"很" |

**做题含义**：选项把具体表达概括成抽象时，**程度和情感色彩可能被偷换**——"攥出汗"（程度极强）被概括成"节俭"（程度弱）就是错的。

## 五、实战三步

1. **拆**：先按五维拆原句（主体/动作/承受者/情感色彩/程度）
2. **对**：选项逐维对照原文
3. **判**：哪一维变了？变了的那维是不是考点？（情感色彩/程度 → 高度警惕）

## 六、⭐ 学术支点：语义学家语义学教材与五维的对接（2026-09-01 圈读 Ch2/Ch6）

- **后二维的体系位置**：语义学家七种意义里，**情感色彩维 ↔ 情感意义+内涵意义**（联想意义层），**程度维 ↔ 极性对立的"规范"**。联想意义开放不定、只能用尺度刻画（Osgood 语义微分三维度：评价/力度/活动）——五维的"后二维难判"不是错觉，是**结构性的**（概念义有限可判，联想义开放只可估）。
- **⭐ 程度维的语义学家补丁：程度永远相对"规范"，规范有三重**（Ch6 书 102）：
 1. **对象规范**：*a small alsatian* 推不出 *a small dog*——"小"是相对德国牧羊犬的规范；干扰项把"对 A 类对象的小"偷换成"对整个类的小"= 程度偷换的经典机制（young man 17–30 vs young archbishop 45–60）。
 2. **说话人规范**：评价词（beautiful/ugly/good/bad）可"对甲真对乙假"——**不兼容规则在评价词上放松**，所以"作者认为 X 好"≠"X 客观好"。
 3. **角色规范**：good boss = "会当老板"——好/坏相对角色期待。
 → 做题加一问：**程度/评价是相对什么规范说的？规范被换了吗？**
- **情感维的语义学家补丁：情感意义是寄生范畴**（Ch2 书 16）——作者态度多靠**语体选择**（正式/随便）和**内涵词**间接承载，很少直接说；所以态度题答案常不在"明示态度句"，而在用词的礼貌度与褒贬色彩里。
