# 语篇 = 衔接 + 语域一致性

> **一句话**：一段话要成为"语篇"（text），必须同时满足两个条件——**内部有衔接**（五种手段）+ **外部与语境一致**（语域三要素）。缺一个都不是完整语篇。

## 一、用法（这是什么）

系统功能语言学家 对"语篇"的精确定义：

```
语篇 = 衔接（cohesion）+ 语域一致性（register consistency）
```

- **衔接**：内部条件——句子之间靠五种手段连起来
- **语域一致性**：外部条件——整段话在"话语范围（field）/ 话语方式（mode）/ 话语基调（tenor）"三个维度上保持一致
- 语篇是**语义单位**，不是语法单位；长度无限制（一个词"NO SMOKING"到整本书都算）

**判断标准**："这段话是不是一个整体？" → 内部看衔接，外部看话题/风格是否统一。

## 二、为什么重要

1. **解释"为什么这段读起来连贯"**：不是玄学，是可指认的条件（衔接 + 语域一致）
2. **解释"为什么这段读起来散"**：缺衔接，或语域不一致（话题乱跳/风格突变）
3. **衔接是必要非充分条件**：有衔接不一定成语篇（机械堆砌连接词也散）；没衔接一定不成语篇

## 三、容易混淆

| 概念 | 是什么 | 区别 |
|---|---|---|
| 衔接 cohesion | 形式手段（指代/连接/复现…） | 看得见，能指出来 |
| 连贯 coherence | 语义效果（读起来通顺） | 看不见，靠理解 |
| 语域一致性 | 与语境匹配（话题/风格统一） | 外部条件 |
| 语篇性 texture | 成为语篇的全部条件 | = 衔接 + 语域一致性 |

## 四、英语阅读专属提醒

- **语篇性 = 程度问题（紧密 vs 松散）**：不是有/无二分，而是密集度问题。《爱丽丝漫游奇境记》在紧密/松散间交替。**遇到"脱节"段落可能是有意的松散设计**（文学/诗歌尤其），别急着判错
- **新语篇的判定**：大多数情况下，新语篇开始于一句与上文无衔接之时 → 划分段落/话题边界就看衔接是否断裂
- **衔接使解码成为可能**：阅读理解 = 靠衔接补缺。读不懂时先找"这句靠什么衔接"，比查单词更有效

## 五、典型干扰项（对做题的直接应用）

| 题型 | 应用 |
|---|---|
| 段落排序 | 先按衔接断裂处划边界，再排 |
| 主旨题 | 语域一致性 = 全文话题统一 → 正确项要覆盖同一话题 |
| 七选五 | 选项要与前后既有衔接又有语域一致（话题匹配） |
