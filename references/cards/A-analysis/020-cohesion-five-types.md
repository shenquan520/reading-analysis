# 衔接五类型总架构

> **一句话**：衔接（cohesion）有五种手段——指称、替代、省略、连接、词汇衔接；前四种是语法手段，词汇衔接靠词汇选择。**这张卡是 Halliday 衔接理论的完整知识地图。**

## 一、用法（这是什么）

语篇里"句子之间靠什么连起来"，Halliday & Hasan 归纳出五种可识别的衔接手段：

| 类型 | 本质 | 层次 | 例子 |
|---|---|---|---|
| **指称** Reference | 靠参照他物来解释 | 语义层 | he / this / the / more |
| **替代** Substitution | 语法占位替换语项 | 词汇语法层 | one / do / so / the same |
| **省略** Ellipsis | 零替代，省去可恢复成分 | 词汇语法层 | Yes, I have. / He might. |
| **连接** Conjunction | 通过特定意义间接预设 | 语义层 | but / so / then / however |
| **词汇衔接** Lexical | 靠词汇选择产生衔接 | 词汇层 | 复现 / 搭配 / 概括名词 |

**一句话心法**：指称/替代/省略直接提供"已有的词"（语法关系）；连接通过语义间接预设（语义关系）；词汇衔接靠词汇选择（词汇关系）。

## 二、考点（考试怎么考）

1. **七选五 = 测衔接**：空后有代词→指称；段首空→连接；段中空→词汇复现。五类当清单用，不漏线索
2. **代词指代题 = 测指称**：it/this/they 回指对象要在上文找得到
3. **完形填空 = 测词汇衔接**：同义/反义/上下义/搭配都是选项依据
4. **段落排序 = 测连接**：转折/因果/时间信号词决定段序

## 三、逻辑（怎么判定）

1. **看到代词/指示词/the** → 问"它指谁" → 指称
2. **看到 one/do/so/the same** → 问"它替换了什么" → 替代
3. **看到"缺成分但能补"** → 问"靠什么结构预设恢复" → 省略
4. **看到连接词** → 问"什么逻辑关系" → 连接
5. **看到重复/同义/反义/搭配词** → 词汇衔接

## 四、英语阅读专属提醒

- **衔接 ≠ 连贯**：衔接是形式手段（看得见），连贯是语义效果（靠理解）。衔接是连贯的必要非充分条件
- **衔接形式之间非泾渭分明**：so/one/that 可同时属多个类别，判断看语境中的具体使用方式
- **专有名词重复 = 词汇衔接，不是指称**（John...John 不等于同一个人，需 he 标记）

## 五、典型干扰项

| 类型 | 原文 | 错误选项 | 正确选项 |
|---|---|---|---|
| 指称落空 | "The dog barked. **It** ran away." | 把 it 理解为另一只狗 | it = the dog |
| 复现漏看 | "...apple, banana, and orange..." | 选与 fruit 无关的项 | 选项含 fruit/这些水果 |
| 连接误判 | "He worked hard. **However**, he failed." | 说成因果 | 转折（与预期相反） |
