# 卡片统一模板 · Reading Skill Card Template

> 所有卡片按本模板填内容。六节固定，缺哪节填"（暂无）"不许跳。

## 两个系列（写卡前先确定属于哪个）

| | **A 语言分析卡**（思想卡） | **B 阅读技能卡** |
|---|---|---|
| 存放位置 | `cards/A-analysis/` | `cards/B-skills/` |
| 回答什么 | 这是什么？为什么？ | 怎么用？怎么判？ |
| 内容重心 | 理论、概念、体系、思想源流 | 用法、考点、判定步骤、干扰项 |
| 使用场景 | 主动翻阅、系统学习 | 做题时小蓝字调出 |
| 是否投入功能 | 待用户决定 | 是 |
| 额外要求 | 思想源流 / 为什么重要 / 容易混淆 必写 | 判定步骤要能照做 / 干扰项给实例 |

**A 是地基，B 是工具。** 用户明确要求两个系列都做，A 系列先供学习，看完再决定是否投入功能。

文件名：`cards/A-analysis/<主题>.md` 或 `cards/B-skills/<编号>-<名称>.md`，用知识点名（中文或英文，简洁）。

## 写卡规则

1. **一段一卡**：一个知识点一张卡，不混
2. **例子要短**：例子用一句话能讲清就别用一段
3. **每个考点要配一个具体陷阱**：抽象说"要注意 X" 不算考点，要"看到 A 选 X 是错的"
4. **逻辑节必须能照做**：判定步骤能让用户照着判，模糊的话不许写
5. **来源必标**：三方合写时三行都列；冲突时按 SKILL.md 铁律"先问用户以哪个为准"
6. **scope 标签**：高考/CET4/CET6 哪个考哪个标，没有就"通用"
7. **可点击唤起的简短别名**：卡内第一行 `<知识点>` 用**简短、能预测**的标签，方便在题目解析里出现"并列关系"→ 直接索引到这张卡

## 触发与展示（与 SKILL.md 的"卡片调阅"对接）

- **触发**：题目解析里出现知识标签（如"并列关系""因果倒置""张冠李戴"）
- **索引方式**：卡的文件名/别名一致 → 自动匹配
- **展示形态**：浮层卡片（小蓝字点开后浮出），不是整页跳转
