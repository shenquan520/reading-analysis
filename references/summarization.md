# 概括层：从句子到主旨

> **这一层的地位**：`discourse-relations.md` 回答"句与句是什么关系"，
> 这一层回答"这些句子合起来在说什么"。
> **关系 → 概括 → 主旨**，是一条完整的链。
>
> **理论来源**：概括方法讲义（待提供后深化）。骨架部分为通用原理。
>
> **状态**：骨架已成型，等电子版提供后补充书中方法并与 `discourse-relations.md` 整合。

---

## 零、为什么概括这么重要

- 主旨题 = 概括全文
- 段落大意题 = 概括一段
- 推断题 = 概括之后往外推一步
- **能不能概括出来，是检验"真懂没懂"的唯一标准**

读懂了但概括不出来 = 其实没懂，只是每个单词都认识而已。

---

## 一、概括的操作定义

**概括 = 保留主干，删掉细节，用一个更高层的概念把一组具体内容"包"起来。**

核心动作：**上移一个抽象层级** —— 往上找一个能覆盖它们的词。

| 原材料 | 上移一层 | 再上移 |
|---|---|---|
| 苹果、香蕉、橘子 | 水果 | 农产品 |
| 种树、立法、做宣传 | 环保措施 | 政策手段 |
| 焦虑、失眠、注意力下降 | 心理问题 | 健康影响 |

**上移几层取决于要概括的范围**：概括一段，上移一层；概括全文，上移两层。

---

## 二、好概括的三条自检标准

1. **覆盖性** —— 能覆盖所有被概括的内容，不漏
2. **不溢出** —— 不超出原文范围，没说的不能算进去
3. **无细节** —— 里面不该出现具体例子、数字、人名（除非主题本身就是这个）

### 两种典型的不合格概括

| 毛病 | 表现 | 对应干扰项 |
|---|---|---|
| **太窄** | 只覆盖了一部分内容 | 以偏概全 |
| **太宽** | 超出文章讨论范围 | 无中生有的变体 |

**主旨题的排除法就是这两条**：太宽杀掉，太窄杀掉，剩下的比对偏离。

---

## 三、概括的四个动作（怎么做出一个好概括）

| 动作 | 干什么 |
|---|---|
| **删** | 删掉重复、举例、修饰语、具体数据 |
| **留** | 留下主题词和高频实词（反复出现的实词 = 主题） |
| **换** | 把具体内容换成上位词（上移抽象层级） |
| **连** | 把剩下的用逻辑关系连成一句话 |

**顺序不能乱**：先删，再留，再换，最后连。跳到"连"会得到一锅粥。

---

## 四、从句子概括到篇章概括

### 句旨（概括一句话）
找主谓宾，去修饰语。长难句先按 `core-principles.md` 第六节剥主干，再概括。

### 段旨（概括一段）
- **有主题句**：改写主题句。**别照抄** —— 主题句常是具体表述，要上移一层
- **无主题句**：把各句分别概括 → 合并 → 再上移一层
- **有转折**：取转折之后的部分为段旨，之前的是铺垫

### 篇旨（概括全文）
1. 各段段旨串联
2. 判篇章模式（见 `discourse-relations.md` 第五节）
3. **抓重心段** —— 转折段、总结段、反驳段，重心在这些段里
4. 合并后上移一层

---

## 五、概括与主旨题（直接应用）

**主旨题 = 篇旨的选项化表达。**

判定顺序（**顺序很关键，不能反**）：

1. **先自己概括出篇旨 —— 不看选项**
2. 再拿自己的概括去比对四个选项
3. 找最接近的那个（通常是同义替换，不是原词复现）
4. 都不像 → 回头检查是不是篇章模式判错了

**这一步能杀掉大部分主旨题陷阱**：先有答案再找选项，而不是在四个选项里挑。
在选项里挑 = 被干扰项牵着走。

## 六、概括与复句关系的接口（两本书的接合点）

| 关系类型 | 概括时怎么用 |
|---|---|
| **转折 / 让步** | 取后半段为重心，前半段降为铺垫 |
| **因果** | 取"果"为重心，"因"作支撑 |
| **递进** | 取最后一层，前面合并 |
| **并列** | 全部合并，找共同上位词 |
| **总分** | 取"总"，"分"是展开，可删 |
| **举例** | 例子全删，取被论证的观点 |

**复句研究教材给的是关系判定，概括给的是压缩方法。**
先判关系（决定取哪部分），再做压缩（决定说得多简洁）。两者是串联的，不是并列的。

## 七、英语阅读的隐性概括难点

- 英语主旨题的正确项常是**高度概括的抽象表述**，看起来"不够具体"反而可能是对的
- **具体复述原文的选项反而是干扰项** —— 这是中国学生最容易踩的坑，因为"看着眼熟"就选了
- 四六级尤其明显，且随着级别升高，正确项的抽象程度也升高
- 检验方法：这个选项是"复述了文章里的一句话"还是"覆盖了整篇文章"？前者必错

## 八、概括方法讲义提供后补充

> 以下条目来自编者概括方法讲义（），按书内章节整理，与上文原有框架冲突时以上文为阅读分析操作框架、本书为方法补充。

### 8.1 概括的定义与层次

- **编者定义**：概括是在思维中把从某些具有若干相同属性的事物中抽取出来的本质属性，推广到具有这些相同属性的一切事物，从而形成关于这类事物的普遍概念。
- **初级概括**：在感知和表象水平上的概括（如归纳段落大意），同层级压缩。
- **高级概括**：根据事物的内在联系和本质属性进行的概括（如分析人物形象、概括主题），跨层级抽象。
- **核心动作**：上移抽象层级；概括范围越大，上移层级越高。

### 8.2 概括的六环节（写作与阅读的通用动作链）

作者写作时的六个动作，就是读者反向还原时应检查的六个环节：

1. **分析**：把整体拆成部分，明确各部分说什么。
2. **分类**：按某种标准把材料分组。
3. **比较**：比出同异、主次、轻重。
4. **抽象**：舍象（舍弃现象、留本质）或舍次（舍弃次要及无关因素）。
5. **综合**：把保留下来的主要部分按关系合并。
6. **概括**：用更高层概念表达合并后的结果。

**阅读应用**：拿到一篇文章，先按这六步还原作者思路，再做题；做题时卡壳，回头检查是哪一步没到位。

### 8.3 概括五步（针对复杂文段/全文）

1. 分解：把文段拆成可处理的小单位（句/层/段）。
2. 分类：按意思合并同类项。
3. 比较：判主次、轻重、同异。
4. 抽象：找上位概念，舍次/舍象。
5. 综合：用累加法或舍次保主法合并，形成最终概括。

### 8.4 抽象方法（"舍象"的具体操作）

- **舍象**：舍弃形象化现象，保留本质本体（如"手制的偶像"→盲目崇拜的对象）。
- **舍次**：舍弃次要因素，保留主干。
- **抽象五法**（书中提法，择要）：
  1. 由表及里：现象 → 本质
  2. 由此及彼：个别 → 一般
  3. 由近及远：局部 → 整体
  4. 由具体到抽象：事例 → 概念
  5. 由浅入深：表层 → 深层

### 8.5 综合方法

- **累加法**：各部分都重要时，把抽象后的结果叠加起来。
- **舍次保主后合并**：先删掉次要部分，再把主要部分合并。
- **综合力度不够**的表现：概括只覆盖局部、漏掉部分关系、合并后仍松散。

### 8.6 概括常见错误

| 错误 | 表现 | 对应阅读干扰项 |
|---|---|---|
| **以偏概全** | 用局部代替整体 | 干扰项只覆盖某一段 |
| **越级概括** | 过度抽象，超出原文范围 | 干扰项空泛、放之四海皆准 |
| **乱扣大帽子** | 给小类强加不恰当的大类 | 干扰项范畴错误 |
| **无中生有** | 加入原文没有的内容 | 干扰项看似合理但无出处 |
| **概括过度** | 把具体诗意/主题上升为空泛哲理 | 诗歌/文学主旨题常见 |
| **正能量误读** | 把文本硬套成励志故事 | 小说/散文主旨题常见 |

### 8.7 不同文体的概括重点

- **说明文**：抓说明对象、特征、分类、事理关系。
- **议论文**：抓论点、论据、论证结构；论点句是骨架。
- **小说/叙事文**：抓情节转折、人物心理变化、作者批判/反思主题。
- **诗歌**：抓意象 → 本质归类 → 部分综合 → 整体主旨；防止过度概括。
- **散文/游记**：抓"由具体景物/人物 → 普遍人生"的升华点。
- **寓言**：抓拥有前后心态变化、行为与后果的关系。

### 8.8 感知与理性的双翼原则

- 完整阅读分两阶段：
  1. **感性感知阶段**：沉浸式阅读，进入文本情境，获得整体印象。
  2. **理性分析阶段**：分析、概括、推理、判断。
- 两个阶段不能互相替代：
  - 跳过感知直接分析 → 断章取义、主旨偏差。
  - 只停留感知不分析 → 主旨模糊、做不出题。
- 深度感知是准确概括的前提。

### 8.9 归纳与概括的关系

- **归纳 ≠ 简单相加**：归纳是从特殊到一般，找出上位属概念统率下位概念。
- **归纳与演绎循环**：个别 → 一般 → 个别 → 一般，循环提升概括深度。
- 英语主旨题正确项应是"上位概念统率下位细节"，错误项常是细节的简单拼接。

## 十、衔接理论教材对概括层的补充（衔接 → 判断取哪部分）

> 以下条目来自 系统功能语言学家 & Hasan衔接理论教材（中译本）。概括层本来回答"这些句子合起来在说什么"，衔接层回答"句子之间靠什么连起来"——两者串联：**先靠衔接判断关系，再按关系决定取舍**（与 discourse-relations.md 第六节接口呼应）。

### 10.1 衔接是概括的前置动作

- 概括一段话之前，先识别它的**衔接骨架**：哪些词在复现（=主题词，概括时保留）、哪些句子靠连接词推进（=逻辑线，概括时按关系取舍）、哪些成分被省略/替代（=要还原后再概括）。
- 对阅读的意义：**段旨概括 = 先看衔接链，再上移抽象层级**——衔接链上的高频实词就是段旨的候选词。

### 10.2 复现渐变群 = 概括层级的预览

- 复现的渐变群（原词 → 同义 → 近义 → 上义 → 概括词）本身就是**抽象层级的阶梯**。
- 对阅读的意义：文中如果作者自己就用了"上义词"（如从 apple/orange 跳到 fruit），这就是作者给的概括提示——主旨题正确项往往就落在作者用过的这个层级。

### 10.3 概括名词 = 现成的概括表达

- the + 概括名词（the idea / the move / the thing）= 作者自己做的概括，回指前文一大段。
- 对阅读的意义：**看到 the + 抽象名词，它回指的内容就是前文的"段旨候选"**——主旨题选项若与这个概括名词同义，命中率高。

### 10.4 衔接断裂 = 概括的边界

- 新语篇开始于一句与上文无衔接之时——**段落/话题边界 = 衔接断裂处**。
- 对阅读的意义：概括全文前先划边界（哪几句属于同一衔接块），再逐块概括——避免把两个话题混成一个主旨。
